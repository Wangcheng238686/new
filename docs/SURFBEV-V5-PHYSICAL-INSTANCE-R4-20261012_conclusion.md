# V5-R4 只读诊断结论与独立复核

R4 在 20 个 R3 孤立世界组件中产生 19 个“现有其他 global ID”中心点归属候选。`170002 → 161009` 的其他场景前景票为 50/50；这是定位单景串号的线索，不是可直接使用的整块标签。19 个目标 ID 在源场景的原 `instances.json` 均缺席，因此任何派生标签都必须同时提供完整的 local/global 映射与元数据。R3 的 489 个相连风险观测涉及 95 个 global，但形状筛查不能证明其余实例干净。

独立复核确认 R3/R4 输入哈希、794 个 train/val 场景隔离与统计，但指出 R4 `stable_1874325323_not_identity_correction=true` 是**无参考场景的空判定**：17 个来源场景全部被排除，`image_in_bounds=0`。该布尔值不得解释为“稳定双栋对照通过”；本案例在 R4 为 `UNTESTABLE_NO_HOLDOUT_SCENES`，其物理拆分证据仍只来自此前用户确认与 V4 审计。R4 19 个 100% 得票来自相关重叠场景的**中心点**，不代表整块像素一致。结论：R4 只通过候选库存门，尚不支持物化完整清洗集或切换 reader。

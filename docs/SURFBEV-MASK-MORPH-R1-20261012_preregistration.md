# SURFBEV-MASK-MORPH-R1-20261012：微小内孔的首轮数据侧清洗

## 范围与路由

这是数据标签质量的冻结诊断与候选物化，不是模型模块、训练或 AP 实验。输入固定为 v3 512² 派生 ID PNG；v2 对象隔离 split 和原始 1,200-pair 数据只读。R3 的已确认误并拆分是另一条独立标签分支，本轮不把 R3 与形态学改动混合，避免事后无法归因。此次只修复**一个实例内部、完全封闭、面积不超过 4 个 512² 像素的背景小孔**；不作通用闭运算、开运算、膨胀、腐蚀、断块连接、实例分裂或大块缺失屋顶补绘。

此规则只处理局部针孔，不声称解决用户所见的所有破碎或结构缺失。前景实例 ID 数和实例归属必须不变，新增像素只能由背景 `0` 变为包围它的唯一原实例 ID。若候选孔接触图边、其他 ID，或与该实例外部背景连通，均不填。所有 mask/bbox 由派生 PNG 重算，不能沿用源 metadata 的 bbox。

## 冻结判定口径（在编码/扫描前）

- 主结局：固定分层抽样中，人工视觉判为**明确填错真实天井/建筑间隙/非屋顶**的数量。通过门：0 个明确错误；存在难以判断者单列，不算通过。
- 伴随：全部 1,200 场的像素改动合法性、实例 ID 集合/连通块数与面积变化、train/val/test/excluded 的候选场景数和新增像素数；至少覆盖 changed/unchanged、train/val、1/2/3–4 px 孔的抽样层。
- 选择口径：固定 v3 manifest SHA `8d3da5addd302451337954191dccbf1b76f588a0790f1073415e30439015922f`，唯一规则 `hole_area<=4`，不根据 test 或模型 AP 改阈值。只在 train/val 可视化和定门，test/excluded 只接受规则冻结后的确定性处理，不参与选规则。
- 不确定性：抽样是固定分层风险检查，不作为总体错误率估计；报告每层分母和错误数，不用 AP、best checkpoint 或统计显著性伪装标签真值。全量不变量要求零容忍。
- 阴性对照：未命中场景输出与 v3 PNG 逐像素相同；禁用操作的旁路必须同 v3 完全相同。唯一改动集合须等于预先登记的内孔像素，不能污染其他实例。

首次版本物化后，独立审计实现、逐像素集合、来源哈希、抽样、split 隔离；抽样图内联供用户查看。审计与抽样未通过前，产物只标为候选，不接入 reader、不训练。

## R1 视觉门失败与 R2 预先修订

R1 已物化但不得发布：固定抽样中的 `train_3-4 Coord_003004` 与 `train_1 Coord_002402` 可见填补点靠近屋顶外缘/道路侧，单凭“拓扑封闭”不足以保证填的是屋顶内部。R1 输出与抽样原样保留，不能事后挑掉不利样本。

R2 只从 R1 候选中保留更保守的真内部孔：把候选孔暂时填回同一 ID 后，以 512² 原生像素计算到**最近的非该 ID 像素（排除候选孔本身）**的欧氏距离，候选每个像素都须 `>=4 px`；图边距离也须 `>=4 px`。R2 不改变 `<=4 px`、完全封闭、背景 0、单 ID、无其他实例接触等 R1 条件。R2 输出另立目录，固定 train/val 分层抽样及 0 明确误填门不变；若没有足够可辨样本或再次出现明确误填，则停止自动填孔，转为只做问题清单。

# 第一轮形态学掩码清洗：结果与停止门

## 结论

本轮按用户提到的“破碎、小孔、结构不完整”启动**保守的小孔候选清洗**，不与多栋误并拆分混合。主目标是验证形态学能否安全修复 512² 实例掩码内的小缺陷；它不可能补全大块缺失屋顶。

R1 对所有完全封闭且 ≤4 px 的背景孔做填补，涉及 2,173 孔/2,637 像素。独立技术审计通过，但固定抽样发现至少两处屋顶外缘/道路侧误填，按预注册门判为 **FAIL**。

R2 增加“填补点距其他标签/背景和图边 ≥4 px”的内部距离门，缩减至 250 孔/322 像素；独立技术审计通过，R1 已知误填被排除。但固定抽样中仍有屋顶接缝、凹槽和环形结构的难判像素，不能确认应填。按预注册“难判不通过”，R2 判为 **INCONCLUSIVE / 不放行**。R2 候选高度集中在少数建筑：val 的 131 孔中，114 孔属于同一 global ID `358001`；因此不能把 54 张重复视图当作 54 个独立建筑的语义验证。

本轮**没有任何新的形态学标签版本获准接入 reader 或训练**。原始数据、v3、R3 误并拆分产物都没有被覆盖。训练/测试不会静默切换标签。两版输出和逐场 manifest 仅作为失败诊断资产保留。

## 后续边界

形态学只能处理极少量局部像素，不能解决用户关注的“屋顶结构缺失”和“多栋误并一个实例”。后者仍应按已确认目标单独推进：跨场景识别物理建筑并为不同楼分配独立 ID。对于真正缺失的大片可见屋顶，需卫星重叠场景/UAV 视角几何证据，而不是扩大闭运算核。若要再尝试微孔填补，也必须为难判的屋顶接缝/开口引入深度或遮挡证据，重新预注册和抽样。

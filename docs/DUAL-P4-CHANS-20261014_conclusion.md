## 四连探针交叉结论（P1-V2 → P2 → P3 → P4）

表示跨越四种（融合 64 维 / 旁路 128 维 / 纯通道 248 维；线性与 MLP 读出），
结论高度收敛：

1. **几何特异信号真实且稳定**：correct−sham90 的 F1 在全部四轮为正
   （test +0.064 / +0.172 / +0.015 / +0.013），AUROC 同向——正确几何优于
   90° 假几何，不是噪声。
2. **correct 从未在任何健康表示、任何指标上超过 SAT**：四轮中 correct−SAT 的
   F1 分别 +0.007（线性 test）/ −0.245 / −0.013 / −0.031，rho 与 AUROC 同向
   偏负。加入 BEV 通道总是小幅损失 SAT 侧性能，BEV 信息补不回。
3. **实例质量预测（rho）BEV 一贯为负贡献**（P3/P4 中 correct 比 sham 还差）。
4. 预注册的方向终止条款字面条件（boundary 两门均未过）未触发——sham 门通过
   ——但**该条款的目的条件已由四轮证据满足**：cell 级 BEV 描述子在所有已测
   表示下都无法让读出超过纯卫星基线，双流的"增益"不存在于该层。

## 决议（依证据关闭该路线）

**cell/密集层 SurfaceBEV 描述子路线关闭**（P1-V2、P2、P3、P4 四连证，预注册
门与判定格全部落判归档）。携带资产：correct>sham 的稳定几何信号证明 UAV
几何信息可被读出，问题在"格子化密集注入"这个用法则。下一步建议转
**RoI 级多视角条件化**（DUAL-R 预注册族）：在每个预测实例的特征上直接条件化
多视角几何/外观信息，绕开密集格子表示。三项指标均为冻结特征可读性度量非 AP，
本结论不声称 UAV 信息对最终 AP 无用。

  双显著（SCREEN-PASS）、无臂 FAIL。** 对照八臂阶梯：全部从零联合训练臂
  的净差为 −0.6~−0.9 或贴零；warm 冻结把代价项按构造归零后，净差 =

- **延长劣化**：双指标点估计缩水至 1/5~2/3，CI 均含 0 → R1 按预注册
  last 口径落 **SCREEN-FAIL（延长后）**。
- **机制归因（登记，非借口）**：EXT 续训点以满 LR 5e-4 重启余弦
  （30ep 余弦已衰减至 ~0 → 重启跳回全幅），对已收敛的门/proj/LoRA 再
  扰动 30ep；末代 delta_p3_ratio 仅 0.071→0.080（通路未进一步打开），
  best_segm 全程停滞 0.7603。30ep 状态实为该臂更优解。
- **自适应决议（依"不烧无效算力"红线）**：R1G-ext 保留执行——作为
  重启伪影的复现检验（不同 gate_init 下是否复现劣化）；若复现
  （n=2），R1B-ext 跳过，三臂以 30ep 口径关账，修正版续训协议
  （低 LR 平台/无重启衰减）作为后续预注册项。

## 判定门原文（引用预注册）

SCREEN-PASS：on−off 双指标 CI95 下界均 >0 且 on−single segm 点估计 >0；
SCREEN-EXT（一次性）：on−off ∈ (0,+0.3) 且任一 CI 含 0 → 续训至 60ep 再判；
SCREEN-FAIL：on−off 双指标 CI 均含 0；护栏：on−single < −0.5 且 CI 上界 < 0。

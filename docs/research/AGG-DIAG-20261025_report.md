# AGG-DIAG-20261025：五视角聚合信息损失实测报告（val 60 点）

数据与工件：`/data2/wangcheng/checkpoint/surfbev_b0/probes/AGG-DIAG-20261025/`
（脚本 /tmp/agg_diag_20261025.py 拷贝于该目录；rows.jsonl 60 行；summary.json；
parity.json——聚合统计与 `prepare_native` 基线的逐位一致性校验通过；卫星
光轴 nadir 误差 ~2e-16 确认透视相机近似正射）。被测基线 = 当前 z-buffer
4 通道聚合（height/dx/dy/viewcount）。口径：mean / median [p10, p90]。

## 决策相关数字（五条）

1. **z-buffer 丢掉的多表面结构集中在建筑上且量级实质**：支撑区像素中
   ≥2 个独立表面（>1m 分离）占 **15.5%**（全体）/ **25.0%**（建筑足迹内，
   p90 40.0%）；≥3 表面 9.6%。跨视角高度散布 >3m 的像素：建筑内 **25.1%**
   vs 背景 5.9%（**4.3 倍反差**）——多高度信息（塔楼/裙房/悬挑/树冠层）
   系统性地集中在检测器要找的目标上。极端样例 point 455：建筑像素高度
   散布 p90 达 39m。
2. **逐视角证据被"计数"通道严重压缩**：支撑像素中**只有 1 个视角**在最近
   表面 1m 内的占 42.6%（中位 32.5%）、≤2 视角 65.7%；建筑内 <3 视角一致
   的占 61.9%。斜视视角的互补遮挡是常态而非例外——单通道 viewcount 无法
   表达"哪几个视角、各自看到了什么"。
3. **z-buffer 伪可见性缺陷在本数据集上被证实**（呼应 ISPRS 2013 记载）：
   建筑像素中 25.0% 存在 ≥2 表面；其中胜者与次表面高度差 >3m 的，背景侧
   59.7%、建筑侧 46.8%。**每场景平均 32 个"高实例"、65.4% 的实例有 ≥10%
   像素被标记**；高实例 32.4% 的像素存在胜者跳变。即当前 height 通道在
   建筑边缘/立面上有系统性错误值，不只是"少信息"而是"带噪声"。
4. **RGB 外观信号存在且与建筑相关**：可比较像素上（占比 57.4%）跨视角
   RGB 方差建筑 vs 背景 = 40.8 vs 27.0（point 455；point 493 为 35.5 vs
   26.2）——外观分歧度是一致的建筑指示器，当前管线完全未用。
5. **过采样充足，richer 通道在 512² 有原始证据支撑**：每支撑像素平均
   **5.47 个** UAV 样本（p90 6.7；point 455 达 7.7，p90 21/px）；UAV 投影
   GSD ~40cm vs 卫星 ~65cm（斜视视角分辨率反而更高）。无覆盖像素：全体
   22.9%、建筑内 19.5%（中位仅 9.1%）——五视角拼接后的覆盖空洞主要在
   边缘/遮挡死区，可由 support 通道显式交给下游。

## 结论（对聚合设计的直接约束）

- **必须保留多表面**：25% 的建筑像素有第二表面、散布中位近 1m、尾部
  数十米——单高度图 + 梯度在建筑上既有损又有偏。K=4–8 高度 bin 或
  有序表面栈有真实信息可装（不是空 bin）。
- **必须逐视角或视角分组**：单一 viewcount 通道不可逆压缩了 42.6%
  单视角像素的证据；至少需要 per-view 平面或 per-bin view 计数向量。
- **z-buffer 伪可见性要修**：任一新方案应按"表面分层 + 遮挡一致性"
  重算，而非在现有 height 上修补。
- **RGB 值得带上**：跨视角外观分歧（building/bg ≈1.5 倍）是现成的
  无训练增强通道；特征级（冻结 SAM2 编码器）为进阶。
- **算力无瓶颈**：5.5 样本/像素的过采样 + 512² 目标网格，K-bin
  splat 的激活内存（C=64, fp16, K=8）约 260MB 级，可承受。

## 判读边界

- 60 点 val 子样本（跨 split 均匀抽取）；未读 test。
- RGB 方差是"外观分歧存在性"的粗测（未控制光照/视角角差），非任务
  可用性的证明——任务对齐仍需探针（const/shuffle 对照）。
- 表面分离阈值 1m、散布阈值 3m 为报告约定；rows.jsonl 含逐点分布可换
  阈值复算。

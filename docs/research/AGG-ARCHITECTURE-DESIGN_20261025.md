# AGG 架构设计：保住五视角信息损失的聚合方案（2026-10-25）

接地材料：`native_geometry_probe.prepare_native`（现行投影/z-buffer/4 通道
基线）、`ue_geometry_proposal_pilot_20261024.Net`（CenterNet 候选头，5ch
输入 512²→128²）、`ue/dual.py`（冻结 SAM2-LoRA UAV 编码器形态；历史稠密
注入失败教训）、`surfacebev.py`（旧 12-bin 光栅器）；实测数字见
`AGG-DIAG-20261025_report.md`；文献支撑见 `MULTIVIEW-AGGREGATION-SURVEY_20261025.md`。

**实测约束（设计必须对准）**：① 建筑像素 25.0% 有 ≥2 表面（散布 p90
39m）→ 多表面必须显式分层；② 42.6% 支撑像素单视角 → 逐视角证据必须
保留；③ 65.4% 实例存在 z-buffer 胜者跳变 >3m → 伪可见性必须修复；④
跨视角 RGB 方差建筑/背景 1.5 倍 → 外观通道有信号；⑤ 5.47 样本/像素、
UAV GSD 40cm < 卫星 65cm → 512² 下 richer 通道证据充足；⑥ 无覆盖 22.9%
→ support 显式交给下游。

**历史失败模式（设计红线）**：稠密特征注入冻结检测器九连败（模态塌缩）
→ 一律走候选接口/RoI 条件化，不做金字塔稠密注入；cm 量纲主导 → 全部
通道无量纲化（写死归一化常数）；稠密信号任务对齐弱 → 通道设计偏向
实例证据集中处（边界/高度不连续保持池化）；联合训练 GradScaler 尖峰
→ 候选头独立损失缩放。

## 方案 A：有序表面栈（Ordered-Surface Stack）——修伪可见性，训练无关

每支撑像素保留按深度排序的前 K=3 个表面（>1m 分离），而非只留最近者。

```
输入: 全样本 (pix, z, h, view)（prepare_native 已有，去 z-buffer 化）
按 (pix, z) 排序 → 逐像素取前 3 个表面簇（簇内 ≤1m 合并，均值高度）
输出 @512²（12 通道）:
  for k in 0..2: height_k/40 (tanh 截断), exists_k (0/1)
  gap_01/40, gap_12/40            # 层间距（悬挑/立面指示）
  occl_consist                    # 胜者与次表面 >3m 且视角集不同的掩码
                                  # —— 即被修复的伪可见性位
```

- 恢复：多表面（①）、伪可见性修复（③）。不恢复 RGB。
- 通道预算：12ch@512² → 头输入处 avg-pool 到 128²（边界用 max-pool 保
  高度不连续，避免诊断 ③ 的边缘被均值抹平）。
- 成本：排序 O(N log N)，N≈1.07M 样本/点，CPU/数据管线级，训练无关。
- 失效模式：K=3 之外的超多层（极少，p90 4 表面）；无表面像素全零由
  exists 位表达。
- 插接：候选头输入 5ch→17ch（首层 conv 加宽，参数 +~4k）。

## 方案 B：多高度 bin 几何 splat（K-bin Geometry BEV）

把（1）里的每表面样本按**世界高度**落入 K=8 个固定 bin（0–40m，每 bin
5m），逐 bin 记 occupancy + 视角计数；不做特征，纯几何。

```
输出 @512²（11 通道）:
  occ[0..7] (每 bin 是否有表面), per-bin 聚合 viewcount 简并为
  maxbin_idx/8, hgt_above_bin_center/5 (仅最近表面),
  n_surfaces/4, support
```

- 恢复：多表面（①）、逐视角计数的 bin 化版本（② 部分）。
- 成本：与 A 同级（数据管线）。相比 A 信息更粗但通道更省、对高度异常
  值鲁棒（截断即丢尾部 39m 之外的样本，A 的 tanh 截断同理）。
- 失效模式：bin 边界抖动；固定 bin 网格不随场景自适应（接受，写死）。

## 方案 C：逐视角平面（Per-view Planes）

不做跨视角合并，每视角独立落平面，把"如何合并"交给头的卷积。

```
输出 @512²（13 通道）:
  for v in 0..4: h_v/40, valid_v        # 该视角最近表面高度与可见性
  cross_view_var(h)/40, n_views/5, support
```

- 恢复：逐视角证据（②）的直接完整解；跨视角 var 同时是遮挡/矛盾指示。
- 成本：数据管线级。失效模式：头需自行学跨视角组合（5 组通道间的
  关系），容量需求略高；单视角噪声直接进头（A/B 在管线内已平均）。

## 方案 D：真正射风格通道包（True-Ortho Pack）——训练无关、一周可消融

测绘界实证配方（true-ortho+nDSM）的移植，与 A 互补地引入 RGB。

```
输出 @512²（10 通道）:
  true_rgb (3)     # 遮挡感知合成：每像素取"高度-梯度遮挡检测通过"的
                   # 最近表面样本的 RGB（Oliveira 2013 高度梯度法）
  rgb_var (1)      # 跨视角 RGB 方差（实测建筑/背景 1.5 倍信号）
  vis_count/5 (1), occl_mask (1)     # 可见性/被遮挡位（③ 修复）
  h2_minus_h1/40 (1), ndsm/40 (1)    # 第二表面差、归一化表面模型
  support (1), sky_dir (1)           # 无覆盖位与主遮挡方位（哪个 yaw 缺）
```

- 恢复：RGB 外观（④，像素级）、伪可见性（③）、无覆盖方位（⑥）。
- 成本：数据管线级；true_rgb 合成复用现有投影样本（RGB 随样本携带）。
- 失效模式：光照/色差跨视角不一致污染 rgb_var（未标定；接受为噪声）。

## 方案 E：深度门控多高度特征 splat（Feature Splat，调研推荐 1）

冻结 SAM2-LoRA 编码器抽五视角 stride-16 特征（32²×C），随深度样本
splat 到卫星 128² 网格（与候选头输入同分辨率），K=6 高度 bin 分层，
逐 bin 视角计数门控 + 跨视角特征方差通道。

```
输入: 五视角 RGB → 冻结编码器 → f_v ∈ R^{32²×C}, C=64
每样本 (u,v,pix,h) 双线性取 f_v[u,v]，按 h 落 bin k，原子加到:
  F[k, pix'] ∈ R^{128²×C}, cnt[k, pix']
输出 @128²: cat_k( F[k]/cnt[k] ⊙ gate(cnt[k]), Var_v(f)[k] )  # K×(C+1)
门控: gate(c) = min(c,3)/3           # 计数门控，抗单视角噪声
归一化: f 已是编码器输出（LayerNorm 后，无量纲问题）；方差通道 /f_std
```

- 恢复：RGB 外观特征级（④ 增强版）+ 多表面分层（①）+ 逐 bin 视角
  证据（②）。四个丢失维度全修。
- 通道预算：K=6 × (C=64+1) = 390ch@128²（fp16 ~12.7MB/点）；候选头
  输入 1×1 conv 压到 96ch（参数 ~37k）。
- 成本：五视角编码器前向 ~5×8GFLOPs（冻结、可缓存 train split 一次）；
  splat 本身为 scatter-add。
- 失效模式（对应第 6 节文献）：模态塌缩——**候选接口先行、冻结检测器
  不动**；内容对照（const/shuffle 特征）先行验证任务对齐。
- 插接：候选头 only（第一阶段）；RoI 条件化为可选二阶段。

## 方案 F：卫星查询几何受限可变形跨视角注意力（调研推荐 2，二期）

卫星 128² 网格 16.4k 查询，每查询沿垂直线 K=4 个 3D 参考点投影到五
视角特征图，deformable cross-attention（C=64，adapter ~1.5M 可训，
编码器冻结）。

- 恢复：与 E 同域，但聚合权重由任务梯度学习；无 dense volume，算力
  数 GFLOPs/点，最省。
- 前提：任务梯度足够（第 6 节风险）→ 作为 E 跑通后的二期，用 E 的
  输出初始化查询缓解冷启动。
- 内容对照：投影几何置乱（同一查询的参考点 shuffle 到错误视角位置）。

## 最小首实验（预注册式，冻结检测器 + 候选头 only）

**臂名**：AGG-SURFSTACK（= A+D 合并通道包，22ch@512²，训练无关数据
管线 + 现有 CenterNet 头首层加宽；对照 = 现行 4ch 基线头，同预算同
种子重训）。

**四要素**：
1. 主指标：候选接口对 **RPN 漏检实例的召回率 recall@IoU0.5**（现行
   +0.47 地板所用同一口径）；伴随：合并后逐场 AP 差、被恢复实例的
   z-buffer 伪可见像素占比（机制归因）、边界带指标。
2. 选择口径：固定预算（10ep 探针协议）last。
3. 显著性：val 全量逐场 scene-paired bootstrap（10k draws、seed
   20261014）。
4. 判定门：**GAIN** = 召回差 CI95 下界 >0 **且** 内容对照臂（表面栈
   通道替换为场景常量）无同等增益（排除正则化假象）；仅前者成立记
   USED_BUT_NULL-嫌疑，需 E 升级验证；HARM = 合并 AP 显著下降。

**为什么是 A+D 而非 E 先行**：③（65% 实例受伪可见性影响）与 ④（1.5
倍 RGB 方差）都有实测直接背书、零训练风险、一周内可落判；E 依赖任务
对齐假设（历史上最脆的一环），等 A+D 的内容对照给出正向证据再上。

## 排序 Top-3（按证据×成本×风险）

1. **A+D 表面栈+真正射包**（最小首实验本体）：修两个已实测的缺陷
   （③④），零训练风险，任何结果（含 NULL）都为 E/F 提供干净对照。
2. **E 深度门控多高度特征 splat**：唯一四维全修的方案；实测 5.47
   样本/像素证明证据充足；冻结编码器+候选接口规避塌缩历史；在 A+D
   内容对照过门后启动。
3. **C 逐视角平面**（作为 A 的廉价伴随消融）：若 A 的增益集中在
   跨视角矛盾像素，C 应进一步放大——用同一评估口径区分"多表面信息"
   与"逐视角信息"哪个是主贡献。

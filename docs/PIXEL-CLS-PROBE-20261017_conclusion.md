## 判读

1. **建筑信号在反投影之前的逐像素 SAM2 特征里存在**：一个 3 层 MLP 就能
   以 86% 准确率 / 0.96 AP 判出"这个 cell 看的是不是建筑"。
2. **与 BEV-READOUT-P0 拼合后的一刀切**：同一份描述子经栅格化跨视图平均
   后任务信号消失（BEV IoU 0.671 ≈ 置换对照 0.670），而源特征逐像素可分
   （本探针 Δ+0.08、AP 0.96）→ **信息是被聚合方式洗掉的，不是源特征
   没有**。SCVT4 复盘原则"度量几何做锚 + 注意力路由内容"在 UE 数据上
   有了正面证据。
3. 判读边界：像素可分性是注意力聚合增益的必要非充分证据；底率 0.78 偏高
   （斜视图建筑占优），acc-Δ 与 AP 双口径均过线；不构成 AP 结论。

## 实施决议（PI 框架内）

新臂立项：**统计组通道继续走精确反投影**（免费、已证有货，
BEV-READOUT stats 组 IoU 0.895）；**描述子组单独走 CVT 式注意力通路**
（查询=BEV 格世界锚，键/值=各视图描述子 cell + 精确度量几何嵌入）进
同一张 BEV。基座沿用 warm 冻结 + gate_init 0.001（对照 R1G 单变量 =
描述子通路替换）。先 30ep 热启动筛查，过门再全量。

  双流 checkpoint 先加载、再以单流 checkpoint 覆盖同名 satellite keys；任何缺失/
  unexpected key、checkpoint SHA256 或 resolved-config hash 未归档即 INVALID。
- **数据:** 官方 `ue_coco_with_uav`；训练仅为既有 128-scene train subset（ratio
  `.1797752808988764`、seed 44）按原始顺序的前 80 个**边界标签有效**场景：有效定义为
  卫星 GT mask union 下采样到 P3 后既非全零亦非全一。固定子集内无效场景跳过，但其 ID、
  原始 index 和最终 80 ID 必须逐项归档；评估为完整 259 val scenes，禁止跳过 val。
  训练/val scene ID 必须逐项保存并断言无交集。边界标签为同一卫星 GT mask union 下采样

  冻结线性读出监督，不是检测器训练标签。
- **特征:** `SAT` 为单流 P3 512-d；`DBEV_correct` 为由 360m、z=0、FP32、autocast-disabled
  W2C/K 投影从五路 frozen UAV-FPN 四层双线性采样并 valid-view average 得到的 1024-d；
  `DBEV_mis` 唯一替换为绕 scene center 旋转 90° 的地面点。每 cell 的 valid-view 计数、
  P3 lattice/world-point 映射和正确/错配几何均须归档。
- **读出:** 对每一套特征在训练场景随机但确定地采样每场 1,500 cell（seed
  `20260925+scene_index`），仅由 train 拟合 standardization、PCA（若使用）和确定性
  linear ridge readout；val 禁止 fit。固定比较为 `SAT`、`SAT+DBEV_correct`、

  DBEV 拟合 512 components、固定投到 val。不得删减或替换任一臂。

### K.2 四要素、对照和门

- **主指标:** 259 val 每 scene 的 Pearson-r 中，`SAT+DBEV_correct - SAT` 的均值差。
  **伴随指标:** correct-minus-mis 边际差、PCA512 correct-minus-mis 边际差、各臂 r 的
  mean/std、improved/worse scenes、valid-view coverage、P3 boundary label scale；未来
  端任务的 boundary-F1/boundary-IoU、segm AP75、segm/bbox mAP_s、segm/bbox mAP 仅为
  *后续热启动* 预注册端点，E5 不报告 detector outcome。
- **选择口径:** 此处唯一一次完整 259-val 扫描；全部 cell 的每场 Pearson-r，不选择
  checkpoint、epoch、scene 或 threshold。
- **显著性:** 259-scene paired percentile bootstrap 10,000 draws、seed `20260926`；另报告
  paired t 仅作伴随，不替代 bootstrap。CI 只量化 val scene 抽样，不外推训练随机性。
- **E5_PASS:** 完整性与所有不变量通过，且 (i) correct-minus-SAT bootstrap 95% CI 下界
  `>= +0.02`；(ii) correct-minus-mis bootstrap 95% CI 下界 `>= +0.02`；(iii) PCA512
  correct-minus-mis bootstrap 95% CI 下界 `>= +0.01`。任一 CI 门不满足为
  `E5_NO_MARGINAL_BOUNDARY_SIGNAL`；parity、hash、数据、标定、manifest 或 fitted-artifact
  任一失败为 `INVALID`。PASS 只授权另立“BEV→boundary-refiner 热启动筛查”提案，绝不
  自动授权实现或训练。

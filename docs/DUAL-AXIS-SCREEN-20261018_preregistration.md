## 臂 C（PI 重评方案 2026-10-18 中午）：WARM-R1F——一次修两环

设计矩阵里唯一没跑过的格子：**R1C 配方（values-only 注意力，查询纯几何，
无 sat_query）+ 消费者解冻 + 固定门 + 注意力输出辅助监督**。

1. **骨架+颈部**：EXP-0009 热初始化冻结（保住代价项归零成果）——不变。
2. **消费者解冻**：rpn_head. 与 roi_head.（P2 注入的真正消费者）从收敛
   初值低 LR 微调——`--unfreeze-consumers --consumer-lr-mult 0.2`
   （5e-4×0.2=1e-4，独立参数组）。**parity 不变式因此失效**（消费者已
   适配注入，off≠single），登记为预期偏差；护栏改为 on−single 直接监测。
3. **门固定不可学习**：`gate_init 0.001 + gate_trainable False`
   （requires_grad 钉死）。**"开度 0.05–0.1"的操作化**：门是传输系数、
   proj 自校准输出范数——R1C 家族训练平衡态开度 0.07–0.12 对应门量级
   ~0.001-0.013，固定 0.001 落在该带内；护栏：ep1 开度 >0.5 终止。
   依据：gate-sweep k=2 +0.40（欠开常态）+ 可学门在冻结消费者手里
   就是替它拒收新信息。
4. **辅助监督 values-only**：bev_head_source='attn'（BCE+Dice，0.05）——
   查询纯几何，注意力输出只能从 UAV values 读内容，堵住查询侧卫星
   信息泄漏（R1Q 的教训）。
5. **调度**：平台方案按 30ep 比例映射 `--lr-plateau-epoch 18
   --lr-plateau-mult 0.1`（60/100→18/30）；EXP-0022（~17:10 收线）的
   平台验证结果作为该选择的确认性证据（不阻塞筛查启动）。

### 判据（双检查点筛查 + 修订机制门）

- **筛查门**：on−single 双指标 CI95 下界 >0 且 segm 点估计 >0（30ep
  last；双检查点 = on/off 双遍评估口径，off 现在是"消费者已适配下的
  撤供"读数，报告但不作门）。
- **修订机制门**：阶梯 C0−C2（注意力输出=values-only 内容，换 train
  均值图）segm CI95 下界 > 0——必须显著掉点才采信；不过则仍是模板。
- mAP_s 防护：on−off segm_s 回退 ≤1 点。
- 中间态/失败按既有条款；若过门但幅度 <+0.3，按 PI 升级路径预研
  RoI 级条件化（注入点上移，BEV 描述子按实例框池化拼进 RoI 头——
  攻 R0 +11.9 边界带 oracle，描述子从冗余竞争者变独占证据提供者）。

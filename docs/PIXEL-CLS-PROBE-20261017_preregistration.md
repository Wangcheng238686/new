# PIXEL-CLS 探针预注册（2026-10-17）：逐像素"看的是不是建筑"可分性

PI 提案 2026-10-17：在改任何聚合架构之前，一刀切开"信息在源特征里就
没有，还是被反投影平均洗掉"。BEV-READOUT-P0 测的是栅格化后的 BEV
（描述子空载），本探针测**反投影之前**的 UAV 视图逐像素 SAM2 特征。

## 设计

- 特征源：冻结预训练 UAV 编码器（EXP-0014 checkpoint 的 uav_encoder，
  该臂为冻结臂 = SAM2 base_plus 原始特征；与 `_uav_bev` 消费同一 FPN
  层——fpn[-4:] 中面积最大层），逐描述子 cell。
- 逐 cell 标签（精确几何）：cell 中心像素 × DeviceZ 真值深度 → 反投影
  3D 世界点（surfacebev.py 第 36–44 行同一数学）→ 3D 点经**卫星相机投影**
  （几何审计 2.4px 验证路径）到 512 卫星格 → 查 GT 并集足迹。注：旧
  ue_dual_stream 的仿射契约为米制，与本数据 cm 坐标不符（2026-10-17
  调试发现，正率坍缩为 0），已弃用。
  无效深度/出界 cell 剔除。
- 读出器：MLP(C→256→256→1)，BCE，AdamW 1e-3，GPU 上训练（与
  BEV-READOUT-P0 同款）；另报逻辑回归基线。
- 数据：train 60 / val 40（split 顺序前 N，与 BEV-READOUT 同口径），
  5 视角 × 描述子网格全部 cell。
- 阴性对照（sham）：场景内标签乱序（打乱 cell-标签配对）——管道无泄漏时
  必须跌回底率。

## 判据（PI 原文）

设底率 p = val 中建筑标签 cell 占比（多数类准确率）：

- **判据 A（PASS，绿灯聚合）**：val 准确率 > 0.75 且显著高于底率
  （acc − p 的逐场景 bootstrap CI95 下界 > 0）→ 信息在特征里存在，
  被平均洗掉 → CVT/注意力聚合有货可拉，允许立项新臂（统计组反投影 +
  描述子组 CVT 注意力进同一张 BEV，即 SCVT4 原则"度量几何做锚 +
  注意力路由内容"的字面实现）。
- **判据 B（FAIL，描述子判死）**：acc − p < 0.05 → SAM2 特征在 UE
  斜视图上分不出建筑/非建筑像素，任何聚合方式都救不了（垃圾进垃圾出），
  描述子正式判死，安心走统计组。
- 中间态：报数字，判读降级为"部分可分"，新臂立项需 PI 再裁决。
- sham 未跌回底率（sham acc − p > 0.05）→ 探针无效，全部结论作废。

判读边界：像素可分性是注意力聚合增益的必要非充分证据；不构成 AP 结论。

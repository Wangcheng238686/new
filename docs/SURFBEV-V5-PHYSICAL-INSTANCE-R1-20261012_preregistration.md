# SURFBEV-V5-PHYSICAL-INSTANCE-R1：物理建筑实例清洗第一轮

## 目标与边界

目标是最终形成 1,200 场、每个实例 ID 尽量对应**一栋物理建筑**的可训练派生数据集。本轮优先发现和修复“一个 UE/global ID 覆盖多栋楼”；非连通和掩码相连的误并都在目标范围，但不得将非连通本身当成必须拆开的充分条件。形态学 R1/R2 失败候选不接入，其他孔洞/边界/漏标留后续轮次。原始/v3 标签只读；训练 reader 不静默切换。

这是数据侧冻结诊断 → 候选标签物化 → 独立审计的路由，不是模型模块叠加或 AP 实验。输入锁定 v3 manifest SHA `8d3da5addd302451337954191dccbf1b76f588a0790f1073415e30439015922f`、v2 split SHA `17f49430b15037c8da25c63a1bf7fe4d510cf5ff153263d2feba62c4393441d5`；卫星标签语义是可见建筑表面的俯视投影，不是地面 footprint。可使用卫星 RGB/标签、跨场景重叠、已有 UAV RGB/DeviceZ；不使用 WorldPosition。

## R1 冻结诊断（先于任何 v5 标签写出）

从 train/val 794 场产生候选：既有 M2（第二 8-连通块 ≥64 px 且占原 ID ≥10%）36 个全局 ID 为受控主集合；同时另列“当前图内连通但 bbox 低填充/细颈”的风险候选，不把它们静默算作阴性。对每个主集合 global ID，使用卫星内外参把**该 ID 的全部可见像素**投影到共同世界 XY 平面，构造 1 m 栅格的跨场景占据图；这里的 Z=0 只是跨视图关联近似，不宣称真实屋顶高度，也不用于改标签边界。记录原始/扩张 3 m 后的连通域、可见场景数、图边比例、每景组件数、每个聚类的支持场景数和世界中心范围。输出候选清单及可视化，不读取 test 图像做定阈值。

**主诊断门**：已由用户确认的误并 `1874325323` 与 `170002` 必须被列为至少两栋的候选；已知反例 `1571206454` 与 `1508745546` 不得被自动列为可直接拆分。伴随：36 个 M2 global 的各 split 场景数、图边/单块可见比例、聚类稳定性、遮挡/深度可用性与未能判定数。阴性对照是对每个 global 打乱场景相机 XY 后重建占据图，要求明确记录其与正确几何的重叠变化；它只验证地理关联对齐，不充当物理真值。

**选择/显著性口径**：四个锚点与几何参数在读取结果前固定；本轮不按 AP、test 或事后挑选样例改门。它是有限已知正反例的工程诊断，不主张统计泛化或 AP 增益；固定分层样本和每个 global 的跨场景一致性是后续语义验收的依据。全量像素/哈希/ID 不变量为零容忍。任何正反例门失败，停止自动物化 v5 并归档失败诊断。

## 后续 v5 标签门（本轮诊断通过后才实施）

同一物理建筑在所有可用场景必须使用一致 child global ID；每张图分配不与原 raster **或** `instances.json` 已声明 ID 冲突的 local ID，child global 限正 signed int64。只重新标识原 parent 前景，不补绘/删像素；连通原掩码若需分界，必须另有卫星结构或 UAV 证据并记逐像素依据。只露一栋的场景也必须按冻结的世界身份归属，不能沿用 parent global 冒充 child。无法稳定归属的场景标为 HOLD，不静默半拆。全部 1,200 场输出派生 PNG、完整映射、mask/bbox、来源与输出哈希；train/val/test/excluded 都按冻结规则处理，test 不用于调规则。

固定分层视觉抽样覆盖自动拆分、HOLD、未变对照、裁边、不同 split（语义判断仅 train/val）；明确误拆/漏拆为 0 才能放行，有难判样本则不称完整清洗。独立子代理审首次实现及关键修订；未过审计/视觉门不得接 reader 或训练。若最终未覆盖 connected 多栋误并，须明确标为“不完整第一轮”，不可称最终可训练清洗版。

PI 决议（2026-10-21）：v1 划分存在验证集指标虚高、测试集漂移的问题
（`docs/VALTEST-DRIFT-20261021.md`：三因子归因以分布失配为主）。PI 提供
**v3 重划分** `/data1/wangcheng/dataset/CitySample_SatUAV_TrainMinimal_v3_20261021`
（2629 点：train 1931 / val 285 / test 413；实例 123788/18066/24754；
目标 70/15/15，实际 73.45%/10.84%/15.71%，分布平衡优化；标签权威与
修订不变 `review99_v3_user_approved_20261021`；格式与 v1 逐字段同构，
加载路径零改动）。重跑同对双臂。

## 两臂定义

唯一变量 = 训练增强（同 EXP-0024/0025）：**EXP-0026 全关增强**（flip 0）、
**EXP-0027 默认增强**（hflip 0.5，其余全 0）。

## 相对 EXP-0024/0025 的协议变更（PI 指定，共两处）

1. 数据根换 v3（新 SHA 契约：7 个数据文件重钉，规模断言 1931/285/413、
   123788/18066/24754）；
2. **批布局调整：每卡 batch 2 × 梯度累积 1**（原 1×2），有效 batch 仍 8
   （4 卡 × 2 × 1）；world_size、LR、wd、warmup、cosine、epochs、amp、
   seed 44、last 口径、SAVE_LAST、val 每epoch 全量 285 场、test 密封——
   全部不变。模型身份 `ue-whu-a3sgm-512-v1`（指纹 `5305b315…`）不变。

## 四要素（继承 EXP-0024-0025 预注册）

1. 主指标：val 285 全量逐 epoch COCO segm/bbox AP@[.50:.95]；对照差 =
   EXP-0027 − EXP-0026（last 口径）；伴随 AP50/AP75/面积分层。
2. 选择口径：last epoch 100。
3. 显著性：last 权重 285 场逐场 scene-paired percentile bootstrap
   （10,000 draws、seed 20261014）。
4. 判定：AUG_WINS / AUG_NULL / AUG_HARM 同原定义；**新纪元卫星基线 =
   本对中 last 更优者**（v1 双臂降级为历史参照——其 val 分布已证失配）。
   测试收口沿用已注册 cap250+maxDets250 规约（commit `187c29e`），
   开封为独立事件。

## 预注册解读条款（v3 治理目标）

- v3 的 val-test 漂移检验：收线后若 val（285 场）与 test（413 场，
  cap250 口径）差仍 >5 点，则漂移不可归因于划分，需回数据生成侧；
  若收敛到 ~1-2 点，v3 确立为新纪元标准划分。
- 批布局变更本身不设判定（有效 batch 不变；GroupNorm 无 BN 统计差异；
  DDP 梯度数学等价），仅在契约行登记。

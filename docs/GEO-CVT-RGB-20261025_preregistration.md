# CVT-RGB 增量臂预注册（2026-10-25，PI"RGB 必须保留叙事"裁决的落位）

## 背景与唯一存活形态

RGB 直投已在已验证几何接口上否证（`GEO-RGB-INCREMENT-20261024_conclusion.md`：
真 RGB − 常量 RGB = +0.049pp CI[−0.036,+0.102] 含 0；头对头 vs 几何-only
四指标 CI 上界 ≤0）。远端预注册保留条款指认的唯一未测形态 =
**CVT 式跨视角聚合**：不是 z-buffer 胜者像素直投，而是学习式跨视角
注意力池化（S²DB-Net IPT / SCVT4 CVA 血统），把 5 视图 RGB 特征在
几何对齐下聚合成卫星帧的稠密外观图，再并入几何头输入。

## 设计（单因素：几何头输入 5ch → 5+Cch）

- **聚合器**：轻量固定几何交叉注意力（无位姿学习——用已验证的精确
  投影）。每卫星 4px 格的候选（≤2/视角）携带其源视图 token 的
  SAM2 冻结特征（256d，与 EVI-DECODER 同源同提取）；单头余弦注意
  力（温度固定 4，与 B0 底盘同款）聚合成 C=8ch 外观图。
- **头**：几何头首个 block 输入 5ch → 5+8=13ch，其余逐位不变
  （含 common-init 对旧参数的位等同源加载）。
- **训练**：10ep × real/constant-RGB 双臂（对照 = 外观图在 RGB 常量
  化下重建，几何 5ch 保持真实），同预算同协议同 common-init 纪律。
- **判据**（预注册四要素）：
  1. **RGB 内容门（主）**：real − constant 的 Mask AP 配对 bootstrap
     CI95 下界 > 0（直投形态在同门下 +0.049 含 0——只有过此门才谈
     RGB 复活）；
  2. 接口净门：real − (几何-only 复现基线 66.5546) ≥ −0.1pp（不伤
     已验证接口）；
  3. 伴随：候选召回（any50@250）与 Boundary 指标；
  4. 解读条款：过门 → CVT 外观图并入联合训练最终形态（叙事：卫星
     RGB + UAV 几何与跨视角外观）；不过 → RGB 增量第三次否证，
     叙事定为"卫星 RGB + UAV 深度/几何"双模态，RGB 路线正式关闭
     并归档三重否证链（13 变体电池 + 直投 + CVT）。
- **风险**：聚合器位姿刚性（无 SceneAwareAlignment——SCVT4 的对齐
  学习模块）——用精确投影替代，若不过门需区分"形态错"vs"对齐不足"，
  归档时注明。

## 排程

等 joint-100ep / sat-100ep 收线让出卡后跑（10ep × 2 臂 ≈ 6h DDP2）；
不阻塞主线。

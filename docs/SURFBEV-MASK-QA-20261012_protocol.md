# SURFBEV-MASK-QA-20261012：建筑实例标签分层复核协议

## 范围与冻结口径

这是数据质量诊断，不是模型 AP 实验；只读使用已注册的 1,200-pair manifest 和
`surfbev_b0_split_v2.json`。抽样、制定规则仅使用 train/val，**test 不读、不抽、不按其
内容调阈值**。所有面积、形态阈值均在原生 512×512 ID raster 上计算，不使用
1024×1024 的上采样面积。模型预测、AP、UAV 图像均不参与标签判定。

目标标签仍为“卫星视角实际可见的建筑几何投影”，主要是屋顶，但不强制为规则多边形、
完整屋顶或地面 footprint。遮挡和图边截断可以产生多块可见区域。

## 抽样（诊断优先，不直接估计总体坏标率）

对每个非零 local ID 计算像素面积、bbox、最窄 bbox 边、bbox 填充率、8 邻接连通块、
最大连通块占比以及是否触边。按以下**互斥优先级**分层；后续层排除前面已纳入者：

1. `micro_1_4`：面积 1–4 px；
2. `tiny_5_15`：面积 5–15 px；
3. `thin`：bbox 最窄边 ≤2 px；
4. `major_fragment`：≥2 个连通块，且最大块面积 <总面积 80%；
5. `sparse`：bbox 填充率 <15%；
6. `border`：mask 碰到图像外边界；
7. `control`：其余实例，不按模型成败筛选。

每层固定 train 12、val 6，共目标 126 个。若某层不足则全取并显式报告，不从其他层
补足。层内按空间 cell 均衡、尽量选不同 `global_instance_id`，随机种子 20261012。
同一建筑在多景重复出现时仅保留一个复核样本；未选中候选不被解释为合格。
抽样清单冻结后才人工判读；不能根据发现替换样本。

## 人工判读标准（逐实例，RGB + ID + 同景 `instances.json`）

`KEEP`：像素确属当前 global ID 所代表建筑的卫星可见表面；遮挡、裁边、内部空洞、
不规则屋顶或合法多片可见区域均可保留。不能仅因不够“方正”或尺寸小而删除。

`FIX`：能从原始 RGB、原始 EXR/ID 及实例元数据确定正确归属，但现掩码有错。记录
子类：`wrong_id`（像素归错建筑）、`merge`（多栋混为一 ID）、`split`（同栋拆为多 ID）、
`missing_surface`（可见建筑面漏标）、`background_leak`（道路/植被/阴影/非建筑结构
纳入）、`raster_artifact`（细丝、孤岛、孔洞等渲染/清理伪影）。修正必须有可定位
的像素与证据，不能按预测形状绘制。

`DROP`：确认该 ID 的**全部**像素都不是目标建筑可见表面，或 ID 完全不可可靠归属。
极小、细长、遮挡或不完整本身不是 DROP 理由。

`UNCERTAIN`：RGB/ID/元数据不足以确定，保留原标签并列入二次复核；不能自动按
坏标处理。记录原因：遮挡/阴影、建筑附属物边界、实例归属、渲染异常或其他。

每条需记录 `verdict`、`error_type`、`evidence`、`reviewer`；`FIX/DROP` 须写明
像素或实例级依据。第一次判读至少 20% 双人盲审：113 例时预先选定 23 例，
A 表包含全部样本，B 表只包含这 23 例；两表互不展示对方意见。以稳定 `sample_id`
关联，另设独立裁决表，冲突逐例裁决。若只有一名审阅者，
只能形成“候选规则”，不得宣称已确定清洗标准或坏标率。

## 统计与下一门

主读数为逐层、逐 split 的已裁决 `FIX+DROP` 比率（附计数和不确定项）；伴随报告
错误子类、bbox/面积分布、跨 cell 分布、双审一致性及原始标签哈希。此 126 例是
风险富集样本，不可直接算作整个数据集坏标率；若要总体估计，需要另抽概率样本并按
抽样概率加权、以 scene 为聚类单位给 CI。

只有复核完成、错误规则冻结、对所有受影响数据按**同一规则**重建标签并版本化，
才允许立项重训 B0。旧版 EXP-0006 的 val AP 不得与新标签版本上的 AP 直接比较。
封存 test 的标签/推理在规则冻结前均不用于裁决或选择阈值。

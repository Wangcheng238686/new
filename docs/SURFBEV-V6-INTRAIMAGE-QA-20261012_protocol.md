# V6 单图物理实例清洗：只读审图轮

## 目标与边界

目标是在每张卫星图内实现“一栋可见建筑一个实例”。跨场景相同物体的 global ID 一致性不是训练标签发布门；global ID 仅可作为重叠视图和划分泄漏的离线审计线索。卫星标签仍为 visible-surface / roof-top，不是 ground-footprint。本轮不改标签、reader、split 或模型，不启动训练。形态学修补另立一轮。

以 V4-R3 与 V5-M3 各自冻结的 1,200 场 manifest 为输入。先完整枚举 M3 相对 V4 的图内 partition 变化、前景变化，再把所有发生 partition 变化的场景可视化；不能以“身份纠错已通过哈希审计”代替图内实例语义审计。六个 V4 excluded/HOLD 景的单图掩码保持不变，不因为跨场景 ID 被列为待拆错误。

另以 R3 的 489 个相连风险观测/95 个 global 为候选库存，只在 train/val 上选定可视化代表；形状阈值不能直接决定拆分，也不能证明未命中者干净。非连通误并和相连误并都要留出随机未命中抽样，以识别召回盲区。审图时允许参考卫星 RGB、重叠卫星图、UAV RGB/DeviceZ；禁止用 WorldPosition 作标签分界。

## 本轮固定判读与选择口径

- 主结果：逐场 partition delta，区分“原实例被拆”“原实例被合”“仅 ID 重命名”“前景增删”。采用全集精确枚举，不报告统计显著性或 AP。
- 伴随：改动像素、受影响旧/新 local ID、前景增删像素、RGB/掩码叠图、图边接触及相连风险形状字段。
- 样本选择：M3 全部 22 个有 action 的场景均列入审图；相连风险优先取非裁边、大面积、低填充的不同场景，另取裁边对照和随机未命中样本。先可视化，人的判读只给“拆/保留/不确定”，不能把低填充率直接写成标签。
- 判定门：用户确认明确误合并的才进入下一轮派生标签；不确定的保持原标签并列出需要的补充视角。若发现明确误拆，M3 相关 action 不可带入新版。任何规则只在 train/val 冻结，test 仅按冻结规则执行与事后独立抽检，不用于调阈值。

本轮是数据质量诊断，不是模型增益实验；不申请 EXP-ID，不产生 AP 结论。下一次物化前另写版本化规则与全量自动审计要求。

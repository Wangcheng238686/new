# SURFBEV-DISCONNECT-QA-20261012：一个 ID 覆盖多栋的规模诊断

## 结论边界

**精确可复现的是形态候选，不是物理误合并真值。** 使用 v3 派生标签、v2 空间隔离 split，只扫描 train/val 的 794 场、40,745 个实例；未读取 test、未更改数据、未运行模型/AP。

| 口径 | train | val | 合计 |
| --- | ---: | ---: | ---: |
| 任意 8 邻域非连通的 scene-local ID | 1,364 | 230 | 1,594 |
| `M2`：第二块 ≥64 px 且占总面积 ≥10% | 58 | 30 | 88 |
| `M2-strong`：第二块 ≥128 px、占比 ≥20%、两大块间距 ≥8 px | 27 | 25 | 52 |
| `M2-strong` 去重 global ID | 11 | 6 | **17** |

`M2` 总计涉及 82 个不同场景、36 个不同 global ID；`M2-strong` 涉及 47 场、17 个 global ID。同一 global ID 会在相邻场景重复出现，因此不能把 52 说成 52 栋不同建筑。强候选中 28/52 个 scene-local 实例触边；17 个 global ID 里仅 3 个有至少一幅强候选图像不触边，图边裁切增加了语义判定的不确定性。

用户亲自确认的 `19064360d2c1ae7c` 是两栋误并，属于强候选：global ID 1874325323，第二块 4,642 px、占 49.9%，间距约 33 px。强候选中也有反例：global ID 1571206454 的两块在同一屋顶结构上；global ID 1508745546 的两块是同一较大屋顶上的局部结构。其余大量候选只在图边露出不同屋顶的局部，视觉上常疑似多栋，但单幅裁边图不足以逐一确证物理归属。因此**本轮不能诚实地给出“恰有 N 个误并实例”或有意义的 Wilson 误并比例**；已确定至少存在 1 个，受控形态上界为 17 个强候选 global ID、36 个宽候选 global ID。这不是整个数据集所有误并的上界：相接屋顶的误并可能仍连通。

已对强候选中除已知正例外的全部 16 个 global ID 各看一个代表场景，并从弱候选 19 个 global ID 中抽看 16 个；抽样用于识别反例与风险，不当成全量逐例裁决。图与逐场数据见 `portable_sam2_explicit_coarse/outputs/SURFBEV-DISCONNECT-QA-20261012-R3/`。R3 形态计数和抽样由独立审计复核通过：`docs/reviews/SURFBEV-DISCONNECT-QA-20261012_independent_audit.md`。

## 下一步

先不要按连通域直接拆 v3 标签。若要构建修正版，应针对 global ID 在所有场景联合判断：不同物理建筑则重做 producer 的资产分组/实体 ID 映射，并同步生成每场 local ID、mask、bbox，随后重审 train/val/test 的物体隔离；同一建筑的分离可见面则保持单实例。当前 B0 reader 会把同一 local ID 汇成一个 mask 和一个跨两块的 bbox，这能解释潜在的检测监督异常，但本探针没有测量 AP 影响。

## 预注册后处理方法与门

对该 global ID 在 1,200 accepted scenes 的所有出现先只读清点。用 v3 的 512² raster 做 8 邻域连通域；前两大块面积至少各 128 px 且合计覆盖该 ID ≥90%，否则该场景不自动修改，并报告。卫星相机 `K` 与 `camera_to_world_cv` 已给出；用像素中心射线与 `Z=0` 平面交点计算每块近似世界 XY 中心。此地面平面仅用于跨图匹配身份，不是真实屋顶高度或 3D 标注。

用 **val 中**符合条件的所有场景的两块中心做固定初值、确定性的 2 簇聚类。放行门：至少 8 个场景；两世界中心相距 ≥20 m；各簇中心到簇均值的最大距离 ≤15 m；每场两大块必须分到不同簇，且两块各自对另一簇的距离优势 ≥5 m；每场其他连通块总面积 ≤10%。test/excluded 不参与拟合或改阈值。门不通过就不生成 v4 标签。

门通过后，在该 global ID 出现的**所有 split** 按固定两中心给组件分配身份；场景仍需通过上述双大块/不同簇/距离优势/小块面积门，不通过的场景完整保留旧 ID 并显式登记 `HOLD`，不得静默半拆。通过的场景把一个子实体保留原 local ID，另一个分配该图中未使用的最小正 local ID（要求 ≤255）；每个连通块的像素只改 ID，不增删像素。建立派生 `parent_global_id -> child_global_id` 映射，子 global ID 使用独立命名空间与稳定哈希，逐场记录 local→child global、原/新哈希及逐像素 diff。其余所有 scene 的 v3 PNG 必须逐像素不变。

### R1 失败与 R2 修订（在任何标签写入前冻结）

R1 地面平面簇半径门失败：17 个 val 双大块场景中，裁边只剩小片的场景最大投影中心偏差 26.116 m；没有生成 v4 产物。原因是**可见部分的质心**随裁边移动，而不是同一栋建筑真实位置漂移。因此 R2 将“中心标定”限于两大块均不触图边、每块占原 ID 至少 20% 的完整视图（要求 ≥5 场）；这些场景仍须满足中心距 ≥20 m、最大簇半径 ≤15 m、各块距离优势 ≥5 m。其余裁边视图不参与中心拟合，只用于固定中心的身份分配：两大块各 ≥128 px、合计覆盖 ≥90%、归属不同中心、各自距离优势 ≥15 m；不再以被裁切的可见质心距中心 ≤15 m 为门。完整视图应用时仍要求该半径 ≤15 m。此修订仅针对已由用户确认的 global ID，不外推为其他候选的自动拆分标准；R2 另立输出目录，不覆盖 R1。

### R2 独立审计失败与 R3 接线修复

R2 的逐像素语义通过，但 17 个拆分场景中 12 个新 local ID 与同场 `instances.json` 声明的不可见 local ID 碰撞；一个哈希 child global ID 超出 signed int64。R2 保留为失败产物，禁止 reader 接入。R3 仅修 ID 命名：新 local ID 须同时避开**PNG 已用**与 `instances.json` **全部已声明** local ID；新 global ID 限于正 signed 63-bit，仍和全数据已声明 global ID 做碰撞检查。物理拆分像素、适用场景、几何门及指标均不得改变；产物另立 R3 目录并复审。

主门：已确认对象的所有符合条件场景两栋屋顶分开，其他 ID 像素逐位不变、前景 union 不变。伴随：修改/保持场景数、子实体跨场景 XY 稳定性、最大局部 ID 是否溢出、v2 train/val/test/excluded 与新 child global ID 交叉性。选择口径为一次固定数据构建，无模型 checkpoint；显著性不适用于确定性逐像素契约，报告全量验证而非 CI。首次实现独立审计，固定抽样的前后图供人工检查；测试集只做规则冻结后的确定性应用，不拿结果回调规则。v4 标签尚不自动成为 B0 默认 reader，训练需另立项。

# S²DB-Net 精读 × 双流吸收设计（2026-10-22，子代理深读 + 主会话核定）

论文：Lin et al., "Urban sidewalk detection via a cross-view joint
segmentation method using satellite and street-view imagery",
ISPRS JPRS 240 (2026) 16–30（网络名 S²DB-Net）。子代理全文精读 +
逐思想映射 + 三臂设计；本文件为归档版，判据条款以各臂预注册为准。

## 一、论文机制归因（对我们最重要的读法）

+9 IoU 的双流增益由两个部件承载，融合算子本身几乎是平凡的 concat：
1. **IPT 隐式透视变换**（学习式 BEV，无位姿/深度）：+4.70 IoU；
   且**未对齐裸拼接比纯卫星还低 0.71**——对齐必须先于融合。
2. **逐支辅助监督结构**：两支各挂训练期专用轻量解码器，
   **都用最终任务 GT（卫星帧掩码）直接监督**（λ=1/3 三路等权），
   +3.46 IoU；动机是实测梯度失衡（街景支 10⁻³ vs 卫星支 10⁻¹）。
3. 体制：单阶段联合训练、无冻结——**从不要求已收敛的解码头学消费**；
   两支先被监督逼成"独立解算器"，融合只是 concat 两个合格解算器。

这与我们九次失败（全部是 warm 收敛头 + 端到端注入）不矛盾，反而
精确指出我们没测过的格子：**逐支最终任务监督下的联合训练**。

## 二、逐思想映射（要点）

| 论文思想 | 我们的对应 | 裁定 |
| --- | --- | --- |
| IPT 学习式变换 | 我们有精确度量相机+EXR 深度，显式投影严格占优；IPT 的端到端学采样=九次证伪体制 | 只取"对齐先于融合"原则 |
| 特征层 concat | 九次失败家族；但冷启动臂从未配过辅助监督结构 | 仅体制变更臂内成立 |
| **逐支最终任务 GT 辅助监督** | bev_head aux 用的是并集足迹（代理目标）——论文用最终答案；辅助监督训练得动是我们的既有证据 | **全篇最可转移** |
| 地理范围一致性 | 已是硬契约（300m 环/512 帧/zmean 数学） | 已满足 |
| 显式几何法 ST 仅差 1.2–1.8 | 供给端保持简单（几何+统计），勿再造复杂变换 | 支持现有方向 |
| 纯街景<纯卫星 | UAV 只裁决、不重建 | 支持决策级消费 |
| 指标无实例/边界口径 | 我们有 boundary AP 双口径，判据更严 | 沿用双口径 |

诚实对照：论文的第二视角直接可见目标本体；我们的 UAV 增量是探针级
量化的（ZMEAN-CONT AUC 0.663，与外观对照 0.704 相当）——非独占，
故外观消融门是生死门。

## 三、三臂设计（排序）

**设计 1（首选）WARM-BA-h 实例边界裁决臂**：post-hoc 裁决器
（逻辑回归/GBDT）逐界面输出合并/拆分决定；供给 = ZMEAN-CONT 式界面
特征（dz/带内高度分布/覆盖 + dgray 对照）；监督 = v3 干净 GT 实例
结构；基线 = EXP-0027。判据：R0-new 前置门（界面错误 ≥10%）→
净门（逐场 AP CI>0）→ 外观消融门 + 错配门 → 签名（strict-7px 与
多实例场景集中）。零基座训练、off≡single 按构造。代码落点：
`probe_zmean_cont_v2.py` 特征扩展 + 新 `posthoc_boundary_adjudicate.py`。

**设计 2（次选）G2T 边界蒸馏臂**：UAV zmean 不连续图（∧GT 边界带
门控）作教师，冻结基座特征上离线训 bev_head 式辅助头（BCE+Dice
0.05）；推理期其输出作为裁决器特征。先过供给门（DISTILL-P0 门系，
注意旧工件 ep0 R²≈0.5——卫星外观已可读大量高度信息，"UAV 独有"
是残差，sham 差分是生死门；P0 工件当时未在 docs 落判，须 v3 重跑）。

**设计 3（末选，条件启动）S²DB-inst 体制变更臂**：冷启动双分支 +
精确投影（不用 IPT）+ 逐支最终任务 GT 辅助头（λ=1/3）。仅当设计
1/2 失败且 R1G-clean 判别实验落定后启动；预注册须显式声明"体制
变更臂、非换 payload 臂"。

## 四、推荐

先跑设计 1：零干扰（构造性）+ 供给已验证（ZMEAN-CONT PASS）+
监督源已清洗（v3）+ 成本可忽略，四条件唯一同时满足者；设计 2/3
在其基建上无缝续接。

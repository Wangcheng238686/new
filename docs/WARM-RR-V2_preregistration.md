# WARM-RR-V2 预注册：决策级召回救援正式臂（2026-10-24，实施前）

依据：`docs/WARM-RR-20261024_rootcause_and_direction.md`（根因闭环 + v1
零训练原型首证：test AP50 +0.72、常量对照零增益）。v2 的目标：把主
AP 转正，并把三模态使用与归因门做成正式判据。

## 0. 固定契约

- **基座（逐位不动）**：EXP-0017 ep73（与探针族同基座保持可比）；
  全量版复验时换 EXP-0025（快照适配垫片，独立事件）。
- **数据**：CitySample v1；train 2142 / calib-fold 300（从 train 尾部
  切出，只用于超参与分数校准）/ val 459（伴随读数）/ test 459（终读
  一次开封）。评估口径 cap250+md250+通道序修复。
- **三模态强制使用**（PI 补充要求）：UAV RGB（证据解码器）、UAV 深度
  （反投影高度通道）、内外参（卫星帧投影 + 视角计数通道）——三者都
  进供给，且各有独立消融门（§3 归因门）。

## 1. 供给端（两级，v2a 先行）

**v2a 零训练精化**（v1 的三个已定位瓶颈逐一对症）：
1. **掩码量化** → 证据图双线性上采样至 512²，提案掩码 =
   (evi512 ≥ thr_m) ∧ 组件 ∧ 高度门，thr_m 校准；
2. **实例粘连** → 组件内证据峰值检测（局部极大 + 最小间距）+
   watershed 分割，一组件可产多实例；
3. **分数常数** → 分数 = 单调校准映射 P(命中GT | 证据值, 高度, 视角数)
   （train 上 isotonic 回归），提案间 NMS(iou 0.5)。

**v2b 监督提案头**（仅当 v2a 的剩余瓶颈 = 实例分离或分数排序时启动）：
输入 = 卫星帧三通道栈 [证据, 高度, 视角数]@512²；结构 = 轻量
CenterNet 式头（3×Conv+GN + 中心热图/框回归/置信度，~0.3M 参数）；
监督 = train 的 GT 实例；训练 ~1-2h GPU，calib-fold 早停。设计原则
同 S²DB 逐支监督：供给端先被监督逼成"独立解算器"，消费端只做装配。

## 2. 消费端（注入协议，全部后处理）

- 注入条件：提案与全部基座预测的 IoU < 0.3 且中心点不被任何基座
  预测覆盖（防部分重叠重复）；基座输出逐位不动。
- 每场提案上限 = 250 − 基座预测数（协议上限内）；按校准分数排序取。
- bbox = 提案掩码的外接框；segm 分数 = 校准置信度。

## 3. 判据（四要素 + 三门，test 只开封一次）

1. **主指标**：test segm AP@[.5:.95]（主）+ AP50/AP75/尺寸分层 +
   miss 计数变化 + 提案命中率（提案被 GT 命中比例）。
2. **选择口径**：一切超参/校准/头权重只在 train+calib-fold 上定并
   冻结（提交 hash），之后 test 单次终读。
3. **显著性**：WARM-RR vs 基座，逐场配对 bootstrap 10k draws
   seed 20261014。
4. **判定门**：
   - **净门**：test segm AP CI95 下界 >0（v1 现状 +0.03 主 / +0.72
     AP50；v2a 目标主 AP ≥ +0.5 点）；
   - **外观门**：常量 RGB 必须零提案/零增益（v1 已过）；
   - **donor 门**：错场景 RGB 下提案命中率与净增益必须显著劣化
     （逐场景内容归因，十次注入臂从未通过的门的 post-hoc 版）；
   - **几何门 ×2**：去高度门、去视角门各自必须显著劣化——深度与
     内外参的强制使用有归因证据，不是装饰；
   - **安全门**：false 正例增量 ≤ 提案数的 50%；AP_s 不显著回退。

## 4. 风险与对策

- 上采样掩码仍不贴（IoU 卡 0.6-0.75）→ v2b 的掩码由头直接回归；
- 校准过拟合 calib-fold → isotonic 单调约束 + 难场景分层抽样；
- 提案在 test 难分布精度下降 → 校准 fold 按场景密度分层；
- 增益仍只落 AP50 → 如实落判为"召回救援上限受掩码质量约束"，
  v2b 是否启动按预注册条款，不重跑调参。

## 5. 排程与预算

- v2a：校准 + test 终读 ~2-3h GPU（证据栈已在缓存管线内）。
- v2b（条件启动）：头训练 ~2h + 同判据。
- 全量版（v2 过全部门后）：EXP-0025 基座复验 + 双 seed + 边界精化
  二阶段（banded 4482 的 B-AP 头寸，独立预注册）。

## 6. 与既有路线的关系

- WARM-BA-H（界面裁决）：R0-new 已证界面误差仅 1.7%——该臂在 v1
  数据上正式关闭，其 zmean 特征收割器并入本臂几何通道。
- 十次注入臂证据链 = 本臂的动机章节（为什么必须决策级）；
  ZMEAN-CONT/PIXEL-CLS/EVI-DECODER/n1-aux = 供给端可行性章节。

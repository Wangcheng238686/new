## 三、失败臂重审（旧九臂结论哪些带走、哪些翻案）

1. **带走（数据无关的机制结论）**：九次消费失败的核心判读——
   "warm 收敛基座上，端到端新通路无论 payload 形式都长不到有效量级"
   （含臂 E 的无实现疑点版）——是优化动力学层结论，清洗不改变它。
   任何新纪元臂仍不得走"收敛头 + 端到端注入"老路。
2. **翻案（昨天被噪声堵死的方向解锁）**：实例边界裁决方向的阻塞项
   是"监督源（GT 实例结构）在界面处被污染"——S2 归零 + ZMEAN-CONT
   v2 过门，该阻塞已解除。
3. **重设（参照系更换）**：旧臂的全部数值判定以旧 GT 为参照，只作
   历史档案；新纪元一切对照 EXP-0024/25 的胜者（last 口径）。
   warm 筛查基建（configs/launcher/评估工具链）可复用，但双流训练
   侧需要新配对数据加载（citysample_pair 已具备探针级，训练级待接
   UEDualPreprocessor 通路）。

## 四、推荐方向：**实例边界裁决臂（WARM-BA / 后处理裁判）**

**核心反制**：九次失败的共同形态是"推理期把 UAV 信息注入特征、指望
优化器学会消费"。本方向把消费位置从特征层移到**决策后处理**：
单流基座完全不动（零干扰代价，off≡single 按构造），UAV 高度/证据
只裁决"哪些可见边界是实例边界"（合并/拆分决定）。

- **供给**：逐界面几何特征（dz、带内高度分布、覆盖）+ 可选解码证据
  对比（EVI-DECODER v2 若过门）；界面 = 预测实例对之间的可见边界带。
- **消费**：训练一个小裁决器（逻辑回归/GBDT 量级）输出"该边界处
  两预测应否合并/拆分"，作用于 NMS 后的实例装配。基座零再训练。
- **监督**：GT 实例结构（定版后干净）——预测对与 GT 的匹配关系给出
  合并/拆分标签。
- **判据（预注册四要素，收线前不得改动）**：
  1. 主指标：val 459 逐场 segm/bbox AP，裁决后 vs 基线（0024/25 胜者
     last）；合并/拆分错误计数变化。
  2. **双门**：净门（裁决后−基线双指标 CI 下界>0）+ **外观消融门**
     （只用 dgray 等外观特征的对照裁决器必须显著劣于含高度特征版
     ——否则增益不属于 UAV）+ 错配门（C1 式：换错场景 zmean 必须劣化）。
  3. **前置门**（先于裁决臂）：基线错误分解（R0-new）须显示界面型
     合并/拆分错误占错误质量 ≥10%，否则无裁决空间，方向不启动。
  4. 显著性：逐场配对 bootstrap 10k draws seed 20261014。
- **排程**：EXP-0024/25 今日收线 → R0-new 错误分解（当天）→ 过前置门
  则裁决臂训练+评估（次日）；全程与单流任务共租即可（裁决器无训练
  基座，成本可忽略）。

## 六、旧臂结论可信度审计（PI 质询 2026-10-21：失败是方法的还是数据的？）

**分层裁定：测量事实全部可信（预注册/审计/对照在案）；机制解释的
可转移性分三档。**

**A 档：数据无关，完全带走** ——(i) 冷启动融合的训练期干扰代价
（off−single −0.8~−1.7，融合梯度扰动基座，机制层现象）与 warm-freeze
的构造性消除；(ii) 零初始注入在收敛头上难以自发开启的门行为；
(iii) BEV 注入家族收敛为静态模板的**倾向**（EXP-0023 C4≈on）；
(iv) 全部方法学（归因阶梯、机制门、双检查点协议）。

**B 档：被旧数据系统性偏置，可转移性打折** ——(i) "端到端消费不可学"
的普适表述：旧 GT 20.6% 粘连实例恰好系统性**惩罚 UAV 最能提供的界面
高度信息**（真实建筑间隔的高度台阶 vs GT 说"是一个实例"——消费真
信息在这些样本上增加损失，优化器获得的是"反消费"梯度，不止是平坦
梯度）；(ii) 全部 C1 机制门 ≈0 的读数（对抗标签使内容消费更难学）；
(iii) AP75/边界带签名测试与 R0 通道归因（"+11.9 边界 oracle 与 UAV
无关"）在噪声 GT 上测得，归因可能失真。

**C 档：对噪声稳健** ——(i) 各臂"未达 DUAL_GAIN"的判定本身（对照
同 GT，方向性读数有效）；(ii) EVI/BEV 辅助监督（union 足迹掩码对
合并/拆分噪声不敏感）；(iii) 臂 E 的活性结论（适配器生长/解码器冻结
是工程事实）。

**新纪元的半份答案**：PIXEL-CLS v2 A-PASS（信息仍存在）但
EVI-DECODER v2 AP 掉 5.3 点（真实城景外观供给更弱）——**"失败纯粹
是数据的锅"不成立**：新数据同时让供给端变难。

**判别实验（低成本，两结局皆有效）**：EXP-0024/25 收线后，在新基线
上重跑一个代表性旧臂（建议 R1G 家族：warm-freeze + BEV 描述子注入，
30ep 筛查 ~2h 共租）。成功 → 旧 null 部分归因于标签噪声（论文叙事
反转素材）；再次 null → 机制结论在干净数据上确认，九次失败的最后一
个口子闭合。PI 既定计划本就包含重跑旧臂，此为其最优选型。主线（裁决
臂）不依赖此实验的真伪。

# R1C-ATTR 归因对照阶梯预注册（2026-10-17 晚）

问题：R1C（及 R1G 通路）的 on−off 净增益来自 (a) UAV 场景内容还是
(b) 融合模块参数/静态先验与冻结基座的容量交互。三个 eval 期对照切开
（纯推理，不训练，可与 EXP-0020/21 共租）：

- **C0 = on**：正常逐场评估（复用既有 rows）。
- **C1 = 错配 BEV**：场景 i 喂场景 N−1−i 的 UAV payload（v2 split 空间
  有序，倒序配对=空间最远场景；几何自洽、内容错误）。注意力/栅格化在
  错误视图上正常运转。
- **C2 = 恒定 BEV**：注意力输出（R1C）替换为 30 个 train 场景的均值输出
  图（128×128×128，训练侧收获、无 val 泄漏）；统计组通道保持逐场景
  live。R1G 版：描述子块（0:256）替换为 train 均值图，统计组 live。
- **C3 = off**：UAV-off（≡single，复用既有 rows）。

对象：WARM-R1C 筛查 last（30ep）与 EXP-0018 last（R1G 全量 100ep）。

## 判读门（预注册）

设 ΔXY = C_X − C_Y 的逐场配对 bootstrap（10k，seed 20261014，n=100）：

- **ATTR-CONTENT（内容真实）**：Δ01(segm) CI95 下界 > 0——C1 显著低于
  C0 → 通路消费场景特异内容，"注意力路由内容"叙事成立；
- **ATTR-PRIOR（先验/容量）**：Δ01(segm) CI 含 0 且 |Δ01| < 0.05——
  错配不掉点 → 增益与场景内容无关，归因改写为容量/先验；
- **中间态**：0 < Δ01 < 上述门 → 部分内容依赖，报告比例
  Δ01/Δ03（内容份额 vs 总增益）；
- **C2 细化**（在 ATTR-CONTENT 成立时）：Δ02 CI 下界 > 0 → 动态逐场景
  内容必要；Δ02 含 0 → 训练均值静态图已够，注意力只需提供静态结构。
- 附带报告 bbox 同口径（不作门，作一致性检查）。

## 边界

- C1 的错配 payload 其卫星网格仍用本场景相机（查询几何正确、内容错误）
  ——正是"参数先验可解、内容不可解"的分离设计；
- 阶梯是 eval 期证据，不替代训练级归因（如 C1-training 臂）；
- 全部结果并入 DUAL-WARMSTART-SCREEN 结论文档第 8 节。

## 修订（2026-10-17 21:00，C2 结果逼出、C4 运行前登记）

C0−C2 ≈ 0（注意力块逐场景变化无贡献）后，C1 的崩塌需归因分离——C1 错配
的是整个 payload（统计组同被污染）。新增 **C4 = 全 BEV 恒定**（描述子块
与统计组都换 train 均值）：
- **C4 < C2 显著** → 活统计组承载逐场景内容（R1CH 统计加宽的立项依据）；
- **C4 ≈ C2** → 全部增益为静态模板，逐场景内容（含统计）均未被消费。

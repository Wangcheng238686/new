# EXP-0008 预注册：双流（卫星+UAV）@512 原生从头训练，与 EXP-0007 单流 A/B

## 设计与路由说明（PI 决议，2026-10-14）

用户决议：**不经热启动筛查，直接从头训练完整双流模型**，与 EXP-0007
（单流，同协议运行中）做单变量 A/B——唯一变量 = UAV 支路的有无。理由：
(i) 512 协议下单次全量仅 ~3.6h，直接 A/B 的算力成本可承受；(ii) P1–P4
读出探针只检验了冻结特征的可读信息，联合训练能学到的信息利用方式是冻结
读出原理上测不到的；本 A/B 是对该问题的终极检验。此为对 A 路线梯队的
PI 级豁免（跳过筛查层直接双臂全量），在此登记；两臂同协议同种子，失败
臂同样按四要素关账。

## 架构（单变量约束）

- 基座：与 EXP-0007 完全相同的封存 a3sgm @512（`ue-whu-a3sgm-512-v1` 指纹
  `5305b315…` 不变——卫星支路逐字节同构）。
- 新增（仅 EXP-0008）：`ue/` 外围适配器中的 `RSPrompterAnchorDual`：
  - UAV 支路：冻结的 UAV encoder（`configs/ue_uav_encoder.py` 同款，五视角
    512² RGB → 256d 特征）+ 可训练投影到卫星 P3 通道；
  - 融合：UAV 特征按世界几何投影到 P3 网格（复用 SurfaceBEV 投影机制，
    仅几何、不含 BEV 高度聚合），与卫星 P3 拼接后经 1×1 卷积回原通道数，
    **逐通道门控零初始化**——第 0 步模型与单流严格等价（门=0 时输出恒等），
    训练是否推开门本身就是参与度证据；
  - 卫星支路权重初始化：从预训练 SAM2 全新开始（与 EXP-0007 一致），
    不从 EXP-0007 checkpoint 热启动（保持"从头训练 A/B"单变量）。
- 身份登记：`ue-whu-a3sgm-512-dual-v1`（注册表第三条目，双流实验臂身份）。

## 协议（与 EXP-0007 逐项对齐）

v2 split（SHA `17f49430…`）694/100/151、无随机增强、seed 44、GPU0–3 DDP、
每卡 batch 1、累积 2、global 8、lr 5e-4、wd 0.05、warmup 100、cosine、
100 epoch、last 口径、amp、SAVE_LAST_MODEL=1、禁早停、test 全程不读。
唯一差异：每步额外前向五视角 UAV（数据加载 load_uav=True）。

## 遥测字段（四类，预注册写死，run 后无论涨跌全部落盘归因）

1. **参与度**：逐 epoch 的门控 mean/std/min/max 与相对零初始化的漂移率
   （判读线：均值漂移 <20% → "训练未选择使用 UAV"）；流入 UAV 投影/门控的
   梯度范数；UAV 支路输出范数 / 卫星 P3 范数比值曲线。
2. **信息利用**：逐 epoch 五视角的投影贡献分布（哪几路视角被用）；
   融合增量特征的有效秩。
3. **对照**：eval 期 **UAV-off 消融**（门强制置零推理）：逐场 on/off 差 =
   训练后模型对 UAV 的真实依赖度；每 epoch 抽样场景的卫星支路输出在
   门=0 时与单流前向的一致性抽检（DDP 口径：rank0 聚合报告）。
4. **结局**：每 epoch segm/bbox mAP + 面积三分位分层 + RoI 召回；
   逐场 val 结果落盘（供 A/B 的 scene-paired bootstrap）。

## 四要素

1. 主指标：val segm AP@[.50:.95] 与 bbox AP@[.50:.95] 的
   **EXP-0008 − EXP-0007 差**；伴随：AP50/AP75、小面积分位分层、
   UAV-off 消融差、门控遥测全套。
2. 选择口径：两臂均 last epoch（各 100 epoch）。
3. 显著性：val 100 场逐场 scene-paired percentile bootstrap（10,000 draws、
   seed 20261014）；单 seed A/B 的结论边界如实标注。
4. 判定门（预注册）：**DUAL_GAIN** = 两主指标 bootstrap CI 下界均 >0 且
   幅度 ≥ +0.5 点；**DUAL_ENGAGE_NULL** = 指标无增益但门控漂移 <20%
   （训练没选用 UAV——机制归因清楚，考虑换融合形式再试一次）；
   **DUAL_USED_BUT_NULL** = 门控漂移 ≥20% 且 UAV-off 消融差显著但终指标
   无增益（模型用了 UAV 但没用对地方——归因到任务层）；
   **DUAL_HARM** = 任一主指标显著为负。各判定均配下一步动作条款。

## 勘误（2026-10-14，启动前；拉起前审计 BLOCKED 项修复）

1. **初始化方案修正**：原"gate=0 且 proj 零初始化"构成不可逃逸驻点
   （两因子乘积梯度恒零，审计员数值复现）。修正为 **gate=0 + proj 默认
   初始化**：第 0 步与单流等价性不变（0×有限=0），∂L/∂gate 非零
   （独立验证 absmax≈1.46），proj 在门离开 0 后开始学习。
2. **amp 数值路径修正**：UE 世界坐标（±1.3e5 cm）超 fp16 上限，--amp 1
   下 rasterize 的 matmul 会静默产生 inf/nan 使 BEV 坍缩。融合支路
   （encoder+投影+proj+门控）全程 autocast-disabled 以 fp32 执行；amp=1
   smoke 复验 bev_coverage=0.9457 与 fp32 一致。
3. **遥测口径标注**：gate 遥测为 rank0-only 训练步聚合（非跨 rank）；
   梯度范数、五视角分布、有效秩、逐场 val 落盘、一致性抽检为 run 后
   离线工具（从两臂 last checkpoint 重推）。

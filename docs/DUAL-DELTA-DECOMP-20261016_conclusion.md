# DUAL-DELTA-DECOMP 机制探针结论（2026-10-16）

## 问题

EXP-0010/0011/0012（及 0013）训练遥测显示门控增量范数达基座 P3 的 29%–65%
（`delta_p3_ratio`），但 val segm/bbox AP 与单流锚点持平（0010 last
0.7550/0.7317，0011 last 0.7550/0.7327，两臂彼此相等）。本探针回答：
注入幅度大而指标持平的机制原因。

## 方法

冻结诊断探针 `scripts/ue/probe_dual_delta_decomp.py`：EXP-0010 last
checkpoint（身份 `ue-whu-a3sgm-512-dual-v1` 已校验）+ 冻结快照 val 前 6 场，
CPU 前向。分解 `delta = gate ⊙ proj1x1(BEV)` 的（1）BEV 输入量纲构成与
逐通道组对 ||proj(BEV)|| 的精确贡献（leave-one-out）；（2）预注册漂移算子
与有效开度；（3）delta 空间结构（逐通道空间均值/8×8 粗分量/细残差能量占比）；
（4）跨场景相似度与与 base 的对齐。无任何训练或参数修改。

## 机制链（证据闭合）

1. **量纲灾难**：单 bin BEV 的 262 通道中，zmean/zres 两个厘米量级几何通道
   比 256 维 UAV 语义描述子大 5 个数量级。默认初始化 1×1 conv 的输出范数
   （62× base）几乎完全由这两个通道构成；语义描述子的贡献是 0.04%，
   **在数值上从未参与注入**。
2. **门被训练关死**：梯度由巨幅平滑高度场主导，gate 平衡在 ~0.002–0.015
   （有效开度 0.44%），即优化器学会了"关掉这个以原始 cm 值进来的高度场"。
   预注册算子 δ_L≈9e-5 → 官方四判定将落在 **DUAL_ENGAGE_NULL**（0010/0011
   均如此；0012/0013 中途遥测同一签名）。
3. **泄漏成分类偏置**：0.38× base 范数的泄漏中 46% 是逐通道空间常数，
   场景特异结构与 base 近正交、跨场景无一致方向——对卷积检测头功能惰性，
   AP 持平是必然结果。
4. 该结论与 P1–P4 冻结读出四连证互补：即便表示干净，cell 级密集注入也拿不到
   净增益；本探针补充了训练期机制——当前融合形式在数值上根本没有给语义内容
   参与的机会。

## 对预注册 v2.1 漂移算子的勘误建议

δ_L 分母 mean|proj_L(bev)| 被厘米通道污染（≈21.25），"无尺度歧义"的声明
不成立：同一物理开度在归一化 BEV 下会读出完全不同的 δ 值。所幸本例中
ENGAGE_NULL 恰是正确标签（门确实关了）。建议收尾归档时登记：算子应改为
尺度不变的有效开度 Σ|gate⊙proj|/Σ|proj|（本探针已实现并落盘）。

## 方向决议（提交 PI）

- 单纯归一化 BEV 后重跑注入臂只能修复遥测读数，P1–P4 已预测 AP 仍将持平，
  不作为新方向。
- 推荐：UAV 几何先验换轨——训练期高度蒸馏（教师=归一化 zmean，单变量
  A/B 对 EXP-0009，推理免 UAV）+ 边界带掩码精化（攻击 R0 的 segm +11.94
  oracle；可后续以 UAV 高度条件化构成 eval 期双流）。详见会话报告。
- 备选：RoI 级交叉注意力条件化（softmax 免疫量纲问题；bbox 侧上限 +1.8）。

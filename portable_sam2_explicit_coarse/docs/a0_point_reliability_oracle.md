重要限制：复用生产无效点路径意味着将点 embedding 置零，并非从 decoder
attention 中彻底删除 token；全 chunk 全无效时生产代码才去掉 point prompts。
因此结论只覆盖当前模型的标签屏蔽路径，不能外推为所有可靠性门控无效。

裁决：完整 mAP 及图像配对 bootstrap 若无正向证据，不启动可靠性学习器。
若有收益，再做每 ROI 等数量、同符号随机屏蔽对照；在通过效用及随机对照前
不能把结果当作可学习性证明。验证集已用于权重选择和开发，不是独立测试集。

## 本轮裁决

当前冻结 A0、现有 label=-1 zero-token 消费路径下，不晋级可靠性学习模块。
理由不是错误点不存在，而是 GT 精确识别后的总体增益很小且对 raw 的 CI 跨零；
学习器还有误判成本，现有证据不足以承担新模块训练与论文贡献声明。
这不是等效性检验，也未证明所有连续可靠性门控或重新训练的模型都无效。
两格/多个对比属开发性探索，未做多重比较校正；单随机控制不能代表所有随机种子。
未启动新训练，未改生产架构，未进行本轮独立子代理审查。

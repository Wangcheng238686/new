日期：2026-09-07（v0.1 否决；v0.2 五项修正；v0.3 收紧 R1 规格；
**终审通过核心设计**，开工前修正 DDP 归约表述并补配置指纹与采用
条件两条实施约束）。用户裁决：论文只报告**一个完整方法**；期望

## 0.5 已记录的探针结果（2026-09-07，D6 best 权重、全 627 图）

## 1. 证据清单（v0.2 修正版）

1. **监督行为（实测，解释仍开放）**：实例匹配诊断实测正确像素 76%
   的 delta 背离 GT（mean −0.14）、带内错误仅 8.4% 翻转。"监督错配"
   （v1 的 BCE 形态导致该行为）是**待验证的主假说**——最终 mask
   loss、共享卷积等亦可能参与；R1 实验本身即对该假说的检验。
2. **辅助损失的真实形态（v0.1 表述有误）**：v1 的辅助 BCE 作用于
   `search_support ∩ (raw 边界带 ∪ GT 边界带)`（`boundary_loss` 的
   `loss_support`），**不是**支持域全像素。
3. **可达域（两版口径都报）**：v1 并集口径错误像素支持域覆盖率 23%；
   v2 实例匹配口径 29.4%（即 ~70.6% 未覆盖），后者基于 100 图子集 +
   推理期 ROI + 栅格化近似，有口径局限。
4. **通道下游 headroom（联合干预，非 P2 预算）**：+0.0154 来自旧权重
   上"实例 GT 画布 + 门控 α=1.0"的**联合**干预，是通道容量证据，
   **不是** P2 可兑现的收益预算。
5. **PE 适配（精确数字）**：全验证集 D5-B−D5-A 两轮 best 配对差
   +0.0105 / +0.0042；E14 口径 +0.0089 / +0.0002（第二次近零）。
   方向一致但幅度不稳定，"稳健复现"表述降级为"方向一致的初步证据"。
6. **权重口径勘误（非通用事实，按格核验）**：本轮 9 臂中
   `last_checkpoint.pth` 均为 **E14**（训练 15 epoch，E15 末轮权重未
   落盘）；best 权重**不全是 E12**——D6 复跑的 best 即为 E15（按格
   核验 manifest 的 epoch 字段）。历史 E14 结果保留为辅助比较；
   **新实验必须显式保存真正的末轮权重并在评估时核验 epoch**。

## 2. R1 精确规格（v0.2）

**目标**：辅助监督只在"需要纠错/不确定"的区域推动 delta，正确高置信
区域施加残差保持约束。**能力声明（诚实版）**：重加权 BCE 不保证
"纠正后停止推动"——若需有限目标，用 R1b 变体（ hinge 形目标），
本轮默认不做。

```
选择子（全部基于 detach 的量，每步前向重算）：
  raw_d   = raw_logits.detach()
  band    = search_support ∩ (raw 边界带 ∪ GT 边界带)   # 与 v1 的 loss_support 相同
  err     = (raw_d >= 0) != gt_bool                     # 预测错误像素
  lowc    = raw_d.abs() < margin                        # 低置信像素（margin=1.0，logit 单位）
  error_region = band & (err | lowc)                    # 推动区（与 band 显式相交）
  keep_region  = band & ~err & ~lowc                    # 保持区（与推动区互斥；无 GT 带例外）

损失（逐 ROI，两类区域分开归一）：
  L_err(roi) = sum(BCE(raw_d + delta, gt) × error_region) / max(|error_region|, 1)
  L_fix(roi) = sum(|delta| × keep_region) / max(|keep_region|, 1)
  空区域 → 该项为可微零（分母 clamp 到 1，分子为空张量和）；
  L_aux = mean over {band 非空的 ROI}( L_err + λ·L_fix )，λ=0.1；
  band 为空的 ROI 不进入平均的分子与分母；
  **DDP 归约（复用现有实现，不重建）**：沿用
  `_materialize_p2_boundary_refiner_loss`（train_rsprompter_fusion.py）
  的模式——保留本地可微分子，仅对 **detached** 的全局有效 ROI 数做
  all_reduce；本地损失 = w_aux × local_sum × world_size / global_count，
  DDP 梯度平均后即全局有效 ROI 均值的梯度；global_count 为 0 时返回
  可微零；空 rank 传"分子 0、计数 0"，**不**先算 0/0。日志用的全局
  分子另行 detach 后归约。**禁止**对带梯度的分子做普通 all_reduce。
  训练总损失中 L_aux 以固定 w_aux（=对照臂 A1 的 0.05）进入。
```

能力声明：重加权 BCE 不保证"纠正后停止推动"；若需有限目标另做
R1b（hinge 形），本轮不做。anchor 点、搜索带、网络结构、输出参数化
（beta×Δ×tanh）全部不动。

**配置与 checkpoint 契约（含指纹兼容）**：loss 模式（`boundary`→新键
`correction_keep`）、margin、λ 经环境变量进入 config 并嵌入
checkpoint 的 model_config（沿用 P2_* 管线模式）。**不得**给未启用 R1
的旧配置无条件追加新字段——即使前向不变，新增字段也会改变架构指纹。
验收三连：
1. R1 关闭：旧配置解析、旧 checkpoint 加载、**架构指纹逐位不变**；
2. R1 开启：新损失设置真实保存进 checkpoint 的 model_config；
3. A1/A2 除损失设置外，模型参数初始化与**前向行为一致**（DRY_RUN
   差分 + PREFLIGHT 断言）。

## 3. 三臂对照设计（第一轮，不加 R2，**场地=NWPU dev 协议**）

**迭代场地（2026-09-07 用户裁决）**：矩阵交付在 NWPU，P2-v2 迭代直接
在 NWPU 上做，WHU 不再新增训练（已有结果仅作参考系）。

**NWPU dev 协议**：520 训练 / 130 验证全量（无子集，选型集=报告集）；
**100ep**（cosine 压缩、warmup 100 步、lr 5e-4）；4 卡 × batch1×
accum2；EMA on（raw 选型）；seed 44；fi 契约 + rot90 与否随首轮统一
决定；单臂 ~4.5h（162s/epoch 实测）。协议家族与最终 600ep 一致、仅压
长度，相对比较可迁移；三臂差异包含方法效应，**不能**当作运行间噪声底。
运行噪声须在初筛后对同一固定臂独立重复估计。

| 臂 | 配置 | 用途 |
|---|---|---|
| A0 | **D5-B 配方移植 NWPU**（PBM，PE 适配，无 P2）——NWPU 上无现成对照，**新跑** | P2 总增益的分母；三臂同协议同 seed 的严格组内配对 |
| A1 | A0 + **原版 P2**（β=0.10, Δ=0.50, w_aux=0.05） | **新消费端下原 P2 的效果——从未被测过**（D2fi/D3 的 Full 臂均产生于 PE 冻结时代） |
| A2 | A0 + **P2-R1**（§2 规格，其余同 A1） | 监督改动的增益 |

- G1-G4 全部在 NWPU 130 图验证集上裁决；
- A1−A0 与 A2−A0 各自配对解读；A2−A1 隔离监督改动；
- 历史 WHU 数字仅作跨数据集参考，**不得**称为配对复现；
- G1-G4 按 §0 执行；两轮复跑在首筛出候选后进行。

## 4. 工具验收（实施前必须补齐，不再称"全部现成"）

1. **p2_off 干预**：prompt_switch_probe 增加 P2 关闭模式——delta≡0、
   挖点与画布回退 raw（**不是** drop_dense）。**验收为程序断言，非
   说明文字**：干预生效时逐 batch 断言 `refined == raw`（bitwise 或
   allclose）、`delta == 0`、挖点输入与画布输入均为 raw 侧张量；
   不要求与独立训练的 A0 数值一致。
2. **checkpoint epoch 核验**：fulleval 汇总强制记录每格 epoch；
   **新实验 wrapper 开启末轮显式保存**（trainer 若无 E15 落盘路径则
   保存 final checkpoint 并命名区分），报告用词按实际 epoch 写。
3. **bootstrap 输入规格**：predictions.json → dt_records 转换脚本 +
   共享 GT/images 导出 + 每侧执行 manifest 身份校验（沿用已审计的
   强通道）；转换正确性用 --resamples 0 复现点估计验收。

## 5. 分支逻辑（修订：不自动跳转，失败结论受限幅）

- R1（A2）机制转正且 ≥A1 → **初筛候选**；配对复跑后定采用。
  **采用条件（显式）**：最终采用 A2 需同时具备 (a) **A2−A0 的正向
  任务收益证据**与 (b) **A2−A1 的监督改动增益证据**；若 A1 已有效而
  A2 无额外收益，**优先采用较简单的 A1**。
- R1 转正但 AP 不涨：**不**推断"支持域是次级瓶颈"——用 p2_off 探针
  + 画布内容量化实际定位。
- A1 与 A2 都无效：**仅说明该支持域、残差帽（±0.05）与训练预算下，
  两种监督未产生可确认收益；不能排除监督仍是瓶颈**。混入幅度混同：
  raw 错误像素 |raw|>0.05 者无论监督优劣都不可翻转——因此**必须同步
  记录支持域内错误像素的可翻转比例**（遥测沿用 wrong_flippable 口径），
  防止把"修不到"误判为"学不会"。
- A1（原 P2）若在新消费端下已有效 → R1 只需打赢 A1，故事更简单。
- R3（画布渲染器）需**另立设计文档与独立证据**，本轮不预设、不因
  A1/A2 失败自动升级。

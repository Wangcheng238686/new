# a3r（A3 + mask 损失爬坡）matrix300 结果 —— ⚠ 本机（machine2）执行

日期：2026-09-10 启动 / 09-11 完赛。**本实验为 machine2 执行**：四卡 RTX 4090，
matrix300 协议，seed 44。与 lthpc 任何同名臂直比均违反双机协议（+0.011 机器
偏移，见 machine_sync_protocol.md §3）；本文所有对比均为本机内配对。

## 1. 定义与动机

- **a3r = a3 + 平滑 mask 损失爬坡，训练器侧唯一改动**：mask 族损失
  （`loss_mask / loss_shape_prior / loss_decoder_tail / loss_p2_boundary_refiner`）
  权重前 100 epoch 线性 0.2→1.0（`MASK_LOSS_RAMP_EPOCHS=100, START=0.2`），
  之后恒 1.0；检测族损失与学习率全程与 a3 完全一致。**构建的模型与 a3 逐位
  相同（同架构 fingerprint）**。
- 动机（2026-09-10 定）：A3 家族病理 = best segm 落在进度 ~15%（lthpc A3
  bestS@E45，当时 bbox 落后自身收敛 0.068），mask 分支早锁定弱期检测器后
  阴跌。假设：压低早期 mask 梯度占比 → mask 分支适配成熟中的检测器。

## 2. 协议与 evidence

- matrix300：300ep、val/5（四 rank 分片验证）、segm/bbox/composite 三选模、
  seed 44、4×1×2（有效 batch 8）、AMP。
- 训练日志：`vhr10_p2v2_matrix300_a3_pbm_udprk64_maskramp100_tr1.0_va1.0_20260910_214008_pid21638.log`
- checkpoint + evidence：
  `${CKPT_ROOT}/ablations/vhr10_p2v2_matrix300_a3_pbm_udprk64_maskramp100_tr1.0_va1.0/`
  （bestS@E35 / bestB@E225 / bestC@E230 / last@E300，各带
  `inference_*_vhr10/`：metrics + dt/gt_records + manifest）。
- ramp 生效三重验证：逐 epoch 调度日志（`Epoch N schedule: mask_loss_ramp=
  0.200→…`）、训练进程 env、早期 segm 被如期压低（E5 -0.079 vs a3）。

## 4. 与本机 a3 配对（a3 亦为本机完赛版 E300）

| 口径 | a3（本机） | a3r（本机） | Δ(a3r−a3) | 判读 |
|---|---|---|---|---|
| bestS segm | 0.6732@E75 | **0.6868**@E35 | **+0.0136** | a3r 主要收益 |
| bestB bbox | **0.7098** | 0.7088 | −0.0010 | **打平（噪声内）** |
| bestC composite | 0.6842 | 0.6868 | +0.0026 | 噪声内 |
| last segm | 0.6531 | **0.6614** | +0.0079 | 边缘正 |
| last bbox | 0.7039 | **0.7053** | +0.0014 | 打平 |

**定性结论**：ramp 修住了 A3 家族"早峰后阴跌"病理——a3 的 segm 从 E75 峰
0.6732 阴跌至 E205 的 0.6501；a3r 后期稳定 0.66+ 且 bestB/bestC 后移至
E225-E300（检测器成熟后联合最优）。分阶段配对均值：E1-45 segm −0.011
（压制代价期）、E105-205 +0.004（收益期）。

**口径注记（2026-09-15，用户质询补记）**：本机 a3 行为 **1×1×8 单卡形态**
（四臂并行期，一臂一卡），a3r 为 **4×1×2 四卡形态**——协议 §2 裁定两形态
梯度数学等价（dev100 双机验证，残余并入机器偏移标定），但**同机纯拓扑 A/B
从未实测**，故本表 bestS +0.0136（单 seed）不能排除拓扑残余贡献。打平类
结论与轨迹形态结论不受影响（常数性偏移造不出 a3 阴跌/a3r 稳住的形状差异）。
**EXP-0002**（a3-K64 4×1×2 复跑，本机）将以同机同形态配对替代本表，并顺带
给出拓扑残余实测（本行 udprk64 与 udprk64_form4x2 之差）。

**ramp 时长问题关闭**：全权重后期（E100-300）从未接近早峰 0.6868，平台
饱和；延长至 200ep 无证据支持（2026-09-11 判定）。

## 5. ⚠ bbox mAP 专项说明（用户问询记录，2026-09-15）

"a3r 严重伤害 bbox mAP"的表象需拆解归因，**配对数据不支持 a3r 特有伤害**：

1. **a3r vs a3 配对：打平**（bestB −0.0010 / last +0.0014，均在噪声内）。
2. **bestS ckpt 的 bbox 0.6608 是早峰权重的固有属性**（E35 检测器年轻；
   a3 的 bestS@E75 bbox 也仅 0.6885）——segm 选模口径，非 ramp 伤害。
3. **真实缺口在 A3 家族层面，a3 同样携带**：本机四臂 bestB 为
   p 0.7195 / pb 0.7182 / a0 0.7187，而 **a3 0.7098、a3r 0.7088**——两者
   均低于基线 ~0.009-0.011，差值刚过 0.008 噪声标尺（各自单 seed，未确认）。
   归因候选：UDPR 尾存在引入的检测侧干扰，或 run 级噪声；**待 seed 复刻或
   a3 无尾对照判定，暂不下结论**。
4. 与 lthpc A3 bbox（0.719-0.724）之差大部分为 +0.011 跨机偏移（不作数）。

### 5.5 与 lthpc A3 记录（box_prompt md 表）的跨机对表拆解

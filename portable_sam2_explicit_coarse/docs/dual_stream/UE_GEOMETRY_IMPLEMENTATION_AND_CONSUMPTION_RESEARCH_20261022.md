# 几何构建、消费与可验证增益：代码核查及文献调研

## 结论

不能将现状归为“正确几何完全没被消费”。数值和输出干预证明它改变了计算；固定检查点未展示正确字段的额外净优势。
“正确几何”目前只是与样本正确配对的深度，经特定压缩/投影/读取得到的四字段；尚未认证它是对应卫星目标表面的正确、完整表示。

代码未发现新的cm/m、camera-Z/射线深度或重复RGB归一化错误。本轮确认了一个需要修正/对照的表示风险：先按每像素最近UAV已观测表面取值，再在RoI读取时无条件双线性混合几何。两步的表面假设不一致。
此外，消费模块具有独立卫星query适配路径，已由四格诊断确认其对当前净收益的重要作用。这是归因混淆，不是几何有用的证明。

因此当前优先顺序是：认证表面对应 → 保留不连续几何 → 让几何差异参与已有解码 → 以内容控制核定净收益。不能承诺修一个融合算子就必涨。

## 1. 逐环节裁决

| 环节 | 核查结果 | 结论边界 |
|---|---|---|
| 读取深度与相机 | EXR R camera-Z，深度及平移cm→m，CV坐标约定 | 内部一致不替代渲染配准证明 |
| 投影/目标表面选择 | 每卫星像素选择离卫星最近的UAV已观测点 | 未被UAV看到的卫星遮挡物无法参与选择；不是完整可见性认证 |
| 几何表达 | 高度、图像方向高度差dx/dy、近表面视图数 | 属于观测表面描述，不含实例身份，不等于完整三维形状编码 |
| RoI读取 | q/fields双线性读取，fields按支持加权归一化 | 可在不同高度表面之间造出平均值，支持归一化不阻止这种混合 |
| 下游消费 | 新卷积同时读卫星query与几何，conv_s0处加残差 | zero仍可新增卫星适配；已证明几何影响输出，未证明其净增益 |
| 训练动力 | 原mask/UDPR损失经过冻结解码器回传 | 能驱动新增模块；也允许优先学习更容易的卫星适配，未有证据要求立即增加边界loss |

额外坐标注意：原image/high-res特征按RoI重复，新增分支做显式RoI局部读取，而最终mask按roi_local解释。不能仅凭形状匹配就认定坐标语义相同，也不能直接裁剪原卫星路径来“修复”；那会改变封版模型。dense prompt若以后尝试，应遵循现有full-canvas paste/PE合同，不能把RoI32²直接当全图32²加入。

## 2. 新增采样审计：跨高度混合确实存在

读取原native完整val记录，均匀取索引[0,65,130,196,261,327,392,458]，对应点163/472/704/933/1173/1432/1699/1777，不按AP选图。
按实际检测bbox及原128² RoI网格复算采样。材料邻居定义为：有效且归一化双线性权重≥5%；至少两邻居才计算跨邻居高度差。
该权重阈值是探索性诊断，用于排除0/极小权重被计作混合；不是预注册模型阈值。

| 样本位置 | 有支持采样数 | 混合邻居高度差>2m | >5m | 插值高度与最近像素差>1m |
|---|---:|---:|---:|---:|
| 全部RoI网格 | 2751733 | 14.78% | 10.31% | 10.53% |
| GT实例边界2px邻域 | 580495 | 31.60% | 25.47% | 25.34% |

边界由每个独立GT的形态学带取并集，避免建筑接触边界在前景union中消失。采样计数可因RoI重叠重复，不是整图像素比例；2px诊断带不是Boundary AP带。
NumPy复算与PyTorch同一grid_sample公式逐样本最大误差约1.14e−13米（float64校准），核对的是公式，不认证真实表面。

**可确认：在边界附近，现有读取经常把差异较大的高度混合。不能确认：这些邻居一定属于错误物体，或这项混合解释了全部AP差额。** 高度差是表面不连续代理，不是卫星camera-Z差或表面ID真值；陡斜面也可能触发。

原始结果：`/data/wangcheng/checkpoint/ue_native_sampling_audit_20261022/summary.json`；源码`scripts/probes/ue_native_sampling_audit.py`。只读CPU审计，无训练/推理权重变更。

## 3. 文献能支持什么

### Multi-View SAM（WACV 2024）

[原文](https://arxiv.org/html/2311.00134v1)。将多视角深度预测作为dense prompt送入SAM风格语义解码器，证明深度可以帮助2D分割；其SAM冻结主要涉及编码器，解码器参与学习。不能将它视为冻结我们整个解码器后拼几何就会涨的证据。
借鉴：几何需要变成解码器可理解的任务特征；若只在尾部弱适配长期无效，dense prompt是后备方向，但不应现在同时切换入口和解冻范围。

### DeepViewAgg（CVPR 2022）

[原文](https://arxiv.org/html/2204.07548v2)。对3D点的多视角图像特征聚合，利用距离、视角、局部密度/遮挡等观测属性；图像分辨率变化影响性能。
借鉴：保留来源表面与观测质量，再选择/聚合。其目标是3D语义分割，有3D扫描，不认证我们的卫星可见性，也不证明我们必须采用同一注意力。

### CMX（RGB-X语义分割）

[原文](https://arxiv.org/html/2203.04838v3)。在已对齐的多模态表征间做校准和融合，考虑不同模态噪声与互补。
借鉴：几何需要单独编码、校准其可靠性；不能把原始数值拼接等同于已获得互补语义。CMX不解决我们的跨视角对应，不能照搬其多尺度架构作为保证。

### BEVDepth（AAAI 2023）

[原文](https://arxiv.org/html/2206.10092v2)。显示下游检测可在深度不理想时仍有成绩，单一下游任务分数不能认证几何；高质量深度与监督有作用。
区别：我们已有测得深度，当前不应因此再加一个深度预测头；须先确认变换后的目标表面与消费表示。

以上是相邻任务支持，不是五UAV+强卫星单类别实例AP必涨的证据。本报告提出的差分残差是基于本项目混淆设计的工程假说，不宣称来自上述论文的已验证方法。

## 4. 推荐的最小改进：只保留一个入口

### A. 先修几何读取合同

- 保留投影点的真实卫星camera-Z、支持及来源/近表面一致性，避免只剩高度后无法判断表面冲突。新缓存单独版本，不覆盖既有缓存或进行中的任务。
- 首个可解释实现对原始几何用最近有效采样，避免跨表面平均；它可能有量化/别名代价，不能称为普遍最优。
- 如果后续需要平滑，只在可信同表面/连续深度邻域归一化插值。不能把最小z的四邻域点统一扩张到整个边界，避免另一种前景膨胀。
- 高度差/几何不连续与未知支持分开表示。未知不能当0米地面，跨表面高度差不能直接当平滑表面法向。
- 绝对高度可保留为粗上下文，局部相对高度/不连续用于形状描述。归一化尺度只用train统计或固定物理量，不能用val/test标注校准。

### B. 改消费约束，避免独立卫星残差冒充UAV贡献

保留现有单个conv_s0残差入口、原mask解码器及UDPR，提出共享小模块的几何差分残差：

```
Δ_geo = H(Q, G) − H(Q, 0)
F_new = F_base + α × M_valid × Δ_geo
```

Q是冻结卫星表征的局部条件，H两次调用共享权重、坐标和确定性运算。
G=0时增量严格0；无支持时严格0。消除当前可独立存在的H(Q,0)卫星残差项，仍允许卫星上下文选择如何使用几何。
只将α零初始化，H的几何通路不能也全部零初始化，避免α及上游均无梯度。训练中如有dropout，两次调用必须共享随机掩码或禁用；首版沿现有无dropout小卷积。

**关键限制：** 这只提供归因约束，不保证几何有用；非零常量G仍可能使H实现卫星适配。不能用“置零降分”来证明成功，因为它是结构强制结果。
必须保留同结构、同预算的非零常量字段训练控制（固定train统计，支持一致），才能检验空间几何超出这种条件适配的价值。此控制不叫彻底无UAV，支持独立贡献另计。

这一步不新增后处理修边头，不改变检测框/分数，不同时切到dense prompt、增加几何encoder骨干和新loss。

## 5. 开发顺序与验收标准

1. **对应门：** 固定少量train/val样本核查源RGB-depth同表面、实际相机投影、屋顶/立面/地面邻接及卫星标注。真实卫星深度若可补渲，仅作离线可见性诊断；实际模型不能依赖部署时不存在的信息。无卫星深度时明确“无法认证”而不虚构真可见性。
2. **表示门：** 最近/同表面采样不制造跨深度平均，未知支持不变，原相机单位/像素中心合同通过；原始高度混合审计下降只是工程指标，不代替AP。
3. **只实现一条几何差分残差。** 原单入口和原loss不变。未验证前不扩展入口、不追加边界loss；最终mask监督已可回传。
4. **内容门：** 同初始化/预算比较真实几何与固定非零常量字段，除对卫星净收益外，内容差也需正向、可重复；正确几何须优于合理的空间内容扰动，披露分布外限制。zero恒等仅作工程门。
5. **任务门：** 以Mask AP为主要任务结果，Boundary辅助解释。检测被冻结，bbox不涨属预期。若真实字段不优于常量，或只提升边界而Mask不稳，不宣称整体实例增益已实现。
6. **停止门：** 若有限对应审计发现系统性错误，先修对应；若观测正确但正确内容仍无优势，停止堆同类融合。dense prompt/小范围解码适配是之后可检验的后备假说，不能现在同时上来掩盖原因。

修采样与改消费是两个不同干预；工程阶段先分别过门。正式实验若需要归因，应分开对照，不能把组合上涨全归给其中一项。此处是研发建议，未开始新训练，不修改正在运行的矩阵。

## 6. 何时才可以说“几何带来了收益”

必须同时满足：观测对应可信；几何内容的任务增量超出卫星适配/常量条件；完整任务指标有可重复的净收益。
消除一条捷径、让梯度经过几何、三维可重建、zero干预掉点，均不足以单独成立。

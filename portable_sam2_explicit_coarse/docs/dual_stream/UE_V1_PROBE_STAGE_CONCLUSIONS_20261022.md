# v1 探针阶段结论与遥测核定（2026-10-22）

## 范围及主要结论

本报告读取时间：2026-10-22T08:12:57.068857+00:00。主要判断使用完整459张 test。原八臂均完成E10/2670次更新及测试，19项推理完成17项，15项配对分析完成11项；early/contextual的独立常量RGB训练对照尚未完成。因此这是已完成证据的阶段总结，不能替代十臂最终验收。

**在当前固定训练和v1测试中，几何字段训练对照支持小幅内容收益及分割净收益；尚未证明正确局部空间几何是必要原因，也未证明正确配对的 UAV RGB 外观能够稳定提高整体 Mask AP。** 原始RGB分支并非没有注入，而是注入后没有形成净收益。归一化修复了幅度条件，并产生正向净收益，但其RGB内容归因弱于几何路线。

## 1. 固定评价合同

- 冻结EXP-0017 E73整个卫星网络，含SAM2、检测器及UDPR；新增模块与UAV LoRA训练。所有路线固定E10 last，无EMA、无test选epoch。
- 2142 train /459 val /459 test；测试集44988实例。FP32、原检测scores、maxDets250、coarse64。全部已完成比较的GT、检测框/类别/分数一致，bbox AP固定为68.5429。
- AP数值下表按0–100报告；Δ为百分点（pp）。500次配对图像bootstrap，seed20261021，名义95%区间。单训练seed、空间相关及多路线探索未被该区间覆盖。
- Boundary AP按min(mask IoU,boundary IoU)匹配；内边界带宽为图像对角线2%/1%，512²约14/7px，不能解释成2/1px轮廓容差。
- 预先明确净增益参考为Mask AP至少+0.2pp且区间下界>0；当前两条约+0.18pp的路线低于此参考，但不能因此否认小信号。
- 部分训练发生一次原因未明的进程中断，按公共已完成epoch恢复并显式重置后续轮随机种子；不是逐位连续训练复现。详见原固定协议和恢复记录。

## 3. 内容是否真正被利用：匹配训练对照

| 训练内容比较 | ΔMask pp [95%区间] | ΔBoundary 2% pp [95%区间] | ΔBoundary 1% pp [95%区间] |
|---|---|---|---|
| 真实RGB−常量RGB | +0.0884 [-0.0126, +0.0814] | +0.0031 [-0.0572, +0.0801] | +0.0093 [-0.0314, +0.0880] |
| 归一化真实RGB−归一化常量RGB | +0.0615 [-0.0244, +0.1124] | +0.0211 [-0.0322, +0.1323] | +0.0690 [+0.0519, +0.2485] |
| 原生几何−原生字段零值 | +0.2705 [+0.0706, +0.2980] | +0.2446 [+0.0988, +0.3446] | +0.1757 [+0.1735, +0.4408] |

- **最强内容证据：原生几何−零字段。** 两者保留相同卫星query、UAV观测支持和适配容量，四个几何字段组带来Mask+0.2705pp且三项区间均正；这支持深度几何内容的贡献。零字段对照仍含UAV观测支持，不能称为纯卫星。
- 原生分支没有RGB编码器；字段为相对世界高度、横纵邻域高度差、近表面视角计数。不能据此声称RGB有效，也尚未拆分四字段各自贡献。
- 归一化路线在更严格Boundary 1%上出现RGB内容正向证据，但Mask及Boundary 2%区间跨零。因此可说“部分边界内容证据”，不能说RGB整体增益已确认。
- 推理干预进一步限制RGB解释：unit固定权重正确RGB Mask AP=64.7289，常量RGB=64.8294，donor RGB=64.7345。正确RGB未优于这两种干预。donor只置换RGB并保留目标深度/位姿，不是完整错误配对RGB-D，其分布不一致也需考虑。
- 原始RGB固定权重正确输入优于donor约0.0849pp，但该模型仍低于卫星基座；输入依赖与净收益必须分别判断。
- early/contextual匹配训练对照待完成，不将单次推理constant当成独立训练对照。

## 4. 遥测字段及解释纪律

| 字段/审计 | 实际含义 | 能支持什么 | 不能支持什么 |
|---|---|---|---|
| alpha | 无约束可正可负的残差标量；不是sigmoid门控开度 | 残差方向和幅度参数已学习 | 小alpha不等于分支关闭；负值不等于出错 |
| source_delta_rms | 乘alpha前学习残差的RMS | 残差数值尺度 | 不是物理深度、不是信息量 |
| applied_delta_rms | 实际alpha×残差RMS | 分支确实向接收特征注入 | 不保证语义正确或指标变好 |
| base_rms | 注入处原接收特征RMS | 与applied共同判断扰动强度 | 不同入口数值不可直接比较 |
| applied/base | 同一次调用的RMS比值，离线计算 | 相对扰动强度 | 不是信息占比/解释方差 |
| support_fraction | RGB为128²候选格支持；原生为512²观测像素支持 | 该表示是否有观测 | 不是GT实例/轮廓覆盖；两族不能直接比高低 |
| rois | 最后一次mask head调用的RoI数 | 本次RMS计算范围 | 不是整图检测数 |
| grad_norm | 累积梯度unscale后、clip前总范数 | 优化有梯度，监测数值异常 | 不是UAV内容有效性证明 |
| loss/latest_forward | 最后microbatch/最后mask调用 | 当前一次样本数值 | 不是epoch平均loss |
| amp_scale | AMP动态缩放状态 | 数值训练诊断 | 不能单独判断任务收敛 |
| LoRA梯度/参数变化 | 新分支梯度可达且有更新 | 接线/优化路径成立 | 不证明学习了可迁移外观 |
| 完整卫星state SHA | 参数及缓冲区不变 | 排除基座训练漂移导致的收益 | 不证明几何标定正确 |

## 5. 量纲、对齐与数据结论

- 已核对camera-Z EXR的R通道，深度和外参平移均由cm转m；RGB通道与均值方差链路未发现重复归一化。学习特征RMS大不能直接认定cm/m错误。
- test459候选缓存来源/矩阵回环审计通过，原生缓存来源/范围/无效位置审计通过。内部代数回环证明链路自洽，仍不能替代独立的外部像素级标定/遮挡准确性。
- 旧候选每4×4像素格最多8个token、每视角最多2个；固定32图边界诊断中，格有候选约88%，但同格保留点在1px邻域仅约64%。存在细节丢失的可能；表示、查询和算子同时变化，尚不能将原生收益唯一归因于分辨率。
- 原生表面是五视角可观测点在卫星投影下取近表面，可能包含屋顶、立面及地面；不是屋顶标签、完整三维重建或严格可见性认证。
- v1 split存在明显密度偏移：train/val/test平均每图约58.9/32.6/98实例。基座val Mask85.46→test64.55；当前小分支无法承担修复整个分布差异。不能将旧split热启动结果当作新split正式泛化结论。
- 检测框和分数被冻结，bbox指标不变是合同结果；本轮不能改善漏检候选或检测排名。三维信息丰富不保证经当前有损表示、有限候选与冻结解码器后保留为可消费证据。

## 6. 下一步方向与停止条件

1. **保留原生高分辨率深度几何为已获支持的最小参考路线。** 深度→世界点→真实卫星相机投影→四字段及支持；现有卫星RoI query与局部几何共同产生一个残差，在既有SAM2高分辨率解码路径消费；保留UDPR，不新增尾部修边头。
2. **RGB下一步只检验“读取和消费”，暂不扩展多入口全FPN融合。** 已启动的独立S²DB机制探针固定比较：固定/局部可学习读取 × 归一化线性残差/卫星query与UAV局部卷积拼接。匹配常量及零聚合训练对照区分RGB内容、几何支持和新增容量。不能因为某个test点值高临时换路线。
3. **辅助监督单独判断。** 当前独立协议固定D分支比较aux 0/.1，利用卫星掩码并集在实际投影锚点支持处做BCE，辅助query detach；无新增UAV人工标签、无新增边界loss。它是机制假说，工程通过不代表收益。离线主/辅梯度余弦及独立预测内容诊断检查冲突/捷径。
4. **判定看三层证据：** 注入与梯度成立；正确内容在匹配训练控制及输入干预下有可解释依赖；相对卫星有测试净收益。若只有分支整体改善、内容对照无优势，不宣称RGB带来提升。
5. **完成当前既定矩阵后再收敛路线。** old early/contextual内容对照与独立S²DB E10完整矩阵仍在运行，未有最终收益结论；不追加无界架构搜索。若RGB内容贡献仍弱，则将深度几何作为主方法的可证实贡献，RGB外观只作未获支持的扩展。
6. **正式结论迁移到重新划分的数据。** 固定场景/区域隔离的新split，重新训练卫星基线与分支，避免旧v1权重已见过新test区域。固定v1 test已经用于机制研究，应作为开发证据；新split保留独立最终测试。随后验证训练重复性及联合训练，不把冻结热启动探针当最终双流训练范式。

# UAV增益卫星实例分割：阶段复盘与独立审查

日期2026-10-16。用户要求先总结全部已有证据，再派给独立子代理分析量纲、对齐、信息消费及根因。
本次不改模型/训练/标签/cache，不启动新训练、不运行未闭环的full-scale探针。三名新审查者均fork-none，独立读取源码、原始数值与已有探针，不以历史审核PASS代替本次分析。

## 一、阶段判断

**目前研究设想尚未被可靠净收益支持，但不是已经证明UAV没有用。**

已证实：模型读取了与目标几何配对的UAV RGB，辅助信号影响mask，主要沿SAM图像embedding。尚未证实：这些信息能在当前采样、表征、训练与输出接口下稳定超越独立卫星单流。

本轮未找到“修一个100倍单位错误即可恢复收益”的已证实bug。更有依据、但还未获性能因果确认的组合解释是：

1. 数据任务未必形成预想的信息优势：低飞不等于当前512输入的UAV比长焦卫星更细，且目标是卫星可见建筑轮廓，不是所有立面/三维建筑内容。
2. UAV信息经数米尺度token、单4m BEV向量和stride16投影池化后，可能保留上下文而缺少精细边界；当前冻结读出仅有微弱条件形状增量。
3. 主要消费入口是全图SAM embedding，而大多数RoI/P2及SAM高分辨率视觉输入未直接融合UAV，协同训练可能形成替代性依赖而非新增能力。
4. 外部配准/表面可见性仍有未知；当前证据不足以把单位、轴向、全局平移或attention尾部列为首要已证根因。

不能用以上假设替代训练或独立test证据。全量原始数据仍在生产，当前627train/153val/4496验证建筑出现/237唯一建筑只是冻结开发子集。

## 三、独立量纲审查：未确认单位bug，发现了尺度前提问题

审查者stage_units_independent；亲读生产者/consumer，并固定hash选431/28/653、全部15view做CPU原始数据抽样。全文及脚本/JSON见下方归档。

### 量纲已核项（只限源码和抽样范围）

- depth EXR以cm保存，读取除100；两外参translation也各除100，origin已经为米，无重复换算证据。
- 生产者为camera-space Z；consumer用[(u−cx)Z/fx,(v−cy)Z/fy,Z]，无将欧氏range误作Z或额外ray-norm修正证据。
- 15个packed PNG以near10cm独立重解，与EXR最大差.003898cm（float量级），未见100倍或重复range转换。
- RGB/depth固定512²无resize/flip，intrinsics相同尺寸；pyramid[1]确为stride8、candidate token为64²，未发现32/64或256/512错配。
- feature/quality/coverage分别归一，confidence列均无量纲；没有漏除256pixel面积导致256倍强度的证据。手工quality不是校准正确率。

### 真正需要重估的物理尺度

| 当前采样量 | 独立实测/推算 | 与设想的关系 |
|---|---|---|
| 卫星 | fx2844.444、相机Z2000m，近地.703125m/px，512图幅约360m | “卫星”不是天然低清；长焦成像很强 |
| UAV | fx787.911、水平轨道300m、相机高度335–483m；Z约264–717m | 低飞仍可能因宽视场、斜视而没有更细GSD |
| UAV原图局部像素跨度 | 抽样同高度水平面约.38–1.24m/px包络 | 不普遍优于卫星.70m/px；不是立面真值或全数据分布 |
| UAV stride8 token | 同高度平面u向p10–p90包络3.05–6.69m、v向3.45–9.89m | token层面已混合数米范围 |
| UAV stride16 semantic | 同法约6–20m | 上采样相加不能恢复独立亚格内容 |
| BEV单格 | 4m，近地约5.69卫星像素 | 一个格共享向量不等于格内有5.69个独立视觉值 |
| SAM stride16 | 近地约11.25m | 高精度像素footprint不等于高分辨率视觉表征 |

这些数值不说明UAV必然无价值：遮挡、不同外观、立面与视角仍可能互补。但当前目标是**卫星视角可见建筑实例轮廓**，不是3D体积或全部立面；更丰富的三维观测不保证提供额外可用的目标边界。

## 四、独立对齐审查：内部一致性较强，外部图像对应仍未闭环

审查者stage_alignment_independent；复核源码/已有NPZ，新增固定六图30相机的轻量CPU独立view深度互投（5.7秒）。

- camera center与depth metadata max差0m；FOV差<9.3e−7度。
- 两端3×3深度变化<1m的14559互投对中，11111约76.32%差≤1m；3369在目标深度后方>2m，仅2个在前方>2m，大部分差异方向符合遮挡。后方点并非逐点已验证合法遮挡，76.32%不是校准准确率。
- 比同相机roundtrip多了一层真实view深度一致性证据，但仍未独立建立RGB与depth、UAV与卫星RGB边缘对应。RGB是MRQ、depth是SceneCapture，姿态/FOV元数据一致不保证材质、LOD、抗锯齿、时间完全一致。
- Hiera名义中心与anchor块/目标分桶中心有约1.5输入像素的约定差，源端是UAV像素、目标端是卫星像素，不能相加或当同一个误差；maxpool和attention感受野不是点。**不能直接补±1.5px或改align_corners当成修复。**
- footprint的z-buffer只在已有UAV代理面之间竞争，不是完整卫星depth可见性；未被UAV看到的遮挡物不会凭空纳入。coverage高不证明投向正确roof/实例。

结论：系统轴翻转/100倍尺度/已选高度桶均值/旧cache失配目前不是首要证据指向；局部配准、可见性和来源token混合仍未知。

## 五、独立消费与训练审查：已消费，但通路与局部形状需求不匹配是风险

审查者stage_consumption_independent；直接核对dual/CVT/fusion/提示与readout源码、JSON和拟合定义，没有重训/模型前向。

1. **完全不消费UAV被现有证据否定。** 梯度、RGB供体、FPN/SAM交换均一致；强依赖不等于新增能力，卫星分支可能在协同训练中让渡部分能力给UAV，这是相容解释而非已证因果。
2. **P2/high-res缺口是事实。** post-neck P3/P4融合不会自动回流至P2，SAM high-res也原样返回；但SAM主embedding仍使用UAV，不能称大多数实例完全没用UAV。
3. **dense反馈隔离是事实而非已证主因。** point挖掘no_grad、dense detach，coarse只有辅助GT监督；SAM视觉直路仍有mask/tail梯度。.1 loss系数不代表梯度小，解detach不会凭空给P2加UAV或修复support0。既有loss路径验收证明UAV/CVT的部分监督路径可达，不等于已测解除detach后的梯度大小、方向或冲突。
4. **全图SAM输入到roi_local输出需学习转换。** 源码实际重复完整embedding/high给每ROI，最终按ROI局部目标监督和bbox paste；几何对齐的卫星位置不等于规范化ROI像素位置。单/双流共享该设计，不能直接判其是净差原因或训练/推理不一致bug。
5. **极少覆盖的幅度风险未排除。** projection按支持mass归一feature，fusion显式只乘coverage>0，coverage作为gate输入而非连续幅度约束。stride16若只有1/256pixel有支持，valid仍为1；在相同quality/gate条件下显式缩放不会自动小256倍。实际residual还有GN/通道统计，不能声称真实幅度必然相同。既有低支持减半失败不等于单个coarse格的稀疏支持行为已经验证。

## 六、为什么这么多探针还没有一个“修复点”

有一部分探针回答的是**当前模型如何依赖输入**，另一部分是**受限测量器能否读出信息**，第三部分是**GT条件提示能被消费**。它们不自动构成一条从UAV原始信息到最终净增益的可逆推理链。

- donor掉分不能证明新增信息超过单流；GTdense有效不能证明UAV能预测；raw/CVT低维读出不过.001门不能证明原始信息无用。
- 旧8²ridge与新16²卷积头的Brier不是同一任务，不能直接跨数值作阶段保真率。U/C都已经聚合且共享stride16/32维瓶颈，C−U不等于attention纯效应。
- .001等工程门只决定对应候选是否值得扩大资源，不是将研究设想判无效的自然常数，也不与AP差线性对应。已有FAIL保留，不事后改门宣布成功。
- 反复使用同153张val会让它成为开发集，237建筑反复出现；不能通过再叠普通图像bootstrap恢复独立测试证据。

所以本阶段更准确的诊断是**信息优势与信息保留/使用尚未分离**。尚不具备将原因全部归到数据或全部归到CVT的证据。工作方法也应纠偏：不能用一连串冻结依赖性/低维读出的局部问题，代替更早该核实的实际GSD、可见目标互补和外部图像配准前提；探针数量增加并不自动提高对净收益的解释力。

## 七、下一阶段应作的明确决策

本次只总结与审查，未自动执行以下工作：

1. **先闭环一项外部对应与物理信息审计。** 少量分散目标，在真实UAV RGB/depth/卫星RGB上用独立可辨角点/屋顶边缘或已知3D表面核验，区分屋顶/立面/遮挡；报告随view、深度和图像位置的signed误差。不要把同一套矩阵生成的对应或卫星GT反贴回UAV当外部真值。与此同时确认UAV确实看到卫星不清楚的目标轮廓，而非只有更多立面/相似分辨率上下文。
2. **若外部对应基本正确，最多闭环已有投影尺度候选一次。** 当前仅六图smoke，不能写效果负结果。资源允许后沿既定同CVT coarse/fine协议执行，要求测量器有任务相关空间细节正控制；不扩seed/宽度/步数寻找阳性。该比较只能定位stride16汇聚，不会自动诊断更早的source/4m格损失。
3. **然后决定是否作一次有明确单变量的模型/数据验证。** 若原始UAV无明显更细目标轮廓但有视角互补，就应以视角互补设计任务和表征，不能继续仅凭低飞假设追求细边界。若有明确证据被空间聚合抹弱，再考虑保留局部源证据的接入；不是直接把4m改小、改相机或全FPN铺开。新设计净收益必须由匹配训练与独立空间test确认。
4. **停止重复已回答的探针**：不再追加zero/donor、统一强度/平移扫描、GToracle变体、无适配P3→P2借用、读出seed/步数搜索。下一项必须能让“数据互补不足”与“表示/接入丢失”至少一个假设显著改变判断；否则不再扩计算。

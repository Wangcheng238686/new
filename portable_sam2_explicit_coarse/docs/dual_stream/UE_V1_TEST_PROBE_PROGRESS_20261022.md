这些stats来自每图最后一个mask head调用（最多32 RoIs），再跨459图取中位数，不是全图加权统计。
例：test整图检测数中位数85，而stats.rois中位数17。原证据raw_rgb_feature_diagnostics.json。

源输入归一化代码核查：LocalUAVAdapter将OpenCV BGR转RGB，再以123.675/116.28/103.53和
58.395/57.12/57.375标准化；RSSAM2VisionEncoder.forward直接将输入送入image_encoder，
没有再次像素归一化。相机/深度均统一转换为米。当前没有发现RGB重复归一化或cm/m混用证据；
残差RMS增长属于学习特征参数化现象，不能当作物理量纲错误的证明。

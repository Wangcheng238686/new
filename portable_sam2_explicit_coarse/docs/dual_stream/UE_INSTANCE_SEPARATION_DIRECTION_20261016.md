# 研究目标纠正：UAV用于缓解卫星相邻建筑粘连

2026-10-16。承接用户明确指出的研究假设：UAV可提供卫星视角缺少的信息，帮助遥感实例分割分开相邻建筑。本条为研究方向澄清，不是新效果结果，不启动训练、GPU或新readout。

## 1. H1没有否定这一设想

此前将信息优势过度收窄为“UAV有更细屋顶纹理/更好GSD”是不完整的。相似GSD下，不同视角仍可能揭示立面、楼间间隙、遮挡关系、顶高差或建筑体量，帮助判断相邻区域属于一个还是两个实例。

这是合理但有条件的假设：新增证据须对区分目标实例有用、实际可见并能对应到卫星可见mask。立面/顶高差不总存在；完全贴合且无可见区分的相邻对象不能仅因多view就保证可分。图内标签canonical实例单位也应与物理可区分建筑一致。

先前独立H1的结论只能保持“无普遍更细采样优势；原始任务互补未定”，不能升级为“UAV不能帮助分离粘连”。GSD比较不足以检验该研究假设。

## 2. 当前缺的不是又一次是否消费检查，而是目标对齐的评价

现有正确/zero/shift与RGBdonor已证明模型消费辅助及RGB条件；小全局AP差没有给出相邻建筑分离的专项结果。已有GT框IoU、8²/16²occupancy与全局boundary指标均不是“邻接对被正确分成两个实例”的直接测量。8²/16²仍可能含边界信息，但不能把它的总体弱增量当原始关系证据不存在。

邻近、几何接触、预测合并也不能混为一谈。下一步用已有GT与预测，不更新模型，先固定描述定义和分母：

- 基于GT instance mask/ID建立接触或近邻对；距离以卫星像素和米同时报告，接触与近邻单列；重复建筑对/图像相关性单列。
- “两栋各自检出且各有不同预测对应”用一对一匹配与既定IoU阈值定义；不能用一个大mask同时匹配两个GT后称分离成功。
- 逐对归类：缺候选/漏检、一个框或mask跨两栋、框分开但mask侵入邻栋、候选在NMS后消失。允许多种错误并存，不强行单一标签。
- 主观察为邻接对分离成功率与漏/并/侵入类别；伴随完整AP、非邻接实例质量，避免只改善局部而整体受损。专项指标不事后替代原AP主结果，也不将选择后的dev子集称test。

当前已有完整GT/DT及raw候选/NMS缓存，足够优先做这一定位；本次未实际计算这些新指标，不预报哪类占主导。

## 3. 建议模型方向：实例条件的局部UAV读取

优先候选不是提高全局gate、扩大所有FPN层或只把BEV图插值变大，而是让辅助证据进入具体实例的分离决策：

```text
卫星候选 / RoI特征
        ↓ 产生实例条件局部query
由真实相机/深度限定的UAV源tokens（尚未经4m BEV与卫星stride16均值池化）
        ↓ 局部cross-attention / 适配器
实例mask或粗形状特征 → 原分割监督
```

保留已接受的独立BEV作为上下文，不要求卫星参与BEV构建，不回到多高度BEV。局部读取可用源token投影到卫星RoI的相对位置、深度/高度与观测有效性，保留候选身份和视角，不把同token双anchor当独立视觉票。目标是减少在实例分离前进一步平均邻栋证据；尚未证明当前源token一定已保留所需细节。

该方向有依据：P2未直接融合、SAM high-res未直接融合、主要消费为全图stride16 embedding，且单4m向量和stride16平均不能显式为格内相邻区域提供不同值。它仍是待验证设计，不能由结构事实保证AP。

第一版应只改变一个接入轴，保留原损失、generic联合初始化和配对预算。邻接采样、边界加权loss、解detach、改NMS是不同变量，不一起改。监督来自卫星instance ID/mask，不新增UAV/BEV分割标签，不走UE单流热启动。不能用未适配的P3融合器移植P2冻结结果替代新模块训练结论。

## 4. 检测瓶颈是条件分支，不能忽略

若专项定位主要是RPN无独立候选或NMS压掉另一栋，mask入口无法恢复一个根本未进入mask head的实例，此时优先将局部UAV几何/分离证据接到proposal、bbox质量排序或相关P2路径。
若候选/框已分开、但mask混入邻栋或漏掉分界，实例mask侧局部融合是首选。
现有全局NMS损失两臂相近，只排除了其作为已证双流独特主因，不能替代粘连子集的专门定位。

## 5. 下一步止损点

先用已有工件完成一次针对粘连的定位，并核对少量对应可信的同一邻接对在五view是否有新增分离线索。两者合并回答“哪种错误、辅助证据在哪、需要影响哪个阶段”，避免再开一轮泛化依赖性probe。

有可见证据及明确接口后做一次单变量可训练改动；若UAV实际也无区分线索，应调整采样/目标预期；若证据存在但接入后仍无改善，再查具体表示损失/训练动力。保持独立test和种子验证边界，不事后为同一开发集循环改指标/超参。

## 6. 已有产物定位完成后的更新

2026-10-16：[完整邻接对诊断](UE_ADJACENT_PAIR_DIAGNOSIS_20261016.md)已完成。原第2节“raw候选缓存”应理解为逐GT最佳候选几何摘要，未保存全量原候选表，不能重建完整pre-NMS一对一身份链。最终DT一对一配对不受此限制。

根据实际失败分层，§3的“实例mask侧局部融合首选”现在只适用于框已合格的条件子集。整体更应先核对整栋范围/局部屋顶块与筛选后覆盖丢失；未来UAV读取宜有机会在最终NMS之前影响候选bbox/RoI质量，并保留整栋上下文。此为设计优先级修正，不认定RPN/NMS因果或批准新训练。

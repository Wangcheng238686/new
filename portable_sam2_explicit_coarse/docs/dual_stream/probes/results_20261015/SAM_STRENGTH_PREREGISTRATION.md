# SAM残差强度冻结探针预注册

日期2026-10-15。关联EXP-0006/0007，A类冻结诊断。用户明确优先低成本探针，不训练、不改生产融合、不自动推进训练。

## 固定设置

仅使用当前冻结开发子集153验证图、4496次出现、237栋建筑；固定dual E72 strict EMA，正确配对五视角RGB及深度/相机几何，eval+inference_mode，无optimizer。FPN入口保持原模型不变。

以不改输出的forward hook捕获SAM融合输入E0及输出E1；原模型E1=E0+R。仅对传入mask head的图像embedding构造E(s)=E0+s*(E1−E0)，固定s∈{0,0.5,1}；s=1直接使用原E1，s=0直接使用原E0，避免回放舍入误差。0.5是预先指定的主对照，不在跑后按最高AP挑强度；0只作端点诊断，不宣称独立单流。s=0仍保留正确UAV在FPN的融合，不能称整个UAV关闭。

该方法缩放的是浮点有效差分残差，不重新计算gate、不修改learned alpha、不缩放卫星特征；误差应限定于有限精度差分，s=1必须原值回放。

同一图仅提取一次完整特征、一次RPN/bbox。使用原检测框/score进行各强度mask推理；GT共同框用同一组真实框，框hash一致。必须核对原检测框score精确复现历史导出、s=1全部mask/GT框IoU精确复现、PE/high及FPN值不变、参数version与捕获特征前后hash不变、hook恰好调用一次且移除、无RGB-D失配。任一失败停止修复。

## 指标与判据

主指标：完整segm/mAP(s=.5)−segm/mAP(s=1)。伴随bbox/mAP（逐值应不变）、GT共同框mask IoU差及尺寸/建筑等权。选择固定E72，无重选model/seed，三强度全部报告。

探索性不确定性：500次配对图像AP bootstrap seed1720；1000次图像sum/count共同框IoU bootstrap seed1721。相同重采样跨强度，重采样重复图像需要独立位置；缓存聚合验证精确点估计及重复抽样普通COCO重算。仅覆盖图像重采样，不覆盖空间相关、模型选择和训练seed方差。

工程门：若预指定s=.5相对1的segm AP提高≥.005，探索性95%区间下界>0，且GT框IoU差≥.002、bbox精确不变，称“当前冻结模型存在SAM注入偏强的支持证据”；若AP差绝对值≤.002且GT框差绝对值≤.002，称“半强度下整体近似持平”；若s=.5与0均比1低≥.005segm AP且均低≥.002GT框IoU，称“原强度优于这两种减弱干预，未支持过强假设”；其余混合结果。门不是显著性/最佳结构判定。0优于.5或非单调时如实报告，不把0后验选为新模型。

即便减弱获益，也只说明当前权重的推理干预改善，不能等同新训练结构净收益；减弱有害不能证明强度最优。不会扩展强度扫描、重训练或直接修改默认配置。

## 离线诊断字段（不写入训练遥测）

sam_alpha：所选EMA融合模块learned alpha，标量，仅记录不改动。
residual_norm_ratio：||E1−E0||2/max(||E0||2,1e−6)，每图、全通道全像素；不是内容质量/训练动力证据。
scale：有效残差倍率，unitless；1为原模型，0为仅移除SAM融合。
GT框mask IoU：逐出现实例交并比，按图像sum/count或建筑内均值汇总，非AP。
完整正式推理验证优先于上述机制量；不新增生产DEBUG_FIELDS字段。

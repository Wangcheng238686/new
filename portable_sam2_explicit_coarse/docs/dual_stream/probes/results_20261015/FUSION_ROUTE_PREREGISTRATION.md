# 融合入口定位探针预注册

日期2026-10-15。关联EXP-0006/0007。A类冻结诊断；不训练、不更新参数、不修改生产模型。用户要求继续从低成本探针定位，禁止本轮自动推进训练。

先3图smoke、独立实现审核，再决定完整153验证图。固定E72 strict EMA、原manifest与上一轮donor_a/b映射。每套映射分别构建两种完整特征：正确RGB的(C_fpn,C_sam)，供体RGB的(D_fpn,D_sam)。只在后续RPN/RoI入口拼接四个cell：CC、CD、DC、DD。第一个字母指FPN，第二个指SAM图像embedding；SAM高分辨率特征与PE必须在两个原始特征包中完全一致。

CC/DD为对角回放，必须逐图精确复现上一轮完整框、score、mask与GT共同框IoU；非RGB payload跨提取不变，未融合的FPN层相同，特征逐值hash与参数版本无意外变化。失败则停止修复，不解释结果。CD/DC是激活替换诊断，含分布变化，不是可部署模型或从头训练单入口消融。

主指标：全部4496次出现的GT共同框二值mask IoU；伴随完整segm/bbox AP。按尺寸和237栋物理建筑等权报告。只用GT共同框降低开销；不把IoU当作AP。

预定义差值：
- SAM内容效应：CC−CD（FPN正确），DC−DD（FPN供体）。
- FPN内容效应：CC−DC（SAM正确），CD−DD（SAM供体）。
- 交互：CC−CD−DC+DD。均为所选指标尺度上的条件差值，不是独立可加的信息贡献。

判读门：某入口四个条件（两套供体×另一个入口C/D）IoU差均≥.005，另一个入口四条件差绝对值均≤.002，称“本干预的mask影响主要沿该入口”；若入口条件差均≤−.005，标记该条件下反向效应；交互绝对值≥.005且两映射同号，标记交互敏感；其余混合，不强行选单入口。效应门为工程定位阈值，不是训练收益或显著性阈值。

不确定性：1000次配对图像bootstrap，seed1710。每次同一图像重采样跨四cell；逐GT均值采用图像sum/count汇总，不按图像均值替代实例均值。另做建筑内平均后等权。区间仅探索性，不覆盖空间相关/选模/训练seed。AP仅描述完整点估计，本轮不重复AP bootstrap，避免无具体必要的开销。

即使定位到入口，也只能定位当前冻结模型的干预敏感路径；不能证明该模块有bug、不能宣布最佳训练结构，更不能证明UAV带来超过单流的额外信息。若该轮无清晰定位，先报告混合结果再选下一冻结探针，不自动训练或大范围扫参。

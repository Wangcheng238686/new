# 候选接口空间探针：现存真实预测框是否留有 NMS 前机会

2026-10-16。协议先写，CPU复用153图/4496次GT/3734次相邻pair产物；无模型forward、fit、训练、GPU或标签修改。代码`probe.py`、完整逐对结果`pair_records.json`、轻量`summary.json`、源SHA256`source_sha256.json`。

## 结论

**存在非零、且并非全由已标记风险标签组成的候选几何机会，支持继续检查这些候选对应的UAV信息；不支持直接宣告RoI融合可学或授权训练。** 严格阈值的候选框质量机会多于低阈值，但即使几何框恢复，候选mask、其他实例、误检、AP仍未知。前轮GT框oracle被替换为真实已有预测框的部分候选集合，本探针没有生成/回归任何新框。

## 集合与可达性边界

- E：每GT已保存的最佳eligible预测框去重并集，单/双4470/4475框；原生产每图有数百eligible框，**此处不完整**。
- U：E加已有最终预测框，单/双10475/10438框；原最终6533/6514框无重复。最大坐标差<=1e-4px去重，避免同候选重复入表伪造两实例。
- 评价阈值固定 .5/.75；部署最终hard-NMS阈值 .5。
- 图内最大基数优先、再最大IoU和的全局一对一匹配。另检验pair内两个不同候选可行，以及它们互IoU<=.5。
- “重排兼容”：当前全局bbox失败，但U中存在满足两个GT阈值且互不触发NMS的两框。把它们oracle排在首位，可让该pair的两个框存活；**不同pair的oracle排名可能相互冲突，不是一个全图统一可兑现结果**，也没有候选mask生成。
- “缓存不足”仅指当前部分U里不够，不能断言完整候选表里也不存在、必须回归或新proposal。互抑也只针对U，完整候选中可能有另一对可用框。

## 验算与限制

- E独立重算最佳IoU与保存摘要最大差：单3.116e-7、双2.749e-7。
- 全153图、两臂、两阈值最终框全局pair结果逐项重现上一轮全部3734pair记录；assert无失败。尚待独立子代理代码/结论复核。
- GT归属风险使机会定义仍依赖暂定标签。该探针既不否定标签影响，也不把未标记组当清洗后的基准。
- 可用框的存在是冻结几何证据，不能说明其在UAV里可见、其源特征含身份信息、其置信分数可从UAV学出来、或候选mask变好。
- 此结果比较各模型自身几何空间，不是同一模型随机化干预，不将双的机会更多解释为双流优越。
- 缓存丢掉了其余eligible框、身份及大部分分数。未跑完整NMS重放，没有全图可兼容最优解，没有AP数值，没有重新选阈值。

## 下一步探针限定

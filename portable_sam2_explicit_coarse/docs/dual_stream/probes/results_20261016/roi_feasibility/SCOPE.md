# RoI-UAV方向冻结可行性探针

2026-10-16，用户要求先探针，不先实施模型或训练。路由A的冻结诊断阶段；本轮不进入热启动/全量训练。只CPU既有产物和原始RGB-D，无fit、无新模型forward、无数据清洗。三代理分工：候选接口空间；实例级真实UAV对应/局部上下文证据；独立审核。原始标签和生产代码保持只读。

核心问题分别落判：
1. 已有候选中的实例范围/独立框可行性是否存在改善空间？GT协助的候选集合最多只给受限oracle界限。
2. 目标局部与周边在五UAV中是否实际被观测，能否提出有对应的分离/整体性线索？投影支持不是物理语义真值，不将额外视角等同额外可学信息。
3. 这两类证据是否足以支持进一步设计RoI读取？不能由两者合取声称未池化UAV特征在候选条件下可读、可学、可泛化。若无可检验消费干预，本轮结论上限是可行性/缺口，不是模块通过收益门。

先由两实施代理固定协议/样本/指标与边界，再计算。独立审核至少检查来源一致、候选身份/一对一、真实深度投影、选择偏差和标签风险。数值分母与物理对重复披露。label风险flagged/unflagged均不冒充人工clean。

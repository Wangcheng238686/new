# UBR方案收敛建议：先替换统一尾部，再组合G

日期：2026-10-27。依据 `UE_UBR_UNIFIED_DESIGN_20261027.md` 与 `UE_G_MULTIVIEW_EVIDENCE_DISCUSSION_20261027.md`。性质：本轮收敛建议与工程合同草案，不是实施完成/新训练发射授权。最新用户已确认的尾部方向以统一UBR设计为准；旧讨论的保留UDPR、删中心头、三组loss等建议不再作为默认方案。

## 1. 收敛决定

- 新单/双流均只有一个类型的UBR空间边界修正器；新活跃路径不实例化UDPR、不保留64点MLP、不返回loss_decoder_tail。历史代码与检查点的重建隔离保存。
- 首轮先验证尾部替换：原检测、SAM2、coarse与提示栈保持，UBR只接5通道几何。不上RGB query、不扩大8候选、不改分数/NMS/实例上限，不把G/实例发现精简与尾部替换打包。
- 上游G和补充实例头为独立设计轴。首轮尾部替换族的三个臂统一关闭这些额外上游模块，保证差异只在UBR端口；这不是决定从最终G模型永久删头。原G实验与原100轮继续原合同。
- 保留补充头的后续模型必须保留对应中心/框监督，除非独立删头试验成立。UBR无法补回检测完全漏失的实例。

## 2. 尾部输入与作用范围

每实例在卫星原生512²网格输入40通道：SAM2对齐特征32、当前mask概率1、由阈值化预测生成的SDT1、精修前其他预测实例掩码和1、height/dx/dy/viewcount/support几何5。几何单位/洞值/归一化继承已审计缓存，非AGL、非物理坡度，不额外按test归一化。邻居来自预测，不用GT匹配筛实例；所有实例同步取精修前状态。

UBR起点hidden48、7个残差块、GroupNorm+SiLU、单通道输出。带宽k=8目标像素；7px是边界评价带，8候选是缓存限制，三者不混用。支持洞保留其它卫星输入：只清空对应几何通道，不关闭整个UBR。单流全零端口仍有空间边界修正能力。

SDT、邻居、概率状态作为stop-gradient状态输入，首版不经这些条件形成预测间反向耦合；解码特征保持可微，最终mask loss经连续合成训练UBR与decoder。这些梯度定义属于新训练合同，不能据旧冻结加法探针直接声称已验收。

## 3. 连续训练与部署阈值

设原mask logit z，部署阈值t，b=logit(t)，B为预测SDT的|SDT|<=8带。UBR输出相对部署边界的连续分数r，定义绝对logit z_ubr=b+r，训练合成：

```text
z_final = (1-B)*z + B*z_ubr
```

主mask损失使用该连续张量，经与原mask目标一致的坐标/采样链对齐。UBR带内focal BCE+Dice也基于同一z_ubr的概率定义，避免两个相互未声明的logit语义；超参数/目标网格需写进配置和损失指纹。推理按同一部署阈值，等价于带内r>0。r=0的二值判定可沿源探针回退原mask，但不把该硬规则塞进训练图，也不声称零初始化连续logits恒等。

带外连续值在目标网格保持原z；任何连通域处理都在推理发生，处理后恢复带外原值，不能整实例直接只保留最大连通域而删掉带外区域。空mask/满mask/边缘无带的行为显式定义，禁止让无边界实例变成全图可修改。

## 4. 监督与精简边界

首轮单/双流同为：

```text
L = L_det + L_mask(z_final) + L_coarse + 0.1*L_ubr
```

0.1作为待工程合同固定的起点，非声称已调优。L_ubr沿源探针的带内focal BCE+Dice；对每实例有效带像素归一化，Dice也只取有效带，再以每图有有效带实例均值/全局图均值汇总；空带不伪造监督，空RoI与非空rank参与一致DDP计数。Dice平滑、focal参数、实例/图分母要显式保存，不能用像素多的实例隐式获得更大权重。

coarse保留唯一直接监督。删除旧tail margin，不加geometry重建、RGB辅助、并集边界或其它loss。此时是UDPR目标替换为UBR目标，不是从8键魔法压成3项。若后续接补充实例头，另加原L_inst，不能称只有UBR端口变化。最终mask与带内目标可能有重叠，离线测共享decoder/UBR梯度后，才能单独检验删L_ubr；首版不同时改成只靠主mask或位置加权。

## 5. 第一轮最小对照

| 臂 | 上游额外G/补充头 | 尾部 | 几何端口 |
|---|---|---|---|
| S0 | 关闭 | UBR | 全零 |
| Sc | 关闭 | 同UBR | 真实support，支持内train-only四字段均值 |
| Sr | 关闭 | 同UBR | 实测五通道 |

旧UDPR同合同单流是替换参照。Sc不是无深度，Sr-Sc检验几何内容，Sc-S0包含support信息及训练适配；Sr-S0是总端口收益。冻结同权重off/constant干预不是独立训练S0/Sc的替代。源4090正向记录是含UDPR模型上的加法UBR，不能代替本轮替换检验。

短工程预算只检查接线/资源/行为，不凭E10阴性淘汰最终方向。正式比较采用相同初始化来源、完整预算、既定增强、无EMA、FP32整集AP250；按val Mask AP固定选权，Boundary/AP75为伴随指标，不根据test换带宽/loss或结构。正式预算、非劣界和判定区间在发射前固定；本文件不将远端探针阈值自动移植为本机全局门限。

## 6. G与RGB如何继续

尾部替换及几何内容通过后，再用G开/关×UBR几何开/关检查互补性；这里G应明确定义是逐候选早期模块，不能把旧CNN/双向交互/补充头统称为G一起切换。补充头开关和L_inst必要性另列独立问题。若早期几何与尾部几何重复，保留成本更低、净收益更稳的消费者。

多视角RGB仅在几何版稳定后添加：边界带内像素/实例条件读取候选，单独比较正确/常量/错配，不重用当前退化的全图Q作为默认。最终可以共享物理候选库，但不要求不同消费者共用同一个提前平均向量。

## 7. 长训练前验收

- 新架构身份/配置/损失指纹；无UDPR实例/参数/优化器状态/旧tail loss。
- 原生decoder网格→卫星512²→几何图坐标与采样一致，probability/logit语义明确。
- 训练可微，UBR/decoder有梯度；几何数据无GT泄漏。
- 推理带外逐像素不变、邻居顺序无关、空/满/无支持/图边缘行为、AMP及空RoI DDP正确。
- 250实例实际资源门；同图feature/geometry共享，按实例分块。GroupNorm跨空间统计，局部crop会改变输出，不能仅补halo就声称等价；首版优先整图逐实例/小批处理。若成本不合格，裁剪应作为单独工程近似并核对AP，或改归一化作为独立结构变化。
- 离线梯度范数/余弦、带内净纠错、Boundary与Mask/AP75及成本；非零梯度或Boundary单指标不代替成功。

本轮只新增此收敛提案与指南记录，未复制UBR实现到活跃包、修改现有模型或启动新训练。

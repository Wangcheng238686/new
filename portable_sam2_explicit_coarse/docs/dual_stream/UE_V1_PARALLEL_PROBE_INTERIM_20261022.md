### 能支持的结论

1. 冻结已有卫星检查点、仅训练19,681参数的新增几何分支，在这条v1训练轨迹上得到
   小幅实际Mask增益和较大的严格边界指标增益；这是下游训练结果，不只是重建/探针读出信号。
2. 几何内容对照的三个区间均为正，支持四项几何内容有新增价值；零内容臂仍有support和
   卫星RoI query，因此比较条件是相同support/容量，不是完全无UAV。
3. 零内容臂本身Boundary AP1%也比基座高+.265836pp，不能把真实几何臂全部+.830334pp
   归给UAV高度；几何内容增量约+.564498pp。
4. **主门槛仍未通过**：原生几何对原基座Mask+.169pp，低于预设+.2pp，尽管名义CI为正。
   内容对照+.226pp不替代主比较；暂列值得保留的候选，不宣布完整方案成功。
5. 该路线不含RGB编码器，尚不支持“RGB外观也有帮助”。它与RGB注意力臂还同时改变表示、
   算子、query消费方式和参数，不是纯分辨率因果消融。

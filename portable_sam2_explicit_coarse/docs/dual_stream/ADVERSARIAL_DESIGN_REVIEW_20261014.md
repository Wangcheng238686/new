# 双流设计对抗复核

日期：2026-10-14。用户要求三名子代理与主代理对抗讨论。审查对象是本工作树的设计、工程规格、测量快照以及现有单流代码；仅修订设计材料，未实施正式模型。

## 结论

核心研究选择已明确，方案可以进入实现。没有必须让用户重新选择骨干冻结、热启动、额外标签、卫星条件 query 或多高度 BEV 的理由。工程核定是可实施初值，不等于所有算法契约已经验证；本轮补齐下述规则。

三位反方分别审查几何表示、训练归因与工程接入。主代理逐项反驳并要求复核，达成以下共识：

- 不把「value 的原始高度不同于 Zrep」直接判作错误：BEV query 可以读取立面作为建筑语义上下文；必须明确 query 归属 `(XY,Zrep)` 并记录上下文和高度不一致性。
- 不因没有 UAV 标签否定训练动力：训练时已有 GT-positive proposals，最终 mask 到 SAM 图像入口的梯度可达；实际门控下是否有效仍需真实模型验证。
- 不根据全图 embedding 与 roi_local 输出的区别，直接切换监督方式：这是已有单流契约，首版继承。最终掩码像素不与世界 BEV 格建立一一对应的监督关系。
- 旧资源探针不必重做；正式模块完成后补真实数据、优化器更新与拥挤推理的完整测量即可。

## 1. 三种有效性必须分离（实现前约束）

`candidate_available`：8m 邻域内有可读 token，只决定注意力可用性。
`observation_support`：本 4m cell 内有真实有效深度点，决定是否具有本格观测。
`height_valid`：本格代表高度满足已定几何支持规则。

正式投影 mass 来自后两者，不能把 candidate halo 当真实覆盖。无有效高度的格可保留内部 query 状态，但投影残差为零，不借邻格高度冒充本格观测。记录候选支持、实际支持、高度有效、最终目标覆盖四张不同统计图。

依据：8m 邻域卫星参考区域支持率中位约98.47%，前景投影支持中位约88.30%、最差36.78%；两者统计母集不同，不能相减或互相替代。

## 2. 单层 BEV 的空间语义与 token 身份（实现前约束）

query 明确编码本格局部 XY 与观测 Zrep，relative XYZ 和高度相容性进入软 bias。允许立面等上下文，不用硬 Z 阈值排除全部非屋顶 token。监测本格/邻域上下文比例、选定上表面信息比例与 attention 加权几何偏差。

候选唯一身份是 `(view_id, token_id)`。双几何锚点共享一个图像 token 时，先选择最相容锚点并对 token 去重，不能在 softmax 中重复给票。每视角最多8个唯一 token，优先本格上表面候选，余下按距离与高度软相容排序。高度支持由原始独立像素统计，view_count 针对选定高度簇统计，均不使用重复 anchor 数量。

几何代理的2.13px不等于聚合 feature 已达到2.13px对齐；真实 feature 注入需另作可视化与错位诊断。

## 3. 修正 coarse z-buffer 的错误假设（实现前约束）

不能在 stride8/16 单元里直接按最近 camera-Z 硬剔除较远特征。一个 stride16 单元约对应11m地面宽度，其中道路与屋顶可能属于不同细像素，落同粗格并不代表遮挡。

首版方案：以有效 BEV cell 四角、固定 Zrep 投影出细卫星像素上的小足迹，在512像素平面只做几何覆盖/近表面冲突筛选，然后把稀疏投影条目直接归并到P3/P4/SAM网格。不创建256×512×512密集特征图。2m band 仅为细像素同位置竞争的可配置初值，不作为真实卫星可见性证明。

只向四个原始像素 splat 格中心会有空洞（4m格在卫星约相隔5.7px），不能再把pool后的稀疏命中率当真实面覆盖。小足迹只覆盖该有效4m cell，不扩成8m候选邻域。特征加权均值、几何质量/coverage与置信度分别归一，避免再被稀疏命中比例无意缩小。

这一近似仍不能恢复未被 UAV 看到的卫星遮挡面。输出被拒绝mass、细像素覆盖与粗网格mass统计。若首版暂不实现细足迹，保守置信加权scatter并取消粗格硬遮挡筛选是可接受的退化实现，必须明确其限制。

最低几何验收：平面、阶梯屋顶、落同粗格但无细像素遮挡的两面，以及真实高楼。确保不把邻域支持扩大为观测，不把粗格竞争误称遮挡。

## 4. 完整卫星输入与 roi_local 输出（保留既有契约）

`rsprompter/cspm/mask_head.py:378` 重复完整 embedding/high-res 给每个 RoI，没有 RoI crop；`mask_head_targets.py:307` 与 `mask_head.py:677` 定义 roi_local 目标和bbox paste。首版第二入口仍在完整卫星32×32 embedding上融合，最终监督和粘贴沿用单流。

SAM注意力承担全图输入到实例输出的映射。最终mask损失可回传至UAV，但不能声称最终mask某像素直接监督同位置BEV格。固定GT框/固定proposals用于诊断mask路径，不为首版同时改监督坐标。

## 5. 训练与指标的代码接入（训练前闭环）

- **AP100/AP300解耦**：`train/loops.py:365-381` 当前通过 TEST_MAX_PER_IMG 同时改模型cap和评测maxDets。双流设输出300时，主评测与best必须仍消费AP100；AP300使用明确后缀并单独报告。验证/独立测试一致。已有COCO工具支持自定义maxDets，不能静默改变主指标。
- **显式param/clip组**：`train/optimizer.py:58` 不识别UAV命名，新模块会进other；现有独立clip仅覆盖UDPR。新增UAV适配器、CVT和fusion各自明确分组，保留卫星与UDPR预算。每个可训练参数恰好入组一次；unscale后监测梯度与裁剪比例。
- **norm冻结范围**：`optimizer.py:191-198` 的freeze_bn实际遍历GroupNorm，可能冻结新分支affine。限定到明确的旧模块范围，不默认冻结新UAV/CVT/fusion的GN。
- **统一payload**：dataset/collate/设备迁移、train/val/独立推理共用DetDataSample辅助tensor payload，显式 `_extract_dual_feat(inputs,samples)`，不跨batch缓存。缺必需文件立即报错；正常低覆盖和空邻域走零残差。
- **保存/重建闭环**：新双流身份及数据/几何schema进入snapshot，路径替换覆盖UAV；旧单流契约函数保留。现有fingerprint已完整hash模型键，不宣称其会静默错载。验收strict保存重建、恢复optimizer和预测一致。
- **冻结split**：按实际卫星与UAV覆盖和重复建筑形成可执行泄漏判据与manifest；不能只按中心所属tile或随机帧划分。训练A/D使用同样样本、步数、有效batch和选模规则。

## 6. 正式模型后验收（不是新增前置资源探针）

真实高覆盖样本上做少量参数更新，分别检查det/coarse/final-mask损失对UAV/CVT的梯度、更新幅度、残差范数和正确/错位UAV响应。不要求LoRA所有张量每步非零，LoRA_A在初始步无梯度正常。低梯度先查支持/门控/裁剪，不立即增加辅助损失。

完整资源检查包含一次optimizer update和最多300实例的拥挤预测。`anchor_roi_head.py:409-425` 已有默认32 RoI分块，直接复用，避免新增另一套推理分块模块。保留现有DDP find_unused=True及空GT不跳步，检查不同rank支持为空的情况。

首版收益实验先做独立训练的UE单流与双入口双流，以及正确/错配UAV诊断和空间隔离验证。单入口与深度贡献消融后置，遵循用户约定。无需先铺开所有骨干/深度/RGB/坐标消融。

## 7. 是否还需要用户明确

本轮没有发现新的必选研究偏好。上述规则属于实现契约与验收，由开发侧落实；待真实模型出现支持/对齐/梯度异常，再据证据决定是否需要扩大网格、改高度策略或尝试卫星条件query。尚未验证AP增益，不用三名代理的一致判断替代实验。

## 8. 第二轮独立反方复核：实现草稿与设计是否一致

再次启动三名独立反方，分别核对几何、训练归因、工程接入；主代理就单层近似是否必须改表示、是否必须首轮做等容量重训、是否支持缺视角采样提出反驳并要求复核。结论仍是：没有需要用户重新选择的架构问题，但发现以下具体缺口。此轮是设计与草稿核对，不替代开发完成后的独立审核。

### 必须修复或核验的实现问题

- **候选优先级**：当前先按 XY 取最近 16 个 anchor，再高度排序/去重，可能让立面候选挤掉 8m 内更相容的屋顶 token。须在半径邻域内完成相容性与唯一 token 选择，再截为每视角 8 个；优化检索不能改变已定优先规则。
- **置信字段消费**：最近 XY 距离已写入 payload，当前投影质量公式未消费该字段。需要兑现距离降权；所选高度桶内方差与跨桶混杂必须分开命名和记录，不能把前者声称为整格高度离散度。
- **UE 续训身份**：模型 strict load 不校验数据清单、几何/评测合同。当前 resume 可能按新清单建 loader，却被旧 snapshot 覆盖记录。UE resume 必须比较 manifest hash、geometry、load_uav、评测合同和预训练身份；路径迁移允许文件身份一致，新数据实验另开 run。保留旧单流兼容合同。
- **标签合同**：任务是完整卫星图中可见建筑实例，不是地面 footprint。clean ID 图中 0 为背景，图内 local ID 生成 mask/bbox，global ID 只用于追踪与划分；零可见像素实例不成为目标。核对 ID 与实例表映射，未映射 ID 或整实例被清理的异常按生产规则拒绝/审计。
- **验收状态**：正式几何的平面检查当前存在覆盖断言失败，尚未定因；不得将设计认可写成几何测试已通过。真实梯度更新、不同 rank 空支持、checkpoint 保存/重建/恢复和 300 RoI 推理仍需验收。

### 已接受近似及升级条件

本格少量上表面观测展开成 4m 足迹，可能在窄屋顶/边缘格扩张几何证据。细像素近表面竞争仅比较已有 UAV 观测，不能排除 UAV 没看到的卫星遮挡物。首版采用置信降权与门控近似，保留单层 BEV，不因此要求新增卫星深度或多高度语义体。

建议固定真实高楼诊断集。若至少两视角支持、上表面占比≥0.8的高置信格仍出现系统性超过一个 P3 单元（8px）的对应错位；修正候选、坐标和置信后对应分层 AP75 仍下降，门控只有把残差压近零才避免损害；固定 checkpoint/特征的诊断性正确表面对应或足迹修正能恢复预测，则应考虑更细 XY 格、局部多表面或可见性建模。8px 是建议诊断尺度，不是已发现的失败；单独 AP75 下降或高度误差大不足以要求换表示。

### 证据强度与首轮实验

首轮独立训练 A（单流）和 D（双入口双流），同空间划分、有效 batch、训练步数及选模规则。完整卫星 AP100 为主，AP300 与支持度/拥挤度分层另报。validation 负责选模，独立空间 test 才用于正式泛化结论；当前临时清单只有 train/validation，不能冒充 test。首轮单种子为初步证据，小幅增益形成论文结论时需核对种子波动。

A/D 优于单流可支持双流系统增益。正确/zero/shift/mismatch 诊断支持输入依赖，但属于分布变化干预，不能单独证明增益来自新视觉信息而非容量/优化差异。等容量、RGB 与几何贡献的重训控制后置，按论文结论所需证据补做；无需当前扩大首轮消融。

### 输入边界

首版严格要求五个 RGB-D 视角齐全，缺失/损坏文件报错。文件齐全但某视角或全部几何无支持，走相应零残差。这符合已定数据域；可变视角是后续范围，无需现在请用户重新选择。

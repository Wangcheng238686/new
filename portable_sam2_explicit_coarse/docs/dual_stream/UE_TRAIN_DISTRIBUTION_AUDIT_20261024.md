# 旧 N2 / N2-shared 训练分布诊断

目的：判断现有 UAV 分支是否在训练分布上也无法超过冻结纯卫星模型。v1 的 train/val/test 平均实例数约 58.9/32.6/98，分布偏移是合理候选解释，但训练集上涨本身不能证明偏移是失败原因。

## 固定协议

- 读取现有 E10、2670 updates 的 `last.pth`，不继续训练、不按训练集选权重。
- 完整 train 2142 图，无颜色/高斯增强，无 shuffle、drop_last 或样本截取；FP32 推理、原始 scores、maxDets250。
- 单卫星基座 EXP0017 epoch73，与旧探针完全相同；模型参数和 buffer 推理前后指纹须一致。
- bbox AP、Mask AP、Boundary AP 2%/1%。Boundary 使用 min(mask IoU, boundary IoU)，边界带为图像对角线比例；512 图约 14/7 像素。
- 第一阶段输出全量点指标，属于训练集拟合诊断，不将其视作泛化显著性证据。

## 七次推理

1. 冻结纯卫星基座，禁用 UAV。
2. N2 正确 RGB 训练检查点，正确 RGB 输入。
3. N2 常量 RGB 训练检查点，常量 RGB 输入。
4. N2 正确 RGB 训练检查点，常量 RGB 输入。
5. N2 正确 RGB 训练检查点，下一图的 donor RGB 输入；保留目标图几何。
6. N2-shared 正确训练/正确输入。
7. N2-shared 常量训练/常量输入。

2−1/6−1 是相对基座净变化；2−3/6−7 是同结构训练内容对照；2−4/2−5 是固定权重输入依赖。常量对照仍有原几何、位置及可训练容量，不能将所有新增分支收益解释为 RGB 内容贡献。

## 判读

- train 净增益和内容差都清楚为正，而 test 很弱：支持训练分布内可拟合但跨分布泛化不足，仍需排除普通过拟合和 seed 波动。
- train 净增益为正但正确≈常量：优先解释为新增参数/几何/训练适配，不能归于正确 RGB。
- train 也基本无净增益：仅靠 train/test 偏移不足以解释当前现象；消费入口、几何、学习强度和训练分布内基座余量仍待检查。
- train 正确输入不优于 donor：不支持场景对应性，即便相对基座上涨。

训练集密度处于 val/test 之间，故这里不能直接隔离密度因果。后续若有 train/test 差异，先做固定实例密度和几何支持质量分层，再考虑重新训练；不直接得出“数据集有问题”的结论。

## 工程与产物

独立入口 `scripts/probes/ue_train_distribution_audit.py`，复用原 `make_model/evaluate` 数值函数，绕过 CLI 只允许 val/test 的限制，不编辑活跃实验 source。N2 与 shared 分别使用各自原始 initialization，严格加载其对应分支状态。

运行根 `/data/wangcheng/checkpoint/ue_train_distribution_audit_20261024`。最多 GPU0/1 各一个任务，空闲至少 8500 MiB 才启动，PyTorch allocator 上限 5500 MiB；CPU 指标最多一个并行。保留源代码与检查点 SHA、每任务退出码、完整预测、身份与逐项指标；失败停止新增任务，已有任务自行结束。

最终 `summary.json` 包含七组完整指标及配对差值，单位 pp；`state.json` 为任务状态，`logs/` 为各任务原始日志。无新模型遥测字段，不修改既有训练遥测纪律。

## 已完成结果（2026-10-24）

14/14 任务完成，七组均确认 train2142、无增强、冻结卫星参数/buffer 推理后完全相同。126214 个实例。

| 组 | Mask AP ×100 | 相对卫星 pp | Boundary AP2% ×100 | Boundary AP1% ×100 |
|---|---:|---:|---:|---:|
| 纯卫星 | 90.65093 | — | 87.29444 | 78.26372 |
| N2 正确训练/正确输入 | 90.64475 | -0.00617 | 87.29598 | 78.27485 |
| N2 常量训练/常量输入 | 90.62926 | -0.02167 | 87.26071 | 78.21942 |
| N2 正确训练/常量输入 | 90.66715 | +0.01622 | 87.32666 | 78.47241 |
| N2 正确训练/donor 输入 | 90.65374 | +0.00281 | 87.30711 | 78.28887 |
| shared 正确训练/正确输入 | 90.57448 | -0.07644 | 87.27772 | 78.24913 |
| shared 常量训练/常量输入 | 90.56221 | -0.08872 | 87.20022 | 78.19005 |

bbox AP 全部为 91.43387，符合旧注入点不改变检测分支的结构合同。

旧 N2 的正确训练内容差 Mask +0.01549pp，但净变化 -0.00617pp；正确输入比同权重常量输入低 0.02240pp，比 donor 低 0.00899pp。shared 内容差 +0.01228pp，净变化 -0.07644pp。不能把“正确训练比常量训练少下降一点”说成超过纯卫星的收益。

结论：旧链路在训练分布上也没有明确 Mask AP 净收益，故“已有训练内收益仅因测试分布偏移而消失”的解释不受这组结果支持。分布问题仍可能影响绝对 AP、学习过程或更早的特征入口，但不足以作为旧臂失败的单一解释。训练集基座已达 90.65 AP，剩余空间比 test 小；此结果不证明 UAV 无信息，也不排除其他入口能学到收益。

建议不延长旧 N2 / shared 的同配置训练；先完成 J1 的内容及 donor 归因。不要据此立即重划数据、重训所有臂或声称数据集已被排除为因素。

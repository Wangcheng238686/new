# Native空间干预后独立复审（2026-10-22）

本次独立读取四项完整paired分析、16图路径分解、32图错误统计及两个诊断runner。未运行新推理或训练。query四格仍在运行，以下不补写其结果。

## 1. 目前能交付的可信结论

**对当前geometry训练E10固定模型，在这459张开发测试图像上，正确几何改变了计算，但没有展示超越删除字段的整体收益；打乱几何会造成损害。不能再将模型相对卫星的全部增益称为正确几何推理增益。**

三件事可以同时成立，并不存在逻辑悖论：

1. geometry训练的权重优于zero训练的权重；
2. geometry训练的权重在推理时删除几何后仍然有效；
3. 错乱的非零几何会损害该权重的输出。

前者涉及训练得到什么函数，后两者涉及给定函数的即时输入作用。任何一个都不能代替另一个。

正确字段并未证明优于zero；这不是用“不显著”证明两者等效。事实上zero在Boundary 1%有正区间，zero_rms三项均正，进一步反对当前固定函数中正确字段具有必要的正向边际收益。zero_rms是参照correct残差幅度的诊断函数，不能用其得分冒充一个不需正确几何的正式模型；其作用是反驳“zero只是因为注入小所以更好”的单一解释。

shuffle联合置换支持像素上的四维字段，边际分布和支持不变；但破坏空间自相关、高度与dx/dy一致性以及卫星条件对应。因而其变差证明模型对空间组织敏感、扰乱会有害，**不能单独证明正确几何提供了净正信息，更不能认证真实标定正确**。RMS匹配不消除这些分布外因素。

## 3. 对主代理最新解释的收紧

### “存在强卫星适配路径”是结构事实，“它提供了全部收益”还不是

zero仍通过卫星query、RoI读取、卷积bias、GELU、alpha和UAV支持。因此原始净增益有明确的归因混淆。但目前尚未隔离query、bias及支持的作用，不宜在四格完成前写成“强卫星路径已被证实是收益来源”。即使query贡献正，也可能有与几何、支持的非线性交互。

### “纠错与新增错误抵消”是结果描述，不是根因定位

32图2882个bbox匹配实例的统计可信地展示：correct比zero保留内部更好，但边界、外部错误更多。它支持字段修正未完全符合目标mask，而不能判断错误来自投影、遮挡、字段语义、标注、训练不足还是消费算子。

该审计不是全459图，排除未匹配实例，像素可重复计数，也不等价于AP匹配。因此它可解释“为何局部有修正但AP不涨”的可能过程，不能精确分解整套AP差额。无需为交付再无限细分像素统计。

### 相对高度首层RMS大，不代表模型因高度先验失败

16图整图盒分解显示高度项比dx/dy更强，排除了几何项数值近零。但RMS受输入方差、通道相关、非线性和抵消影响；它不能给出因果重要性排序。故“高度主导激活”可报告，“高度先验导致不涨”只能作为假说。

### geometry训练后zero保留收益，不等于证明蒸馏/正则

geo-trained zero AP64.7610，zero-trained AP64.4602；同参数量而结果不同，说明参数量本身不是充分解释。但是仍存在训练输入、优化轨迹与单seed随机差异。“几何训练改善了卫星函数”可以作为现象描述，不能升级为已识别的训练机制。

## 4. query×geometry四格是否足够？

它足以补齐**当前固定函数**的主要遗漏：query关闭同时含投影bias，mixer bias、alpha和支持保留，关闭原卫星网络的误操作已由代码排除。geometry-only与sat-query-only各自相对bias-only的比较能揭示两条支路在另一条关闭时的即时作用。

建议最终同表列出四个AP，明确两条预定配对结果，并给出完整模型下几何边际效应（已有correct−zero）。几何在query存在/不存在时效果可能相反；如果如此，应报告条件交互，不应取最有利一格叫几何收益。AP非线性，四格差不是能量或信息量的可加分账。

即使四格全完成，仍无法回答：纯卫星同结构从头训练能否达到同样指标、是否几何改善训练轨迹、训练效果是否重复、真可见性是否准确。这些是不同估计目标，**不应为了穷尽它们延迟当前固定模型结论。**

## 5. 是否必须新增训练？

**为交付本次“当前固定模型”的可信结论，不需要。** 完成已固定四格并验收后，即可停止这条诊断链。上述负面归因和适用边界已经足够明确。

只有用户希望进一步主张下列命题时，才需要新的匹配训练：

- “收益仅来自新增卫星容量”：需纯卫星同结构训练控制，去除目标UAV字段与支持，保持其余流程；单seed仍不能证明普遍等价。
- “几何在训练时有效，推理可删除”：需至少多seed的geometry训练后删除与zero训练对照，避免把一次路径偶然性当机制。
- “新区域有稳定UAV推理收益”：需新区域独立评价及训练重复，并要求正确内容在匹配控制上有优势。

这些训练不是当前交付的必需附件，也不应现在自动启动。单seed geometry优于zero训练足够作为开发证据保留，不能承担“仅容量”或“正则机制”的最终判断。

## 6. 下一步建议

1. 完成现有四格，收敛本次诊断；不再加第五种归因干预。
2. 将native从“已成功几何推理增强”降为“几何训练相关的小幅模型收益；即时正确几何净贡献未获支持”。这比简单称“UAV无信息”或“容量伪增益”都更准确。
3. 继续已授权机制矩阵，但是否保留路线取决于内容对照，而非相对基座单独上涨。不以这次negative结论自动追加架构或监督。
4. 若要做下一个新研究动作，优先有限的实际对应/可见性审计；现有数值分解无法识别该根因。只有找到卫星剩余错误上确有可靠外部证据，再决定消费结构。

单seed、空间相关、名义区间及开发测试反复使用的限制仍然存在。它们限制外推，不妨碍现在交付清晰的固定模型结论。

# P2冻结跨尺度迁移探针

日期2026-10-15。关联EXP-0006/0007。用户授权补P2探针；本轮没有训练、没有随机新增模块、没有修改生产结构或默认配置。

独立实施、smoke及正式结果审核均PASS。

## 1. P2是什么

在当前FPN中，P2是最高分辨率输出，stride4；512×512输入对应P2 128×128、P3 64×64、P4 32×32。实际张量shape已核验，P2/P3均512通道。

P2有3657/4496（81.34%）GT RoI直接读取，P3为839；这说明补P2有覆盖依据，**并不证明直接加一个已有融合器就有效**。

## 2. 当前结论

冻结E72并借用现有P3融合器，将UAV原生投影到P2后，mask结果基本持平：预定弱注入条件segm AP仅+.0121个百分点，GT框IoU差−.0000319，探索性区间均跨0。正确配对也没有稳定优于错配供体或上采样对照。

**三项预注册支持门均未通过，因此不进入额外完整检测探针，不扩展到全FPN，也不训练。** 这只关账本轮“现成P3融合器直接迁移到P2”的冻结路线，不能否定适配后/新训P2融合器的价值。

范围：当前冻结开发子集全部153验证图、4496次建筑出现、237栋唯一建筑；不是完整生产开发集或独立test。

## 3. 协议与五组对照

[预注册](probes/results_20261015/P2_TRANSFER_PREREGISTRATION.md)；[独立实施与结果审核](../reviews/UE_P2_TRANSFER_20261015.md)。

固定dual E72 strict EMA、原P3/P4及SAM融合、PE/high、正确RGB-D与目标几何。一次原RPN/bbox生成的框与score保持不变；只修改传给mask head的x[0]。所以AP应称**固定原检测框和分数的条件分割AP**，不是新P2模型完整检测推理AP。

只读hook捕获正确/供体BEV与原P3融合实际残差。原生P2路径：生产BEVToSatellite将BEV投影到128²，再调用已训练P3融合器，以P2卫星特征作为gate输入，得到R2=fuser(P2,U128,Q128,C128)−P2。正确/供体使用相同Q/C和相同权重。没有新训练或随机参数，但P3→P2的gate、GroupNorm、通道统计存在分布迁移。

## 5. 预注册落判

- 主迁移门：q相对baseline条件AP≥+.005且区间下界>0，同时GT框IoU≥+.002且区间下界>0：**不通过**。
- 配对RGB门：正确q相对供体q条件AP≥+.002、GT IoU≥+.001且GT区间下界>0：**不通过**。
- 原生细网格门：正确q相对上采样q同上述附加阈值：**不通过**。
- 进入额外完整RPN/bbox联动探针：主门未过，**不进入**。

弱注入有效残差全图范数比均值2.255%，最大3.276%；压力组均值9.019%，最大13.103%；P3 learned alpha=.1020679。不属于数值爆炸，也不能由非零范数推断有用内容已被读出。现有mask路径对这种跨尺度迁移变化响应很弱，不能进一步单独归因到BEV内容、P3融合器或下游读出某一项。

## 6. 下一方向边界

本轮结果不支持“只把现成P3融合器再接P2就能即时改善”，也不给全层融合提供依据。尚未区分：BEV内互补信息本来有限、P3融合器与P2分布不适配、或下游RoI/提示生成没有读取新增内容。不能仅因P2覆盖多数RoI就保证收益。

若继续，应先检查P2变化是否传递到粗提示/点提示，以及冻结UAV表示对卫星难例边界的可读信息；不是立刻扩大层级或全量训练。这些下一探针尚未执行。本轮不改默认配置，不复活历史分支，不训练LoRA/融合器。

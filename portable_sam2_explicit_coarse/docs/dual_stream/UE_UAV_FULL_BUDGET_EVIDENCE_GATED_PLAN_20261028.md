# UAV双流完整预算与消融：按证据推进的候选规划

日期：2026-10-28。状态：规划记录，尚未授权按本表发射新实验。本文件依据侧会话讨论，供主会话后续核定；不修改正在运行的固定E10归因分析、训练配置或队列。

## 1. 先明确：矩阵是待检验假设，不是成果清单

目标是验证“真实UAV证据能改善卫星视角建筑实例分割”，而不是让每一个预设模块、模态、视角数都得到正向结果。不要求所有模块都保留，不因结果不符合预期反复增加loss、模块或训练轮数。

当前模型C只是待验证完整候选，不是提前锁定的最终论文架构。后续消融的目的包括删除没有贡献的部分。一个模块无收益是有效结论，不能自动归咎于预算不足，也不能据此否定整个RGB-D数据集的信息价值。

## 3. 结构主矩阵：分开检验上游与尾部

U定义为整个上游增强模块包：早期几何特征注入、局部双向交互、UAV实例发现头及其训练目标和补框消费。T定义为新尾部头对对齐RGB/显式几何证据的读取。下表四组均保留同一个native卫星掩码修正头，T关闭时将其UAV端口归零。

| 规划组 | U上游增强包 | T尾部证据 | 回答的问题 |
|---|---|---|---|
| S | 关 | 关 | 匹配修正头结构的纯卫星基线 |
| U | 开 | 关 | 上游整体贡献；对应当前B的结构 |
| T | 关 | 开 | 仅尾部直接消费是否有效 |
| C | 开 | 开 | 完整候选及两条路径互补性 |

当前A额外回答“去掉整个尾部头”的问题，可保留为结构参考，不替代S。原单流UDPR基线另列为实际系统比较，不与S的匹配头因果对照混淆。

归因：U−S、T−S为单路径贡献；C−U、C−T为条件追加贡献；C−U−T+S为交互项。不预设必须有正交互。U是模块包，其收益不能直接命名为双向注意力收益。

工程前置：T组必须把对齐证据提取与上游写回分开；不得保留卫星残差注入、双向更新、UAV补框或实例loss的隐形影响。S不读取UAV，相关模块不进入可训练有效路径。四组主任务、native128/目标512、coarse64、增广/实例上限/候选基础策略及评价必须明确核对。U关闭时不再添加UAV实例候选，U开关的总体效应包含候选变化；掩码消费效果另用固定框分析。

## 4. 模态贡献：先限定声明，再选对照

优先在获得支持的结构上检验，不默认所有结构×模态交叉训练。

| 条件 | RGB外观 | 显式几何内容 | 对应关系 |
|---|---|---|---|
| RGB-D完整 | 真实 | 真实 | 实测深度＋相机 |
| 常量RGB训练对照 | 常量，仍走同编码器和相同预算 | 真实 | 与完整组相同 |
| 无显式几何内容 | 真实 | 关闭 | 仍用实测深度＋相机 |

- 常量RGB必须贯穿上游、实例头及尾部的全部RGB消费，不只清尾部；常量来源提前固定，不用测试图估计均值。它控制外观内容，而不删除分支容量。
- “无显式几何内容”必须列清几何CNN输入、候选几何描述、早期几何注入、尾部通道哪些关闭；不能将其称为RGB-only/无深度，因为对应和有效性仍含深度。零值及缺失标记不得产生歧义；要有无支持行为检查。
- 如要声称深度对应本身有效，另做不使用实测深度的标定平面投影基线。投影平面/高度及可见性策略只能由训练/采集约定确定；单独报告覆盖与候选变化，不能把该对照当成只去掉几何通道。
- 固定检查点的归零/错配诊断与从共同初始化训练的模态消融分开；前者含分布外干预，不能替代后者。
- 关闭尾部RGB/几何仅支持尾部局部声明。如需解释完整模型模态贡献，必须用全路径对照。

## 5. 视角数量：敏感性与缺视角鲁棒性分开

候选级别为1/3/5视角，5视角可复用相应完整模型。

1. 五视角模型固定权重，推理时用预定1/3/5视角：仅说明缺视角鲁棒性。
2. 从共同初始化分别用1/3/5视角训练评价：检验采集预算下可达性能。

子集在发射前按采集视角定义固定并记录具体相机ID；不依测试表现挑视角。单视角/三视角若有多种组合，预先指定平衡子集或枚举规则，报告子集离散度；不能把一个好角度代表整个视角数。

移除视角要同时移除RGB、深度及其几何派生影响，重建候选、支持率和视角计数；保证移除视角不通过缓存泄漏。保持每格候选上限等策略和训练更新数，明确视角计数归一化规则与模型有效性输入。另报观测覆盖、有效候选数、耗时、显存；8候选上限下不宣称5视角全部信息被完整消费。

不预设性能随视角数严格单调。平台期可能说明较少视角已够；必须结合覆盖变化判断是否只是新增相机没有覆盖新区域。

## 6. 分阶段准入：不一次性购买理想矩阵

### 阶段0：读完已有归因，不追加重复短训练

核来源/正确推理复现、C权重正确/零/错配、同框掩码、配对区间及分组净纠错。可靠净收益的参考仍为Mask AP差值+.002且名义95%图像配对区间下界>0；更小/不确定信号完整报告，不临时放宽阈值。错误供体含支持/位置不一致，其退化单独不能证明真实RGB内容贡献。

通过只表示值得进一步投入，不表示完整因果链成立。若C固定权重不依赖尾部内容而跨模型C仍更优，应先考虑训练期正则/共享梯度效应，不能直接写成推理时证据读取有效。

### 阶段1：补缺失的S/T与接线审查，明确完整预算协议

S/T先通过对照身份、初始化、关闭路径、数据/缓存及真实资源门。若需要短预算，发射前固定共同预算/判据，现有A/B/C只在严格同合同下复用；短跑不得变成按测试排名反复选结构。

完整训练的最低科学比较是S对一个预先锁定的双流候选；不是必须让U/T/C全上。如果主张两条路径互补，则需要四组共同完整预算。主比较若通过，才追加支持模态/视角声明的训练，避免先铺开所有交叉组合。

100轮是待核定完整预算建议。总轮数、初始化或严格续训方式、学习率、种子、验证选权、评价和主次指标必须在发射前冻结；不根据测试曲线加轮或改loss。本文件不发射100轮任务。

### 阶段2：完整预算验证与训练重复性

锁定结构后比较同预算S/双流，覆盖模型容量对照与训练收敛。检测已联合训练10轮，“只是没学起来”是待检验解释，不是已知事实。训练/验证的分类回归loss、召回和bboxAP趋势帮助判断预算，但不能用更长训练承诺检测必然上涨。

至少对主比较安排预先固定的额外训练种子；图像bootstrap不能替代训练重复。单个新增种子只增加一份重复证据，不构成稳定性保证。每个实验继续四卡，显存允许共租，不改已有任务。

### 阶段3：按获支持的声明补消融

若两消费路径均有条件贡献，开展必要的内部交互消融；若只有一条有贡献，优先简化到该路径。再按第4/5节补模态和视角，不全因素交叉。无贡献组件不强行包装为必要创新。

## 7. 负结果的预定处理

| 观察结果 | 可作判断 | 后续行动与不可声称的结论 |
|---|---|---|
| 归因发现坐标/评价/缓存泄漏错误 | 原效应可能无效 | 修复独立缺陷并重做受影响配对，保留旧产物；不把bug修复当新机制收益 |
| C−B跨模型为正，但C正确/零差异很小 | 可能是训练轨迹/正则效应，推理证据贡献未证实 | 审计梯度/同框效果；若该现象稳定，可研究训练期辅助作用或简化推理，不宣称在线内容读取成功 |
| C正确优于零，但正确与错配接近 | 位置/支持/内容特异性证据不足 | 先审查干预强度和内容对照，不据此认定真实内容必要；追加诊断须事先说明新问题 |
| 完整预算双流不超过S | 主目标在该合同下未成立 | 核查一次具体实现风险及预定训练重复；若无缺陷且重复不支持，停止扩铺模态/视角矩阵，记录负结果；可转向有证据支持的困难子集目标，但重新声明任务与评价 |
| T有效、U无条件追加贡献 | 上游大模块未证明必要 | 优先尾部方案，删除无益交互/补框包；不为了保架构继续堆loss |
| U有效、T无条件追加贡献 | 尾部证据路径未证明必要 | 保留上游方案、去掉冗余尾部证据，单独核匹配卫星修正头容量 |
| RGB对照无明显差异 | 外观内容价值未证实 | 收窄为几何辅助方法或检查读取；不声称RGB-D协同 |
| 显式几何通道无明显贡献 | 该几何编码未证明有用 | 可移除该编码；深度可能仍用于对齐，不能推断深度没价值 |
| 1/3/5视角持平或非单调 | 多视角数量收益未证明 | 核预定子集/覆盖，报告平台与成本；优先较少视角，不只保留最佳组合 |
| 只分割涨、bbox不涨或下降 | 分割质量贡献与检测权衡 | 完整报告；若方法目标只在实例掩码可成立，若目标要求检测同步提高则未达标，不靠改选权掩盖 |

“不显著”不等于严格无效。需同时报告点估计、区间和训练种子变化；区间宽则是未解决的不确定性。每条失败路线至多按明确缺陷做一个有针对性的修订/配对，再无新证据则暂停该路线；新修订必须是独立版本、预先固定预算与判断，不能无限改到测试变好。

## 8. 数据使用与交付纪律

v1 test已用于多轮开发讨论。它是开发测试证据，不能继续兼任独立最终确认集。后续若基于这些观察修改结构/任务，最终结论需要预先冻结且未参与决策的新保留集或独立地理划分；该数据工作另行核定，不在此更改当前数据版本/切分。

每阶段交付：源码/配置/初始化及缓存SHA、准确开关清单、固定预算与选权规则、全部主次指标/负结果、同图差异与训练重复限制、继续/简化/暂停的证据理由。BoundaryAP若报告，沿统一实现/阈值，不看结果换定义；不由loss非零或门控开断言成功。

后续实施先核本文件状态和主会话最新合同，不自动覆写正在执行的归因协议。最终论文结构由证据支持的最简方法决定。

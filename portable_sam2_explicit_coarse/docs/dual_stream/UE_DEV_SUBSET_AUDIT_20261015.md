## 1. 范围与结论修正

这是**当前冻结开发子集的全部153张验证图**，包含4496次建筑出现、237个唯一global building；不是仍在生产的完整开发集，也不是独立测试集。同一建筑出现1–52次，中位数20次，图像及建筑还有空间相关性，不应把4496次出现当作独立样本。

固定双流E72 EMA、单流E66 EMA，无训练、无权重更新。冻结manifest SHA256：`495841b2174242c87661e6b40dba2ddcca13d64b13798116efc8c933c679ca59`。627训练/153验证；模型与数据身份沿用 [首轮结果](UE_AD_RESULTS_20261015.md)。

结论：

1. NMS前存在更好几何候选的现象确实遍布当前验证部分，但单流与双流十分接近。这是共同改善空间，不能据此解释双流净增益弱，更未证明改NMS会提高AP。
2. **此前3图42GT在GT框下双流平均IoU高约.0105的观察不能推广。全4496次出现变为双流低.002304。** 用户对案例代表性的顾虑得到验证。
3. 固定共同预测框时，双流仅高约.0012–.0016；zero/shift仍使mask下降。可以确认对这些UAV干预敏感，但尚不能分离RGB内容、深度/几何条件和分支先验各自作用。
4. 下一步优先做“保持几何、只替换UAV RGB”的冻结检查点诊断，再决定修改融合或重训。此项尚未执行。

## 4. 下一步决定

**优先问题：网络到底在消费多少UAV RGB内容，而不是仅依赖深度/位置条件或学到的分支先验？**

建议下一轮固定当前EMA与全部153图，保留相机、深度、视角顺序、BEV范围、有效性与共同框，仅将五视角RGB替换为确定性的其他样本RGB。供体尽量来自不重叠物理建筑，需先确认供体池及映射；保存映射与数据hash。正常RGB是配对对照。替换仍会产生分布变化，因此其影响不能直接当成真实额外信息贡献。

主评估同时保留完整推理segm/bbox AP与固定共同框mask IoU，并按尺寸和物理建筑汇总：

- 若仅替换RGB的影响很弱，优先检查几何条件、位置编码、query及分支先验是否主导。
- 若影响明显，说明RGB内容与输出相关；再定位检测/FPN入口和SAM入口如何保留有益信息，选择下一轮训练设计。它仍不保证优于独立训练单流。

NMS评分/质量关系作为两臂共有的工程改善项；目前不把它作为UAV净增益不足的主要解释，不凭此立即复杂化模型或加训练轮数。

当前正式AP差仍只有+.1958个百分点，探索性图像bootstrap区间跨0，只有一个seed且使用验证选优检查点，尚无可靠净收益证据。不能由此否定整个数据集设想。完整生产开发集冻结后，应重新核对建筑/尺寸/覆盖/遮挡分布并重复诊断；比较完整训练规模的收益须重新训练匹配单/双流，而旧权重在新数据上的评估仅回答迁移表现。

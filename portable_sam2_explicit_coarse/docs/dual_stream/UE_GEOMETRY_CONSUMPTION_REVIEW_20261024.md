# 几何消费与正式模型成本复核

## 结论边界

当前不能将“高度/高度差有信息，但编码未充分利用”写成已确认原因。已完成的独立实例头两seed证明的是四字段整体在该接口有用；四字段为相对采样中心的世界Z、相邻卫星像素高度差dx/dy、近表面视角计数，常量对照同时替换四项。没有单独隔离高度或高度差。

RGB-D internal四字段真实−常量合并Mask为+.133354pp，名义95%区间[−.083679,+.163880]，四指标均跨零。它不证明零效应，也不证明有尚未被充分利用的大效应。正确RGB相对常量RGB已有正区间，不可用RGB贡献替几何分支背书。正式模型保留几何数值编码的证据门尚未通过；深度的对应/支持作用也不能被四字段对照代替。

## 实际链路与信息损失

来源：`rsprompter/uav/native_geometry_probe.py::prepare_native`、`rsprompter/uav/instance_interaction_probe.py`。

1. camera-Z EXR取R通道，cm转m，经内外参反投影并投到卫星512像素。每像素保留最近观测表面；不是完整三维重建，不能保留所有屋顶/立面层次。
2. height为世界Z减采样中心Z，并非经过局部地面估计的建筑离地高度。输入依次为height/100、clip(dx/10,−5,5)、clip(dy/10,−5,5)、近最近表面1m内视角数/5，另加support。
3. dx/dy是相邻卫星像素高度差，不是除以地面距离的物理坡度。相邻任一点无support时该差分置0，但缺少独立的dx/dy有效掩码，0同时可能表示平坦或差分未知。当前CNN可从support推断一部分情形，尚未证明该歧义造成失败。
4. 5通道经步长卷积与多尺度CNN到U128，再2×2平均到U64；只在U64做3×3局部交互。原始几何跳变需经学习编码保留，不能假定降采样后仍完整，也不能仅凭降采样断言被抹平。
5. support最大池化后任一点即可使目标格有支持；这是观测支持代理，不等于整格可见性/对应可信度。
6. 中心头读取高分辨率U及S′，内部卫星消费者另读回写后的S′。同一回写服务两类目标；梯度冲突仍需实测，未被证实。

## 复杂度核对

直接按当前模块参数逐项计数：几何CNN a/b/c/d/up共202416参数；完整无RGB交互+实例头259893参数。几何CNN占该新增小模块的大部分，但不能因此称其占整个双流模型的大部分；参数量也不是推理耗时。

RGB源使用五视角共享的一套SAM2 Base+权重，并非五套参数；每视角调用完整编码器，之后只消费P0。既有optimizer审计确认有效source LoRA仅patch embedding与blocks0/1共25648参数。`RSSAM2VisionEncoder.forward`实际执行完整encoder，当前P0路径未消费后续深层结果。原深层前向存在可优化空间；不能将删除无效计算的收益算成新信息增益，裁剪必须验证同权重P0/采样/最终输出等价。尚无成体系端到端延迟测量，不能宣称加速比例。

## 正式化决策与下一步

- 可以准备配对联合训练，但不把当前完整探针结构直接定为正式模型。保留必要对应几何与是否保留显式几何CNN是两个决策。
- 先完成既定四字段/常量比较及原路径分解，离线审查中心与原损失对共享回写的梯度；原任务拆检测、mask、UDPR。零范数标不可定义，不用loss数值大小推断梯度。
- 固定现有权重的字段组干预可用于定位height、dx/dy、viewcount敏感性，但会改变联合输入分布，只作诊断；不能替代同初始化的字段组匹配训练来证明各组收益。
- 若需新结构，只选择一个有诊断依据的因素：例如表示有效性或消费入口；不同时改字段、loss、采样及解冻范围，不预设多层/更大编码器能解决。
- 成本审查覆盖整条UAV链路：共享权重参数、有效可训练参数、batch1端到端延迟/峰值显存、五视角编码/几何/交互/新增候选解码分项，以及缓存生产成本单列。测量需相同精度、实例数与热身策略，不能仅比较参数量。
- 正式保留标准是匹配结构/预算下内容净增益与增量成本共同成立；若显式几何CNN未提供可复现增益，优先使用更轻的几何属性嵌入/保留对应与支持，而不是以“理论上深度有用”保留整支。新的轻结构需重新验证，不称已可无损替代。

本复核没有改变原14臂/119项的冻结代码、训练及选择规则，也没有启动额外训练。

- 有支持像素486813240/561512448；height/dx/dy/viewcount四个归一化输入的有支持像素RMS依次.439875/.382138/.373148/.559697。未见四字段整体相差多个数量级，不能优先把失败归结为数值缩放；也不证明所有局部投影/梯度量纲都无问题。
- dx/dy分别在468126669/465644554个有效邻接对中，约.20646%/.20165%达到clip上限。全局比例不大，不能因此排除截断集中在关键建筑边缘的影响。
- 在全部有支持起点中，邻点缺测或图像外缘导致的差分未知分别3.83855%/4.34842%；但在“输入为零”的有支持起点中，未知分别占15.7770%/25.6356%。有效差分数值为零还可能含真实平坦与float16舍入，不能将剩余部分全部叫平屋顶。缺测零值歧义存在，尚未证明它造成AP损失。
- 将原始support按8×8合并到64²格，仅作为覆盖代理：有支持格8379638/8773632；其中全64像素覆盖5247562格。非空格原始覆盖率p25=.9375、中位=1，最低1/64。不能把所有交互格描述为普遍稀疏，也不能把max-pool有支持等同整格可靠可见。

因此当前不优先追加全套尺度修补或更大几何网络。保留“差分有效性歧义”和“关键边缘截断”作为可定位疑点，等当前四臂联合结果分离实测深度整体价值后，再决定是否需要单因素编码/消费对照。该审查未改变正在运行的任何数值源、loss、训练预算或选权规则。

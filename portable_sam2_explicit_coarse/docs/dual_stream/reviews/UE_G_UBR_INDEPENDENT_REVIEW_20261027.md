# 独立审查：完整 G 双流 + 统一 UBR

日期：2026-10-27。性质：只读设计/源码审查，不是实施验收，不启动任务。

## 结论

**有能力实现“UAV 帮助卫星实例分割”，值得进行替换验证；不能把 G 与远端 UBR 的两份阳性结果相加，声称这个组合已经成立。**保留补充实例头与直接实例监督合理。当前方案不是无压缩表示，也不是多视角 RGB 已在 UBR 直接消费；首版明确只有几何进入 UBR。最需要优先核定的是训练邻居来源、连续输出/初始化行为，以及 250 实例资源。

## 实际结构核实

1. UAV RGB：5×512² → 源 Hiera 前两个 block/P0 → 256→32 通道 → 深度/相机对应的最多 8 候选（每视角最多 2） → **G/detail 仍按有效候选均值汇总 RGB** → 与旧几何 CNN 的 U128 融合。
2. G：保留候选七维几何 → MLP32 → 卫星 block1 的 128²/112ch query 读取候选 → 32→112 零初始化残差写回。G 的学习候选选择针对几何，不是 RGB Q。
3. 旧内部交互仍在：U128→平均池化 U64，先 UAV query 读取卫星局部邻居，再卫星 query 读更新的 UAV，写入 block4 64²/224ch。它有 SAT→UAV→SAT 路径，不能称纯 UAV 证据。
4. 补充实例头直接消费 U128 与上采样的已更新卫星特征，监督中心/偏移/尺寸；UAV 信息并非全部先降到 64²。
5. 原 RPN/RoI 候选与补充候选最终共用 SAM2 和新 UBR。保留现有合并/评分规则意味着补充框仍不是统一经过原 RoI 分类器的新检测器。
6. UBR 首版：32 解码特征 + 概率/SDT/邻居各1 + 几何5 = 40ch，hidden48/7残差块；预测边界带内重分类、带外保持。几何5来自原生512²栅格最近表面摘要，不是 G 的8候选张量。UDPR及其 margin loss 从新活跃模型移除。

核查源码：candidate_detail_interaction.py:47–100；instance_interaction_probe.py:115–148；compact_joint.py:62–78；geometry_inputs.py:candidate_arrays/native_arrays；data/ue_candidate_evidence.py；rgb_p0_encoder.py。UBR核查对象为 0d21759e13873186234f501a090fa29e13fe542b 的 rsprompter/uav/ubr.py，本机尚未实现替换。

## 压缩与消费评价

**压缩仍显著存在，但不等于不可用。**原始深度/内外参先转为有限对应和几何字段；候选生成按目标格/源token去重，每视角截2、总截8，不能重建被删掉的表面。RGB只用浅层P0且降32维、均值聚合，跨视角差异会丢失。G避免在选择几何之前先变为单表面，但最终仍是32维加权和。UBR几何则先按卫星最近表面压成height/dx/dy/viewcount/support；立面只有在实际投影和保留规则允许时才贡献，不是完整立面模型。

消费职责合理：早期 G/内部交互可以影响检测和掩码，补充头帮助发现，UBR负责已发现实例的局部形状。**UBR不能找回没有候选的实例，也不能修复超过带宽的错误。**高分辨率几何为UBR提供不经过U64池化的直接证据，但上采样32通道decoder特征本身不会创造原来不存在的卫星细节。

## 风险与必须核定事项

### 高优先级：邻居来源的训练/推理合同尚不完整

文档要求使用预测而非GT邻居，方向正确；但需要明确训练时哪些实例参与邻居图。仅将已按GT匹配的正RoI掩码相加，会缺少推理阶段的误检、重复候选和补充候选；大量训练重复RoI也可能人为提高邻居和。需要明确候选筛选、去重、自身排除、精修前同步状态、是否包含补充候选以及detach规则。不能用GT实例数量/GT邻居代替。首版至少做固定训练样本与推理样本的邻居数值/密度分布核对，并公开训练集合与推理集合差异。

### 高优先级：绝对带内重分类不是恒等初始化

新合同 z_final=(1-B)z+B*(b+r)，零初始化r=0意味着带内连续logit变为b；即便推理对零输出回退原mask，训练logit也不恒等。主mask对原decoder的带内直接z梯度被截断，仍可通过UBR解码特征间接回传，但零输出层初始化的第一个更新不向UBR前层传梯度。不能同时宣称零初始化保持原连续预测、主mask始终原样训练。需要实际单步/多步梯度与初始loss门，监测早期掩码和边界退化；如果失败，再单独考虑identity/residual起步，不能悄悄改合同。

### 高优先级：原来源的边界空值行为不能原样搬用

来源 signed_distance_transform(empty)=0，随后band_mask会产生全图带，和本机“空掩码不能全图可修改”的要求冲突；来源full mask也需明确定义图外边界。新实现必须显式处理empty/full/图边缘，补充无支持不是关闭整UBR的门。按部署阈值而非隐含0.5构造二值mask，mask概率、b+r与loss目标必须一致。

### 高优先级：小参数不代表低计算成本

40→48的3×3输入卷积加7个48→48的3×3块，在512²上约42.6G MAC/实例，250实例约10.65T MAC（只计卷积，不计其它模块/反传）。推理分块降低峰值显存但不降低总计算；训练如果分块forward后统一backward，仍保留所有激活，不能声称分块自动解决显存。GroupNorm空间统计使裁剪不等价。先测单实例真实反传、实际正RoI数量下整步训练以及250实例推理时间和显存；需要时用activation checkpoint，而不是无声明改变空间窗口。不能用约0.2M参数判断可部署，也不要同时为每张图的250实例保留全512²反传图。

### 中优先级：几何重复与RGB捷径

G、旧几何CNN、UBR用同一观测的不同摘要，有互补可能，也有冗余。首轮保留是为了不混入删分支因素，但最终需要G早期模块开/关×UBR几何开/关，不应把整条旧交互/补充头一起称G开关。SAT→UAV反向读会使常量RGB也能获得强卫星内容；新Dc只改变UBR端口，只能判断尾部几何，不证明整条RGB必要。已有RGB正确/常量证据应保留，新模型若要声称RGB贡献，需要匹配内容训练对照或至少明确证据边界。

### 中优先级：小实例、候选与训练动力

8像素带对窄小实例可能覆盖整个实例，本质上不只是局部边界；固定训练集统计带占前景/实例的比例，按尺寸报告净纠错。中心格碰撞、3×3峰值抑制、NMS及补充候选手工低分追加仍在，UBR不能解决这些候选阶段问题。已核对CompactJoint.loss：原satellite.loss负责RPN/RoI/mask，补充头outputs只进入center_loss_fn，没有将补充框直接纳入训练RoI/掩码监督。新UBR沿用原训练接线时也从原正RoI学习，却在推理处理补充框；补漏小框的定位/尺度/掩码错误分布可能更差。开工前需明确该差异，按候选来源分别报告尾部收益和新增损害，不能称所有候选已端到端统一监督；是否把补充框加入训练属于另一个候选策略改动，不默认混入首版。

## Loss评价

det四项各1、final mask1、coarse0.1、UBR0.1、实例1（center+offset+0.1size）是可解释的固定首版；它替换而非大量减少监督。UBR带内focal+Dice与全图final BCE职责有重叠，但尺度/分母不同，不能凭权重0.1认定动力足够或微弱。主mask、带内loss、中心目标对共享decoder/G/RGB参数的梯度范数与余弦应离线检查；不可动态参与首轮选权或权重调节。训练带由预测产生且detach是合理首版，但选择边界本身不可微，不能声称模型能通过选带梯度主动扩大可修复区域。

## 最小必要验证（不追加新大结构）

1. 写清并验收上述坐标/阈值/邻居/初始化/空满mask合同，测250实例实际成本；这是长训练前门。
2. 单流UBR对旧UDPR，双流D0对旧G+UDPR，确认替换没有用另一处退化换边界上涨。
3. 同上游D0/Dc/Dr，Dc保留支持且只常量化UBR端口；Dr-Dc才是尾部几何内容差。
4. 按预固定协议检验Mask AP/AP75/Boundary及困难小目标净纠错，分原卫星候选/补充候选，报告未匹配实例/漏检/新增误检；单个Boundary阳性不能代替实例AP。
5. 替换成立后才测G早期开关与重复消费者精简。正式效力需完整匹配预算；工程短跑不能用阴性淘汰方向。

**审查建议：有条件推进当前收紧版本。它保留发现能力，并提供更直接的形状消费者；并未解决全部RGB压缩，亦未证明所有多视角内容必要。不建议此时加Q、RGB到UBR或新的辅助loss。**

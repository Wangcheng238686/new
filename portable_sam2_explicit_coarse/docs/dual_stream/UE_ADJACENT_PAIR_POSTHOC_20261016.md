# 事后补充范围（不改变原主指标）

全量统计与六例首序案例读图之后，出现两项具体解释风险：失败可能主要来自图边小块；GT整栋可能被拆成若干屋顶预测。因此只用已有工件补充：

1. pair按任一GT触512画面边缘、任一GT面积<32²px（COCO固定small界）分层；两栋均非small且均不触边作为敏感性组，不重新定义主集合。
2. 对每个原主匹配未通过的GT，标记“多块覆盖代理”：存在两预测，各覆盖该GT≥25%、各预测≥50%像素在该GT内；两预测互IoU≤0.1，合并后覆盖该GT≥50%。这只是不相交局部块可解释整栋的几何代理，不是已证过分割因果、人工标注类别或新增主判定门；不能用它比较/选择未来模型。
3. 汇总失败pair中至少一栋未匹配GT带该代理的数量，以及GT框条件下两mask都过线的数量。允许与漏候选/排序等共存。

所有阈值在此补充计算前固定，不搜索阈值或声称验证预注册的过分割假设。原协议全部结果保留。

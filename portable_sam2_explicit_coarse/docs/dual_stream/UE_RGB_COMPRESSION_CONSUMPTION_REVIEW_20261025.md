# 三代理深审：RGB 信息压缩还是消费不足？

审查者：`rgb_information_deep_review`（编码与聚合）、`rgb_consumer_deep_review`（消费者与梯度）、`rgb_causality_deep_review`（归因与对照）。均只读审查实际 source 和已落盘证据，未启动新训练或修改现有协议。

## 联合判断

目前最具体的候选机制是：**查询之前发生视角/空间信息汇总，后续双向交互又允许几何与卫星特征完成任务，从而使精确配对纹理的边际收益较小。** 两个结构事实均可核验；但谁是当前 AP 的主因尚未被因果验证。不能将此写成已发现决定性 bug。

三方一致不支持以下泛化结论：RGB 全部被压没、当前消费者仍冻结/梯度断开、256→32必然不足、所有问题来自域偏移、旧辅助梯度压倒主任务的诊断适用于当前联合训练。

## 1. 当前真实链路与不可逆点

```text
5×RGB 512²
 → Hiera patch + 前2个block（stride4 / 112维）
 → 固定P0 lateral（256维；没有深层top-down语义）
 → 可学习256→32 + 每token无affine LayerNorm
 → 连续source_uv读取最多8候选
 → 候选等权mean（128²；视角/表面不再独立）
 → 与几何CNN特征拼接卷积
 → 2×2 avg_pool（64²；子格不再独立）
 → UAV读取卫星3×3邻域 → 卫星读取更新后的UAV3×3邻域
 → 32→224写回block4，后续编码/检测/分割消费
```

证据：`rsprompter/uav/rgb_p0_encoder.py:20–51`、`instance_interaction_probe.py:69–84,113–148`、`attention_ladder.py:19–38`。

### 已证实的有损压缩

候选均值对排列不变，两个候选分别改变 `+δ` 和 `−δ` 可使均值严格不变。后续 query 无法恢复被抵消的视角区别。源view ID、source_uv、satellite-Z未作为候选属性显式送入此RGB均值器；隐式位置特征可能残留，但不保证可恢复。之后2×2均值进一步消除子格差异。这是**先汇总、后选择**，不同于旧J1直接由卫星query读原始候选。

这只证明某些信息不可恢复，不证明丢掉的是有用信息；对齐的相同表面跨视角均值也可能降噪。需要把阶段信息变化与实例任务质量变化关联。

### 编码侧限制与不能混淆的事项

- 当前读取是浅层局部描述子，非完整深层SAM2语义。前两层8×8窗口的名义原图依赖范围约35×35像素，正确source_uv仍可能读到跨表面混合描述子；特征不只代表该一个三维点。
- 实际参与P0的source LoRA约25648参数，不是全source声明的约106万都对任务可达。见已有有效路径审计和 `UE_INSTANCE_INTERACTION_INTERIM_20261024.md`。
- compact删掉后续source block没有新增这一限制：后续层本来不影响lateral-only P0，完整/compact配对输出已审计相同。
- 256维来自112维的lateral扩展，不能机械解释256→32为丢失八分之七有效信息。
- 连续坐标读取沿用已核定kernel7/stride4/pad3中心合同，本次没有发现需要另补半像素的错误。

## 2. 常量臂能做什么：无需纹理的替代路径

`data/ue_joint_inputs.py:24–59` 中常量RGB只去掉纹理，仍保留实测深度生成的高度、导数、观测计数、支持及候选对应。source中位置编码也保留，常量图并不一定得到全空间恒定特征。

`instance_interaction_probe.py:125–140`：

```text
u（几何+RGB）作为query读取卫星value → upd
updated_u = u + 0.2·upd
卫星再读取updated_u → 写回卫星
```

所以常量臂也能以几何query重组卫星邻域，形成 SAT→U→SAT 条件适配。实例头同时读取high_u与high_s（143–147行），又提供无需纹理的求解路径。这是有意的双向交互结构，不是bug。

已有遥测只给总delta/base RMS，未按几何、RGB、卫星复制值分解，**尚不能断言模型主要走了捷径**。主/辅损失能反传不等于它们要求使用独有RGB证据。

## 3. 梯度与内容证据的边界

当前 `compact_joint.py:66–79` 没有包住卫星extract的no_grad，原主任务损失与实例损失都参与优化；实例监督跨S'，不存在全局梯度断路。

当前joint E10固定8个train样本、eval/noaug诊断：

| 参数组 | 主损失范数 | 实例辅助范数 | 平均余弦 |
|---|---:|---:|---:|
| source LoRA | 0.304 | 0.311 | +0.069 |
| RGB融合 | 0.905 | 1.102 | +0.022 |
| 写回 | 0.554 | 0.157 | +0.009 |
| attention | 0.255 | 0.209 | -0.033 |

源：`ue_compact_joint_20261024/joint_loss_direction/epoch10/complete.json`。方向近正交且部分样本冲突，但不是旧冻结实验中辅助在source上数十至数百倍占优；范数/余弦不能直接代表AdamW有效更新或AP损害。

新实例internal已有正确训练−常量训练Mask +0.1937pp（95%CI[+0.0613,+0.3434]），原卫星路径 +0.1428pp（[+0.0128,+0.2658]）。同权重正确−常量RGB +0.3123pp（[+0.1907,+0.4469]）。这些反驳“RGB全部丢失/完全不被有益消费”。

但正确−donor RGB的Mask +0.08675pp（[-0.002735,+0.191038]），对应性仍弱；Boundary2% +0.09409pp（[+0.000259,+0.194343]）刚好为正，须保留这份弱证据，不能笼统说所有配对指标都无信号。单seed、多指标开发探索下，它不能升格为稳定Mask收益。

旧J1 donor为`(i+1)%N`；新实例/联合计划donor为`(i+N//2)%N`，不应都称相邻donor。两者均保留目标几何，不是物理一致的RGBD场景替换。

## 4. 原图对齐审计与信息独有性

固定8张train×5视角：深度warp卫星/UAV ZNCC均值0.862、参考平面0.298；实际保留锚点原色均值0.9225，稠密观测warp0.9513。没有普遍大位姿错位的证据，但这些是原色相似性，不是学习特征对实例边界/身份的条件信息。

40996/668301（6.13%）保留候选比最近观测表面远1米以上；21607/122417（17.65%）支持格混有近/远候选。简单过滤的原色ZNCC反降至0.9144，不能未经验证删掉全部远表面。

高RGB相关既支持配准，也与大量卫星/UAV外观重复相容。正确−常量强于正确−donor，符合分支部分利用自然纹理共性而不是精确场景细节的解释，但没有直接证明此机制。

## 5. 最有区分力的后续诊断（先不新增架构训练）

### A. 逐阶段信息保留 + 最终实例质量联合定位

预先固定train/val样本，保存正确/donor在P0、投影32维、LN、独立候选、候选均值、几何融合、2×2池化和写回delta处的表征。按边界/内部、单/混合表面及support分层。报告阶段差异、候选间抵消比例，并结合原卫星路径的GT最佳可达mask/boundary IoU、召回恢复和损害。

必要时用相同容量的小读出比较“SAT”与“SAT+阶段RGB”的局部任务增量：标签在卫星坐标定义，不伪造UAV真值；按图像/空间组划分训练验证，不随机混合同图像素。它仅测可解码性，必须再用固定权重局部替换与实际质量变化关联。

- 当前P0本来无可用增量：优先查编码表征/原始互补性，不直接宣判原始RGB无信息。
- 候选前有增量、mean后骤减：支持聚合丢掉任务相关信息。
- 写回仍保留差异但实例质量无收益：优先查消费者/与SAT冗余；只凭RMS不能区分。
- 形状最佳质量改善但AP不改善：先查分数、重复候选和排序，而非继续换融合模块。

这不是重复L1/L2训练：L1已经采用，旧L2发生在不同冻结末端组织，不能替代当前均值链路定位。

### B. 卫星复制项的2×2因果敏感性检查（次优先）

在固定完成检查点上，对正确/donor RGB分别开启/关闭 `.2*upd` 及实例头对应ur项，保留其他输入、参数、query和几何；分开原路径与合并路径。对照当前已有正确/常量/donor计划，新增只定位SAT复制回流。

若关闭后正确−donor差扩大且正确质量保持，支持复制路径稀释RGB价值；若所有输入均恶化，只能说明路径被用到，不能证明它妨碍学习，因为关闭是推理分布外干预。不得据此直接删路径重训。

附加的保纹理统计空间打乱/位移应绑定A的定位结果再决定：它可以区分精确对应与自然纹理共性，但也不是物理一致反事实。

## 6. 当前决策

优先嫌疑是**查询前的均值汇总与可替代消费路径共同作用**；明确瓶颈位置仍待A的任务相关定位。维度宽度、深层source、额外loss均不先开新臂。当前四臂继续原100epoch协议；同E28验证RGBD83.6580、常量84.4334，不能中途按排名改结构或挑epoch宣布胜负。

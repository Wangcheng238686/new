# UAV 双流阶段证据独立审查（2026-10-22）

## 审查范围与总判断

本报告由独立子代理完成。读取阶段报告后，抽查原始配对分析、native 两组2670条训练记录、恢复合同和实际训练源码快照，并阅读候选构建、注入及新 S²DB 代码。未启动训练、未修改运行任务。旧 test 当前仍为17/19推理、11/15比较完成；未完成 early/contextual 独立训练对照不补作结论。没有重新计算全部 AP 或复核全部原始图像，所以下文是独立证据审查，不是最终产物验收证书。

**主代理的保守判断大体可信：存在小幅几何分支信号，RGB 的整体内容收益未成立。但“几何被利用”应限定为这对固定训练及这批图像上的内容控制证据，尚不能升级为正确空间配对依赖、可重复的训练收益或新区域泛化。**

我最主要的异议不是数字错误，而是下一步重点：当前最稀缺的是对“正确局部证据”的因果解释和收益重复性，继续扩大 RGB 架构搜索的证据基础偏弱。

## 1. 分层裁决

| 命题 | 裁决 | 原因 |
|---|---|---|
| 分支接通，新增参数能更新，残差能到达解码器 | 已有充分工程证据 | 梯度、恒等性、参数及卫星冻结审计；注入/接收RMS比明显非零 |
| 原始 RGB 失败是门控接近零、信息完全没进模型 | 不支持 | 实际扰动约接收特征RMS的75%；alpha不是门控开度 |
| cm/m 或 RGB 重复归一化是本轮已确认根因 | 不支持 | 代码显式单位转换，未见双重归一化；大特征RMS不是物理量错误证明 |
| 几何分支在固定 v1 test 上有小幅净收益 | 支持，有条件 | Mask AP +0.1797pp，名义图像bootstrap区间为正；单次训练，且未达+0.2pp参考线 |
| 四字段组优于同结构零字段训练 | 支持，有条件 | +0.2705pp，三个指标名义区间为正；匹配初始化与数据流证据较好 |
| 正确位置的几何形状是上述收益的必要原因 | 缺失关键证据 | 未见 native 固定权重空间错配、保留分布的字段扰动；高度先验、覆盖属性和学习轨迹亦可解释部分收益 |
| 正确配对 RGB 稳定提升整体实例 AP | 尚不支持 | unit 的训练内容差+0.0615pp区间跨零；正确输入未胜过固定权重constant/donor |
| unit RGB 对更严格 Boundary AP 有内容信号 | 仅提示 | 单个指标名义区间正；存在多指标、多路线探索以及固定权重干预不支持整体优势的问题 |
| UAV 本身没有额外信息、强卫星模型已无增益空间 | 不支持 | native 有正信号；没有建立正确对应下的信息上限或剩余误差分析 |
| 分辨率损失是旧 RGB 失败的唯一根因 | 不支持 | native 同时换了表示、查询、算子和参数规模；不是分辨率单因素实验 |
| 数据集足够支撑三维点恢复，所以实例边界应自然可解 | 不成立的推论 | 可见表面没有人工实例身份，卫星遮挡与标签归属仍未自动解决 |

“注入存在”“内容有用”“正确配对有用”“训练可重复”“独立测试泛化”是五个不同层次。目前最强证据到第二层，第三层仍需约束。

## 2. 几何内容对照是否可信？

### 2.1 对照匹配程度比普通独立训练要好

实际 native runner 快照在建立适配器前重置 seed45，建立后重置 seed44。geometry/zero 使用相同类、同一初始化代码和相同损失、优化器、训练预算。zero 只将四个字段置零，保留支持、卫星 query 和同一个卷积模块。

额外抽查两条 `train.jsonl` 的全部2670行：

- epoch、update对应图像进度、学习率、AMP scale 完全一致；
- 最后调用的 support_fraction、base_rms、RoI数逐行完全一致；
- 两者 clip 前梯度范数均未超过0.5，没有一组被频繁裁剪导致的显见混淆；
- 两者原始合同的 native runner/source SHA 相同，均从公共E9恢复，E10重置为同一1044010种子。

这不是逐张样本顺序及增强的完整回放证明，但强于“仅口头称相同 seed”。未发现明显一边少训练、不同学习率、不同AMP缩放或不同接收特征导致的伪比较。

### 2.2 对照仍然不能证明什么

zero 将四个输入通道恒置零后，其对应卷积权重没有数据驱动梯度；geometry 的这些权重有梯度，alpha最终方向也不同。因此两组不会有相同优化轨迹。**这是内容干预的正常结果，不足以推翻对照；但一次训练差异不能排除优化偶然性，也不能单独证明逐位置内容依赖。**

native_zero 仍读取目标 UAV 支持以及局部卫星 query；它不是卫星单流。真实字段组包含高度、高度差与近表面视图数，增益不能全部叫“建筑三维形状”，更不能叫RGB增益。绝对相对高度、观测次数和场景类型的相关性也可能提供容易学习的先验。

对照证明的最窄表述是：**在当前训练协议和固定 v1 test 中，提供这些目标相关字段比删除字段更好，并且最终权重优于卫星基座。** 需要固定权重下的空间干预，才能进一步问模型是否依赖正确位置的局部几何。

### 2.3 统计结论的边界

原始 `content_paired_analysis.json` 的 Mask 增量为0.00270501396，名义95%区间[0.00070610979,0.00297962203]；净增益为0.00179677605，区间[0.00047726366,0.00232924782]。数字与阶段报告一致。

图像配对bootstrap回答“这两份固定预测在这些图像的重采样下差多少”，不回答“换训练种子还能涨多少”。场景空间相关降低独立信息量，多路线与多指标探索令名义区间不等于家族错误率受控的确认。AP非线性和重复分数可造成区间不对称，不能只凭区间不包含原点估计就认定代码错误；已有恒等与重复样本校准提高了实现可信度。本次未发现足以推翻结果的bootstrap实现证据。

这份 v1 test 已被用于方向决策，后续固定新矩阵并不重新使其成为未触碰测试集。可以继续作为开发评价，但正式结论需要独立最终区域。

## 3. 数据能否支撑目标？

已有数据确实提供卫星RGB、独立实例mask、五视角RGB-D和相机参数。深度回投影覆盖大量目标，说明有进行局部证据研究的条件。未发现必须先重做整个数据集才能开始的证据。

仍不能从覆盖率推出有效可用信息：

1. “离卫星最近的 UAV 已观测表面”不等于真正卫星可见表面；卫星未被UAV观察到的遮挡物不会出现在该z-buffer中。
2. 原始深度/位姿代数回环只验证同一公式自洽。像素中心、渲染RGB/深度同步、可见轮廓及实际物体表面的跨模态对应尚缺独立实证。
3. 旧数据历史问题与本轮最小归档要分开。旧模型曾训练到新test中的454/459张，不能继承为干净正式初始化；本轮EXP-0017从generic新训，当前没有该继承污染的证据。
4. 当前target split隔离不等于所有UAV输入互斥。已有文档报告部分train UAV视域与val目标AABB重叠；AABB不是像素泄露认证。报告称test目标交叉为零，但本次未独立重跑该审计。
5. train/val/test密度58.9/32.6/98偏移与基座val→test大跌是实际问题。不能要求一个被冻结检测器的局部分支修复全部偏移。

**可见几何丰富，与“卫星已有判断之外的增量证据丰富”并不等价。** 真正相关的是卫星出错的实例上，UAV是否有对齐、可见、目标相关且标签可解释的证据。当前尚无这个条件集合的完整审计。

## 4. RGB 失败原因：按现有证据排序

| 优先级 | 解释 | 事实部分 | 尚待验证部分 |
|---|---|---|---|
| 高 | 分支学成几何/卫星条件适配，RGB被弱使用或无益使用 | unit常量训练本身有收益；正确输入未优于固定权重constant/donor | 依赖的是几何元信息、卫星query、均匀残差还是外观，尚未完全分解 |
| 高 | 原始外观残差数值条件差 | 原始输出RMS数百，constant令注入减约14倍；unit显著改善条件 | 归一化仅证明条件改善，不证明RGB变成有效内容 |
| 中高 | 锚点或可见表面与目标证据不一致 | 内部回环不认证实际RGB对应；保留多个表面且无真卫星遮挡GT | 不能在没有独立像素核查时称系统性错位已确认 |
| 中高 | 候选压缩及稀疏读取丢掉细节 | 4px目标格、8候选、每view2候选；细边界保留率下降 | 这些丢失的内容是否是AP增量来源，尚未隔离 |
| 中 | 源特征对任务不合适/训练信号绕过RGB | fine高分辨率层不是完整深层语义；更新不等于语义学会 | contextual没有收益不排除其他表征，但也不支持无止境更换骨干 |
| 中 | 冻结解码器、coarse和UDPR限制可表达修正 | 所有训练梯度经过固定消费路径；检测框/分数不变 | native能涨说明入口并非完全不可用；尚无证据将其定为首要瓶颈 |
| 中低 | 监督不足或梯度冲突 | 无直接UAV标签，只有最终mask梯度；当前没有分支监督 | 同一监督下几何可学，不能直接断言“必须加loss” |
| 低/未发现 | 单位、RGB归一化、分支完全无梯度 | 代码和遥测与这些解释相反 | 局部数值及实际标定仍可查，但不应再泛泛归咎cm/m |

量纲判断的代码依据：`payload()`读取0–255 PNG后BGR→RGB；`LocalUAVAdapter.encode()`仅做一次 `(image-mean)/std`；`RSSAM2VisionEncoder.forward()`直接调用encoder；实际外部仓库 `../sam2/sam2/modeling/backbones/image_encoder.py`将输入直接传给Hiera，`hieradet.py`从patch_embed开始，没有再次进行像素均值方差归一化。候选和native构建均读取EXR索引2（OpenCV的R），除100；`camera_arrays()`同时将两个外参平移除100。这支持“未见重复归一化或明显单位错误”，不认证渲染文件数值语义必然正确。

另一个容易忽视的瓶颈：检测候选及分数被冻结，分支无法替缺失实例产生候选，也无法通过重新排名释放所有掩码改进。当前探针只回答“已有候选上的mask消费”，不是完整检测增益评估。

## 5. 新 S²DB 矩阵能回答什么？

四格 fixed/local × normalized/concat，加constant及zero训练，能够估计局部读取变化、局部卷积/直接卫星query消费变化及其交互。共同初始化、明确训练内容、离线梯度及纠错区域统计，比只有最终AP更有辨识力。预先固定D辅助分支避免按test挑模块。

但它只覆盖部分解释：

- local在同一保留锚点附近±4源RGB像素读取外观，不补回已丢候选，也不重建对应世界点；失败不排除更大错位或缺证据。
- 缓存坚持旧index/geom相等是复现实验优点，同时固定了原128²压缩和潜在锚点问题。
- concat同时改变算子、query直通、容量与局部感受野；不能把C−A叫单独“融合方式效果”。匹配constant/zero有助于收窄归因，无法将所有组件分离。
- zero聚合保留支持和卫星query；constant仍有几何key/value。两者用于不同问题，不应称任一为彻底“无UAV”。
- auxiliary是query条件化UAV聚合对卫星语义union的监督。它能促进前景可预测性，不能直接要求不同建筑分开，不能认证表面对应，也可能学习类别/位置捷径。
- 所有臂仍同一冻结decoder、来源骨干、候选集合和单训练seed。矩阵全失败不能证明RGB没有信息，全成功也需匹配内容证据及独立泛化。

**建议将当前矩阵视为一次有上限的机制排查，不作为继续增加第三、第四种入口的起点。**

## 6. 我建议的最小下一步及停止标准

### 优先一：不新增训练，核查现有最强正信号

在不抢占现有任务的前提下，对已训native E10做一次预先固定的推理诊断组：correct、字段zero、保留target支持的字段空间扰动。扰动应固定seed、GT无关，四字段向量联合置换，保留支持位置与字段边际分布；它故意破坏局部几何，不能视为真实替代场景。

同时报告输出残差的方向变化、实际注入RMS和掩码纠错/新增错误；若扰动显著改变注入幅度，可额外做一个仅诊断用的逐调用RMS匹配版本，不能用其AP作为新模型成绩。零字段与空间扰动各自有分布外限制，下降只能提示依赖，不能独自证明正确语义；反过来，若正确空间结构持续不优于扰动，则应收回“正确局部几何驱动收益”的强叙述。

这组诊断不需要等待新训练矩阵结束，也不改变其合同；但当前GPU都忙时应排队，不为诊断抢停任务。**不再为这一问题追加新结构训练。**

### 优先二：只给对齐问题一个有限的外部核查预算

固定抽取8张train/val，不按AP筛图，选择屋顶内部、可见轮廓、立面/地面交界，检查原始RGB与深度对应点及卫星落点；记录明确正确/错误/无法判定，展示误差而不只展示投影覆盖。预算一次、不要扫参数直到视觉变好。若发现系统性像素或表面错误，先修数据对应并重建干净对照，停止扩大融合模块；若未发现，仍不能宣布全数据已校准。

### 优先三：完成已授权矩阵后必须收口

预先给出三类结局：

1. **RGB正确内容在匹配训练对照上有正向整体Mask贡献，且固定权重干预与区域纠错解释一致：**只保留一个结构，下一步做独立训练重复/新场景确认，不再堆入口。
2. **只有模型相对卫星涨，内容对照无优势，或正确RGB持续不胜constant/donor：**把它解释为新增适配/几何收益，停止宣称RGB增强；不以加更多loss、解冻更多层作为自动下一步。
3. **RGB无可解释内容收益，而native空间证据和重复训练保留小收益：**优先做一个最小深度几何增强方法。它完全符合“UAV信息增益卫星分割”的原始命题，不需要为了双RGB流形式强保RGB编码器。

正式验证只推进一个候选。至少增加两个固定种子的完整候选/匹配控制训练，报告三个种子的全部结果；图像bootstrap与训练种子分开。若收益符号反复、均值仍小于+0.2pp且正确内容优势不稳，停止作强增益主张，保留为弱机制证据。最终新区域测试须独立保留，不能复用已做机制选择的v1 test。

**不建议当前立刻转向检测入口、联合大规模解冻、新边界loss或三维重建头。**它们会改变问题，现有最强信号的正确空间依赖尚未查清。最终联合训练可以是确认后的工程阶段，不应拿来掩盖冻结探针的内容归因缺口。

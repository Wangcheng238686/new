# 原始影像对应核查：训练集固定8图、40视角

## 本次结论与边界

真实深度和内外参确实能把部分UAV外观定位到实际卫星RGB的对应位置。该证据来自两个实际观测图像的内容比较，不是矩阵回环或用卫星GT反贴生成“真值”。它下调“整批RGB/depth或UAV/SAT存在严重系统错位”的优先级；仍不能认证每个点可见、每幅图绝对标定无误、UAV有超越卫星的信息或最终实例AP必然提高。

固定使用v1 train列表等间隔8索引，对应ID1234/1842/2182/2518/2857/3229/3620/3999及全部5个yaw。没有读取val/test图像或实例标签，没有改缓存、相机、样本、模型、loss或在训协议。

## A. 同视角RGB与深度图结构

实现：`scripts/analysis/ue_rgb_depth_image_alignment_20261025.py`。
产物：`/data/wangcheng/checkpoint/ue_compact_joint_20261024/rgb_depth_image_alignment`。

- EXR R为camera-Z，厘米除100。有效邻接深度差大于max(2m,1%较近Z)标两端为结构边缘；RGB固定灰度Gaussian3×3 σ1、Canny80/160 L2。
- 深度边缘到RGB边缘的距离在12px截断。统一排除40px图外缘，40视角共428567个深度边缘起点；局部dx/dy∈[-8,8]和固定±32px控制使用相同点与分母。偏移只用于诊断，未施加任何修正。
- 最佳局部偏移32/40在每轴±1px内，35/40在±2px内；40/40零偏移距离均优于四个32px控制的均值。局部最佳相比零偏移的距离改善中位仅.001673px、最大.430495px。
- 合并48.6729%深度边缘距RGB边缘≤2px，57.9650%≤4px。**这不是标定准确率**：暗部几何轮廓缺少阈值RGB边缘，材质纹理也会额外产生RGB边缘；例如1234所有view显著受暗部影响。

实际看过10组原图：6组预先选定视角，加上其余全部>2px的局部argmin异常，共覆盖所有5个大argmin异常。主要建筑轮廓大体吻合，未见一个可直接应用的统一大平移。未对全部40组人工像素标注，保留`visual_review.json`中的范围；大argmin不能自动作为校正。

## B. 独立UAV RGB→实际卫星RGB

实现：`scripts/analysis/ue_rgb_sat_image_correspondence_20261025.py`。
产物：`/data/wangcheng/checkpoint/ue_compact_joint_20261024/rgb_sat_image_correspondence`。

直接使用厘米坐标的camera-Z、camera_to_world和world_to_camera，不复用模型候选或native字段缓存。按实际卫星透视投影、floor落像素并保留最近**已观测**表面，带回原UAV RGB。比较真实深度与sampling-origin水平参考面（非实测地面）。每个view的两条件在相同支持交集及40px中心裁剪区域比较，合计3335545像素；RGB每通道去均值、整体L2归一做ZNCC。

## 对后续模型开发的影响

1. 深度/K/T对准确读取RGB的几何作用获得了影像层面支持。相机rig固定、缺乏独立标定变化的限制仍在；不能以跨图交换相同K/T声称消融过标定。
2. 暂不优先做全局平移补偿、量纲补丁或扩大几何编码器。下一个需要定位的是原始对应证据进入候选/特征聚合及原解码链后是否被保留、是否有超越SAT的互补性；不能把原图相关性高当作新增信息多。
3. 真实深度原图对齐优于参考面，与E2全模型AP尚未优于控制并存。它支持检查读入/聚合/消费和优化，不能单独证明某层就是根因。保持既定四臂100轮及E3/E10同样本梯度诊断，不由本检查改权重或选结构。
4. 不把“物理对应可用”“梯度可达”“最终分割净收益”合并成一项成功。当前目标仍未完成。


## C. 实际保留候选的读取与平均聚合代理

实现：`scripts/analysis/ue_retained_rgb_read_audit_20261025.py`；产物`retained_rgb_read_audit/`。仍是相同8train，不读模型/标签；不将原始颜色代理称为P0特征或实例信息。

- 668301个真实保留锚点逐点核对：view来自index//16384，index剩余值严格等于源u/v所属stride4 token；源Z与EXR差0m；厘米矩阵独立复算SAT UV最大差1.137e-12px、SAT-Z最大差4.547e-13m。排除本抽样中的view/RGB源像素/缓存字段排序拿错；不是仅检查同矩阵回环。
- 按锚点实际floor卫星像素，与原始五view全512射线的最近已观测sat-Z比：40996/668301=6.13436%在后方>1m；没有显著负残差。最近已有表面不是完整遮挡真值，1m继承原native视角计数约定，不寻参。
- 支持格122417，其中21607=17.6503%同时有front和behind候选；732=.59796%格没有front候选。不同源候选处在同4×4格内的不同目标子像素，深度跨度>5m的11040格不能自动叫错误混合。
- own-projection原始RGB对实际SAT像素的逐候选平均绝对误差（0–255颜色单位）：front12.4334、behind27.2834。组间位置/材质分布也不同，不能直接把该条件差解释为过滤的因果AP收益。

为比较格聚合，四方法统一使用74631个同样目标格：dense warp原始16像素均有观测、中央40px内、至少1保留及front候选。每格参考为实际SAT的4×4 RGB均值。跨8图等权平均：

|原始颜色代理|ZNCC|RGB MAE（0–255）|
|---|---:|---:|
|现有保留候选等权平均|.922496|8.901655|
|按own-pixel最近已有面1m硬过滤后平均|.914433|9.228678|
|仅取每格最小sat-Z候选|.801425|14.893024|
|全512射线最近已有面RGB warp再4×4平均|.951289|7.289458|

8/8图硬过滤的ZNCC均未改善。候选均值与dense proxy仍有差距，但它们在每格中的采样数量/子像素位置不同，不能把该差距换算成特征保真率；也不能直接同B的逐view.862比较。结果暂不支持为修复大规模读错或简单最近面硬门控增加工程/训练复杂度。它没有排除学习特征中的高频/语义损失、局部小目标问题或更合适的加权方式。

此检查未改变保留候选、排序、源特征读取、聚合权重或无支持回退。后续以原四臂的完整训练/内容控制和固定CP结果决定，不由原始颜色相关性认定分割成功。

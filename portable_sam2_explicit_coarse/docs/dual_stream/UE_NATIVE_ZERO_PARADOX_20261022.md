# 正确几何未优于字段置零：定向排查（2026-10-22）

## 结论范围

不能确认增益仅来自容量。结构上存在新增卫星适配路径；几何显著影响计算，但其推理修正存在纠错/新增错误抵消。路径是否负责收益需以query四格补充为准。几何可能改变了训练条件或优化轨迹；目前不应把模型整体收益归为正确局部几何推理增益。
未新训练；完成冻结权重分解（8 train+8 val，均匀索引）与32张test已有预测的错误审计。
完整500次Boundary及RMS匹配配对统计仍在原owner运行，不把未完成项当结果。

## 1. 为什么zero不是关闭分支

`NativeGeometryAdapter._chunk`仍执行：卫星high→Conv1x1(256→32)→按目标RoI读取→Conv3x3(36→32)→GELU→Conv1x1→支持mask→alpha残差。字段置零只删除4个输入通道，卫星32通道、卷积、bias、RoI空间读取及UAV支持仍在。
因此该对照检验的是额外几何字段的即时必要性，不是有无新模块；也不是彻底去除UAV（支持保留）。
原卫星高分辨率路径是全图特征repeat，新增query路径是显式RoI读取，改变消费形式；不能将差异仅叫参数数量。

## 2. 训练与推理两种干预不能混为一谈

| 训练内容 | 测试字段 | Mask AP |
|---|---|---:|
| 卫星基座 | 无新增模块 | 64.5510 |
| 几何字段训练 | 正确字段 | 64.7307 |
| 几何字段训练 | zero | 64.7610 |
| 几何字段训练 | zero且残差RMS匹配 | 64.7789 |
| zero字段训练（同容量） | zero | 64.4602 |

geometry−zero训练对照+0.2705pp仍是实际观察，但一次训练不能排除优化轨迹偶然性。
同容量zero训练未涨，反对“增加相同参数就必然带来全部收益”的简单说法；不排除容量与训练条件共同作用。
几何训练权重的query/mixer及alpha均与zero训练不同，不能把推理删除字段等同于重新训练zero模型。
候选解释是几何提供训练条件/先验，最终模型的卫星路径已能保留收益；不是已证实的蒸馏或正则机制。

## 3. 几何是否被数值压弱？抽查不支持

固定8 train/8 val，各使用整图[0,0,512,512]盒、128²读取网格，分解首层卷积：Wq*q + Wg*g + bias。
分解逐值allclose检验通过，完整卫星state前后SHA不变。这是激活诊断，不是检测RoI或AP归因。

| 项目RMS中位数 | train 8图 | val 8图 |
|---|---:|---:|
| 卫星首卷积项 | .3563 | .3874 |
| 几何首卷积项 | .3210 | .4175 |
| 高度字段单独卷积项 | .2537 | .3526 |
| dx高度差项 | .0469 | .0602 |
| dy高度差项 | .0479 | .0522 |
| 近表面视角计数项 | .1109 | .1035 |

几何不是近零输入，亦不是完全无效权重；当前几何驱动以高度项为主，细节高度差项相对弱。不同通道相关性与非线性存在，不能将RMS比例叫因果重要性。
完整test1500调用中，zero残差与correct残差余弦中位数约.8384；删除字段确实改变输出方向，不能说模型完全不读几何。

## 4. 32张固定test预测审计：纠错与新增错误互相抵消

均匀索引32张，不按AP筛图；用冻结bbox Hungarian IoU≥.5匹配，2882对、341个GT未匹配（不计入以下IoU/像素）。按匹配实例重复计像素，区域不是Boundary AP。
2px形态学内外带为boundary；腐蚀后为interior；GT/bbox并集外扩8px局部区域内、膨胀轮廓外为exterior。

| 输入 | 匹配平均IoU | 边界错误像素 | 内部错误像素 | 外部错误像素 |
|---|---:|---:|---:|---:|
| 卫星基座 | .852512 | 329190 | 15961 | 61442 |
| 正确几何 | .853260 | 325462 | 15781 | 62570 |
| zero | .853408 | 324497 | 16882 | 60242 |
| zero_rms | .853560 | 323628 | 17285 | 59971 |

固定区域像素分母：boundary1905919、interior2744794、exterior6432592。
正确几何相对卫星在边界纠正16690像素、同时引入12962错误，净少3728；zero纠正13464、引入8771，净少4693。
正确几何更活跃地修正，新增错误也更多。在此样本中，相对zero保留内部更好（少1101错），但边界多965错、外部多2328错，总体收益被抵消。
这是小样本机制提示，不替代完整AP、不推成全部图像掩码扩张，也不是几何可见性错误已证实。
但它反对“正确字段只是被完全忽略”的解释，更符合字段修正与目标掩码不完全一致、正负效果抵消。

## 5. 根因按当前证据排序

1. **已确认的结构混淆：卫星query直接路径与新RoI消费容量。** zero仍然是强新增卫星适配器，不能用模型净增益单独归因UAV。
2. **已有预测证据：几何修正存在正负抵消。** 当前字段以相对高度为主，不含实例身份；可观测近表面与目标屋顶轮廓未必一致，局部假阳性可能抵消修正。具体对齐/可见性仍需独立核查。
3. **合理但未确认：训练条件改变。** 几何训练与zero训练产生不同卫星适配权重，几何不一定在推理时仍必要；单seed训练偶然性未排除。
4. **目前不支持作为主要解释：几何量纲极小、分支关闭或完全无梯度。** 代码/激活与这些解释相反。没有重新认证渲染RGB-depth配准，因此不宣称数据对应无问题。

## 6. 下一步收口

- 暂停把native定义为“正确局部几何增强已经成功”的主路线，只保留它为小模型收益与训练内容控制证据。
- 完成已固定矩阵的zero/constant内容对照：若同一结构zero同样改善，按卫星适配贡献报告；外部内容效应必须单独成立。
- 只给真实对应/可见性一次固定样本核查预算，优先看已观测近表面与卫星标注边缘是否一致，不扫参数到视觉好看。
- 不因当前结果自动加边界loss、检测入口、三维重建头或解冻更多模块。结构改动前先确认对卫星剩余错误确有可对齐的外部证据。
- 真要检验“纯容量足够”，正式训练应使用同结构卫星query且去掉所有UAV支持/字段的匹配控制，并多seed复核；当前native_zero仍保留UAV支持，不能充当纯卫星容量控制。本轮不因此新开训练。

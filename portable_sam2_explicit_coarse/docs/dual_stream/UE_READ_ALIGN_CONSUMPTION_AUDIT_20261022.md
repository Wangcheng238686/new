# 探针的读取、对齐与消费审查（2026-10-22）

## 结论边界

发现了数项明确的实现语义限制，尚未发现足以据此宣布所有探针结果作废的公共单位/坐标轴错误。
本次仅CPU代码和数值合同审查，没有新性能消融，不能量化各限制损失多少AP。
运行中的41份冻结源码未改动；不因新test观察调整本轮结构、轮次或权重规则。

## 1. 公共入口：局部残差和全图接收特征的坐标语义不同

源码链：`cspm/mask_head.py` forward将image_embeddings及high_res_features按RoI重复，
没有先裁剪成对应RoI；`decoder/sam2_decoder.py` conv_s0接收该全图128²特征。
所有highres探针的`_chunk`却以boxes将query/UAV证据映射到RoI局部128²；early对应局部32²。
SAM2随后将feat_s0与decoder上采样特征相加并过激活，最终掩码按roi_local目标训练并粘回框。

因此：

- 残差与最终mask监督的RoI位置约定一致，不能说残差被整图错误粘贴或RoI顺序混乱。
- 残差与接收它的原始卫星全图特征不是逐像素地面点对应。相同局部(u,v)，卫星base取整图位置，而残差取各自bbox内位置。
- C/D的“卫星query与UAV”彼此同RoI网格对齐；这不意味着它们与原conv_s0输出也严格逐点对齐。
- early更早进入具有全图位置编码、全图dense提示的冻结transformer，存在相同混合语义，且扰动经过的冻结非线性更长。

CPU坐标坡度实验验证：两个不同RoI的原base重复值相同，而按同一公式提取的query裁剪值不同。
这证明接线约定不同；实验的坡度位移数值不能解释为真实模型特征误差或真实地面偏移。
这项限制来自当前保留的基座合同，并非本次新加的裁剪回归bug。不能直接热修改冻结解码器；
若未来要验证“入口不适配”，需独立协议和恒等回放，不能将当前残差失败直接推为UAV没信息。

## 2. RGB固定候选读取：覆盖粗、混合表面、内容与几何并存

适用：原始RGB、unit、contextual、early，以及新A/C。

- 源为stride4的128²预训练特征；目标为4×4像素格。一个small测试实例的bbox中位尺寸34×35px，
  对应约8.5×8.75个目标格。输出128²不能把这一证据粒度变成128²独立观测。
- query在RoI连续双线性读取，但候选通过floor(uv/4)选择，格内共享k/v；格界会跳变。
  geom含相对格心的偏差，能让注意力区分候选，却不能自动补回被压缩的点或创造细像素证据。
- 每视角最多2点、总8点；先各视角rank0，再rank1按yaw顺序截断，不是全视角严格可见性融合。
  可同时带入不同表面的点；有深度不等于经过完整卫星遮挡认证。
- 原始key/value为RGB线性投影加geom_key/value；常量RGB仍有几何输入、源位置编码和视角/支持分布，
  因而是匹配外观对照，不能称无UAV。
- A/B当前归一化残差只通过注意力间接读取卫星query，不直接比较卫星原内容与UAV内容；
  有效候选仅1个时，softmax权重固定1，query不能通过权重改变读出的value。B的偏移仍可依赖query。
- contextual把更粗的FPN2上采样后加进细特征，增加语义上下文；没有增加几何定位精度，原始版本还未约束自由幅度。

已有32图独立几何审查显示原stride2投影点的1px邻域边界覆盖96.82%，候选保留后91.57%；
不能用“格有候选”代替真实点覆盖。详见测试弱点报告。

## 3. 新B/D局部采样：两个不同的起点

源码`S2DBAdapter._candidates`：

- 特征位置：`token_xy + 0.5 + offset`，用128²特征图双线性采样。
- 深度位置：`original_source_uv + 4*offset`，用512²原深度判断孔洞/越界和记录突变。

两者使用相同位移，但起点不完全重合。固定32张train共2630165个保留锚点，
按适配器自定义edge-domain token中心`4*token+2`比较原始source_uv，每轴差均为±1px。
这是该代码中心约定的比较，不是对Hiera特征物理感受野中心的外部标定；Hiera起始卷积本身还有kernel7/stride4/pad3与后续注意力/位置编码。

**后果：** accepted只表示原锚点附近平移后的深度代理位置有效，不能称双线性特征插值的每个感受野都对应有效、同一表面。
在孔洞或窄立面边缘，深度代理位置与采样token邻域可能给出不同判断。零偏移与固定gather严格一致仍成立，
原锚点几何也确实没有重写，符合这轮“局部外观上下文”的狭义干预；但“精确新三维对应”解释不成立。

偏移后遇到有效深度跳变仍保留，是预注册选择，不是漏加深度一致性门；因此B/D收益/失败均混合局部外观上下文的利弊。
本轮不改范围、孔洞策略或重新选择深度原点。后续若比较另一种原点，应单独记录并从初始化做匹配训练。

## 4. 原生深度几何：更细的表示仍有平滑与可见性限制

适用：native_geometry/native_zero。

- 原生512²按卫星camera-Z近表面取点，比4×4候选格保留更细；高度相对采样中心，外参和depth均cm→m，未发现重复单位变换。
- 只在已观测点之间取最近表面；没有目标视角完整遮挡真值。可能含屋顶、立面、地面，不是屋顶专属表示。
- dx/dy是相邻目标像素高度差并缩放、截断，不是按地面米距归一的物理坡度。不要把字段称为真实表面法向。
- fields与support双线性采样后按cov重新归一，避免空洞零值稀释；最终用nearest support判定有效。
  这会混合相邻有效表面，尤其高度突变处；插值、最近邻有效掩码和3×3卷积有不同空间范围。
- native零字段对照保留query、支持与容量，能检验四字段组的训练价值；目前不能拆开高度、视角数、局部差分的各自贡献。
- 该分支在有支持处把卫星query直接送入卷积，原始RGB路径只条件化注意力，因此两者差异不只是512与128分辨率。

既有数据提示native在低覆盖组平均IoU略负、高覆盖组略正，且虽纠正较多边界像素也会引入背景外扩。
这是关联证据，不能据此在当前矩阵追加门控策略。

## 5. 消费方式与训练动力

- 原始RGB存在输出幅度补偿：小alpha乘大残差，实际扰动并不小。不能把小alpha理解为未消费；unit/A/B输出LN缓解尺度自由度。
- 源LN、残差LN去除向量幅度，但不保证语义对齐，也可能去掉可用置信幅度。有支持不代表每处应等强注入；单一全局alpha缺少空间可靠性决策。
- C/D直接读取卫星query并做局部卷积，卫星内容可帮助拒绝或改写UAV证据，也可仅靠query学习修正。
  常量RGB和zero聚合训练对照用于区分外观、几何及容量；zero不等于纯卫星原网络。
- 无支持处在输出LN之后遮罩，排除了由query/卷积偏置产生无支持残差。支持处即便没有RGB信息，偏置/几何仍可使残差非零。
- α=0时主任务最初只能先更新alpha，之后源分支梯度才打开，这是恒等初始化的预期行为；工程门已检验后续LoRA/偏移/融合梯度可达。
- 当前冻结RPN/框分类分数，分支不能补回检测漏框或改变排序；不能期待mask-only探针提高bbox AP。
- mask损失沿冻结SAM2 decoder及UDPR回传至注入张量，冻结权重不等于no_grad切断解码器。当前没有发现主任务被detach断路。

辅助路径已检查：在融合前全图目标网格重新计算聚合/偏移，query.detach同时覆盖偏移输入；
不是只detach最后attention query。原实例标签并集、实际保留点唯一投影像素监督、空支持BCE=0。
辅助前景loss不教实例间分离，且部分训练动力可能来自几何；头也可能从query条件化和背景分布获益，
故辅助IoU必须与常量/zero以及实例AP联合解释。zero聚合情况下辅助头只能学偏置/空间边缘等先验，
其梯度不能传回被乘0的源内容，这属于控制设计。

## 6. 当前判定及后续核对清单

|事项|判定|如何约束结论|
|---|---|---|
|cm/m、view/token展平次序、源RGB通道|既有审计与本轮代码未发现公共错误|仍不等于外部像素标定认证|
|零偏移读取、无支持、零alpha、梯度|工程门已通过|只能证明接线|
|局部残差+全图接收特征|确认混合坐标语义|不能宣称严格点对点卫星/UAV融合|
|偏移特征与深度代理的原点|确认不同|accepted不是精确新3D或全感受野有效率|
|源格与候选压缩|确认有损|B/D不能否定无锚点/远距离证据潜力|
|LN/全局alpha/预训练跨视角表征|潜在限制，未单独消融|不凭相关现象直接选新架构|
|常量/zero/辅助的卫星或几何捷径|结构上允许，已有对照|收益必须做匹配内容归因|

等固定矩阵结束后，逐项对照B−A/D−C、C−A/D−B、常量与zero容量对照、辅助六格、偏移接受/回退与分组收益。
若局部读取无收益，也不能据此说精确几何读取无意义；若拼接有收益但zero同样有益，不能归为UAV内容。
若只有几何路线稳健，不把RGB架构复杂化当作默认答案。当前不根据本审查改动正在运行的实验。

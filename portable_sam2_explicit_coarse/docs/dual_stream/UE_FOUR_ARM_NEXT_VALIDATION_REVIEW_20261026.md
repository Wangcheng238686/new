# 原四臂后续验证：三方向独立审查汇总

## 范围与决定

用户要求派子代理讨论结合新证据继续原四臂方向。独立审查分别为：`review_original_fourarm_evidence`（原始指标/进度/归因）、`review_qg_transfer`（架构/可迁移机制）、`review_next_validation`（最小验证与可推翻条件）。主代理复核原始epoch记录与源码；本轮仅形成决定，不启动新增训练，不修改冻结数值源或当前合同。

一致结论：继续完成已有内部交互＋实例监督的完整预算验证；原四臂是已有收益机制的参照，不是压缩已解决的最终模型。完成现有Q/G矩阵，暂不新增Q+G+RGB高分辨率入口等组合。

## 必须纠正的架构描述

原路线不是全部UAV信息先压64²才消费：

```text
8候选RGB均值＋几何CNN → u128
  ├─ pool64 → block4双向交互 → 后续卫星编码/RPN/RoI/掩码
  └─ u128＋上采样交互增量 → 128²实例中心/框头 → 追加候选
```

源码 `rsprompter/uav/instance_interaction_probe.py` 的high_u直达128²实例头。Q把卫星query提前到候选聚合前；G新增的是逐候选几何的block1回写，原CNN/旧交互仍保留。新128² RGB入口真正检验的是早期卫星编码消费，而不是旧模型完全缺乏高分辨率实例发现。先平均的损失依然存在，但不能将所有小目标损失归为64²瓶颈。

## 最小后续顺序

1. 完成原100轮四臂、既定完整459val的combined segmAP250最佳选权和selected-best test，不改为E100 last，不按同轮阳性重选。保持原已启动任务合同；新训练才执行每实验四卡要求。
2. 用既有预测离线拆分：条件化原路径、合并路径、追加候选；在预定尺寸/密度/支持组，以固定bbox关联统计找回、破坏、FP与未匹配分母，再定位无候选/筛除/定位不足/掩码不足。固定权重correct/constant/donor绑定同一CP，披露错配RGB保留原几何的不一致。这些新增逐实例诊断尚待实现，不将总FN/FP冒充净纠错完成。
3. 跑完已有10臂DDP矩阵。Q正确/常量与baseline正确/常量已足以筛查只替换候选均值，毋需新开重复短训练；比较正确绝对AP、内容差及差中差、同权重donor和原/合并路径。新DDP不与旧单卡轨迹直接相减归因。
4. 固定全预算候选规则应先于查看QG test排名；若依据开发test改结构，标为开发选择并保留后续未使用空间划分核验。对有依据的单改动再投入完整预算及匹配训练重复。

## 可推翻条件与后续方向

| 结果 | 决策 |
|---|---|
| 原路线净AP与内容差均保住 | 优先匹配多seed复核，不为压缩理论丢弃已有效路线 |
| 整体/深度收益成立但RGB差持续弱 | 精简几何/内容消费者，不能把全部RGB容量称必要 |
| Q正确绝对AP和内容收益都改善 | 先只迁移Q；完整预算与同结构对照匹配 |
| 内容差扩大主要因常量下降 | 不认定找回有效信息或提高模型上限 |
| Q成立但原路径仍疑似受入口限制 | 另做旧64²与替换128² RGB入口单改动，几何固定，不与G/删CNN打包 |
| 预测对RGB敏感但净错误增加 | 改实例决策/消费，不能继续只归咎压缩 |
| 密集组损失仍集中候选竞争 | 针对真实候选阶段验证，不默认加宽UAV编码 |

G暂不整体吸收：它是容量＋几何表达＋早期入口组合，需证明额外净效用再检查删旧分支的可能性。遥测仍只观察，优先离线、不进入loss/门控/选权。

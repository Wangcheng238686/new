## 机制解释

1. **存在值得继续定位的信息组织效应。** 空间可学习压缩使内容差及差中差明显转正；视角组织改善差中差，并出现正确优于donor的Mask区间。故“聚合方式完全无关”不受支持。
2. **不能宣布空间信息瓶颈已被解决。** spatial正确81.30367没有超过原正确81.46567，内容差扩大主要伴随常量从81.90819降至80.44459。支持该结构改变了对RGB的依赖/早期优化，不足以证明找回了额外有用信息或提高了原模型性能。
3. **no-copy可提高整体Mask，却没改善训练RGB内容优势。** 正确与常量都上涨，且常量依然更高。不能将整体上涨解释为“去掉捷径后RGB成功”；它也改变了实例头的反向卫星value来源。
4. **固定权重依赖与更好的RGB学习要分开。** no-copy/view的正确−donor区间为正，说明该检查点的对应RGB确有有益作用；但不代表同预算正确训练优于常量训练，更不代表100epoch跨seed稳健性。
5. 还没有单一变体同时满足：显著超过原正确基准、正确训练优于同结构常量训练、正确输入优于同权重donor。不得将不同变体各自的正向比较拼成一条已完成的因果链。

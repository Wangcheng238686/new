## 结论

状态：完整计算及独立实施/结果审核均PASS。仍仅为冻结开发诊断，不作为UAV净收益或论文总体结论。

本次配对RGB替换造成的mask变化，主要沿**SAM图像embedding融合入口**；FPN入口的RGB条件差值很小，两个入口交互也很小。预注册“主要沿SAM”定位门通过。

这是当前冻结模型对既定干预的路径定位，不是FPN无用的证明，不是SAM实现错误的证明，不是从头训练单入口消融，更不是UAV净收益。

范围仍仅为当前冻结开发子集全部153验证图、4496次建筑出现、237栋唯一建筑，不外推正在生产的完整开发集或独立test。

## 设计和控制

固定dual E72 strict EMA、相机/深度派生payload和上一轮两套RGB供体。分别完整提取正确RGB特征C、供体RGB特征D，在RPN/RoI前构造四组合：

| cell | FPN特征 | SAM图像embedding |
|---|---|---|
| CC | 正确 | 正确 |
| CD | 正确 | 供体 |
| DC | 供体 | 正确 |
| DD | 供体 | 供体 |

PE、高分辨率SAM特征、未融合FPN层逐值一致。只交换两个融合后的显式特征入口，head不从payload隐式重新读取内容。非RGB payload hash不变；所有使用特征前后hash不变；参数version不变。供体仍有训练见过、RGB-D失配等上一轮局限。

CC/DD逐图复现上一轮完整框/score/mask及GT共同框IoU；正式306组对角双端回放均通过（两套映射×153图，每组两端，共612次cell回放）。CC/CD框和score完全相同，DC/DD同样相同，符合SAM embedding不参与检测框生成的边界。

主指标：GT共同框逐GT二值mask IoU；伴随完整segm/bbox AP。为控制成本，本轮只重复GT框诊断，不重复三种共同框及AP bootstrap。

## 预注册落判

- SAM四条件IoU差均≥.005，FPN四条件差绝对值均≤.002：**主要沿SAM，通过**。
- 主要沿FPN：不通过。
- FPN或SAM四条件一致负效应≤−.005：均不通过。
- 交互绝对值≥.005且两映射同号：不通过。

这只定位既定激活替换敏感性。GT框下FPN路径仍包含RoI和提示；完整AP下另含RPN/回归/NMS。SAM入口也不能进一步拆成单一decoder层原因。

## 工程线索：RoI层级与融合层级

以下工程线索已由独立审核CPU读取检查点配置并执行官方RoI映射函数确认。

当前融合只在neck完成后的P3/P4（indices1/2）注入，不会再通过FPN自顶向下传播回P2。mask路径使用SingleRoIExtractor按框尺寸选择单层；finest_scale=56时，sqrt(bbox area)<112分配P2。

对全部GT框按官方映射公式计算：P2为3657/4496（81.34%），P3为839（18.66%），P4/P5为0。small881和medium2510均落在P2。本次这些尺寸组的FPN条件IoU差精确为0，与P2未融合一致。

这是固定GT框下的**直接mask RoI路径覆盖缺口**：当前FPN融合未直接进入大多数目标的mask RoI特征。不能把它扩写成整个模型绕过UAV，因为SAM入口仍融合；也不能据此否定FPN对RPN、回归框或最终AP的作用。实际部署预测框的分配可能与GT框不同，后续若比较应单独统计。

## 后续仍优先冻结探针

当前证据足以把下一步诊断集中到SAM残差，无需立刻训练，也无需据此删除FPN或重写CVT。

建议先做少量预注册的SAM残差强度对照（保持FPN、权重和数据不变），验证当前注入是否过强，以及强度改变能否改善正确RGB下的完整AP与共同框IoU。需要原强度回放，避免把关闭后分布变化当净贡献；不能用验证扫参尖峰宣布最终结构。

若强度不能解释，再检查小范围空间偏移/屋顶边界与支持区关系。RGB-D匹配、聚合细节损失、任务冗余和训练适应仍是候选解释；本轮没有证明其中任何一个为主因。下一项探针尚未运行，不自动扩大扫描或启动训练。

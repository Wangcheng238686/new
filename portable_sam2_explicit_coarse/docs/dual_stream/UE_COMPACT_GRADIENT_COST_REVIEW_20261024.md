# 联合训练前：固定函数梯度与完整推理成本

这两项只读审查使用已训练的旧冻结E73 RGB-D internal探针，不将该权重用于正式联合训练初始化。原14臂/119项、loss权重和所有训练代码不改。当前紧凑联合运行器仍使用共同基础初始化。

## 梯度方向：没有证实单一冲突解释

`scripts/analysis/ue_interaction_loss_direction_20261024.py`对预先均匀固定的8个train索引，在E1/E3/E10各执行一次FP32、无增强、卫星/adapter eval的原任务与直接实例loss梯度；共24行，无optimizer更新。参数组取声明参数的并集，未使用梯度视为零；范数为合并向量L2，非逐参数范数之和。任一范数零时余弦null。每checkpoint首个固定样本另分原loss对writeback.weight的范数。

均值（8图等权，均值余弦不等于合并梯度余弦）：

|epoch/组|原任务范数|实例目标范数|平均余弦|负余弦图数|
|---|---:|---:|---:|---:|
|E1 writeback|.3424|2.7464|−.0264|7/8|
|E3 writeback|.3614|.8111|−.0162|5/8|
|E10 writeback|.3446|.5473|+.0067|4/8|
|E1 geometry|.0655|33.7022|−.1208|5/8|
|E10 geometry|.2373|16.7804|+.0448|4/8|
|E1 source LoRA|.0132|6.4473|−.1625|5/8|
|E10 source LoRA|.0417|2.0971|+.0403|3/8|

早期实例目标对UAV表示的梯度远大于原任务；但writeback平均方向接近正交，E10没有一致负向。不能据负余弦计数断言它造成AP损失，不能据E10轻微正值声称冲突不存在。这是固定eval函数，不覆盖随机增强/LoRA dropout训练梯度的分布。E10首固定样本writeback.weight的原梯度主要来自decoder_tail(.2655)、ROI分类(.0775)、mask(.0548)，RPN分类/框(.000068/.000893)很弱；仅一个样本，不推成全数据事实。

当前结论是**有监督强弱差异，但没有确认足以要求改loss的单一冲突根因**。不按此少量样本调中心loss权重或冻结/解冻范围；共同基础联合训练本来会改变原任务梯度，不能把冻结E73范数直接外推。

## 成本：源大冗余已减，整条链仍有新增实例成本

`scripts/analysis/ue_compact_cost_audit_20261024.py`在val首/中/末3图、每种设置预热1次、3次轮转重复，比较同一E73卫星与同一个RGB-D E10的三种路径。完整/紧凑的全部非source状态复制，P0状态逐项复制；9个配对预测的框/分数/RLE指纹全部相同。以下为每路径9次测量中位，不是置信区间或部署指标。

|路径|整条评估wall ms|评估输入准备wall ms|UAV准备stream ms|检测/掩码/RLE stream ms|最终实例数中位|
|---|---:|---:|---:|---:|---:|
|强SAT|363.807|33.876|.022|306.743|145|
|完整源RGB-D|826.417|155.521|106.542|516.567|250|
|紧凑源RGB-D|727.555|155.710|19.582|514.312|250|

卫星编码（含内部交互）的stream中位分别24.365/26.285/25.510ms。全/紧凑源的预测严格一致，源准备约少87ms，整条路径约少99ms；新增候选掩码和更多输入读取没有随源裁剪消失。紧凑整体wall仍约为SAT的2倍，不能写成“0.7M所以几乎无额外成本”。SAT和RGB-D实际输出数量不同（145对250），这不是固定实例数算力比较；旧几何补候选正是要承担这部分实例工作，是否值得须与AP一起评价。

wall包括评估用卫星图/GT读取、UAV缓存/PNG读入、预处理、网络及RLE；stream事件可能包括主机引发的空隙。数据在热页缓存、单GPU无其它GPU任务条件下测，CPU仍有统计任务。全部旧权重同时常驻，additional_peak_allocated约1335.5/1379.9/1369.4MiB，只是相对起点的额外峰值，不代表单独部署占用；不外推最终联合模型速度。

## 决策边界

保留已核定的紧凑源，不再添加更深UAV backbone或多层交互以追求表面复杂度。明确记录候选解码与数据读取成本，后续可针对批处理/预取等优化，不将它们算作新信息增益。当前两项审查不足以否定已有候选内容证据或要求马上删头；正式共同基础配对训练仍是验证任务增益与模态作用的必要下一步。未用这些val成本/固定train方向调整原119项或按test挑模型。

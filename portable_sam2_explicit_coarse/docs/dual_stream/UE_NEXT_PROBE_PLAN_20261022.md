## 3. P1：固定native E10的空间赋值敏感性推理诊断

### 3.1 冻结对象

使用已训练native_geometry E10 last、同一SAT基座、原query/支持/四字段通道/注入入口，FP32、scores、maxDets250。
SAT baseline和native_zero独立训练对照沿用已完整测试记录，不把它们与同一checkpoint的字段zero混为一谈。
所有模型、数据、缓存、脚本SHA先封存。新包装脚本独立，不改正在运行的冻结源码。

### 3.2 六个固定条件

|模式|同一native权重输入|意图|
|---|---|---|
|correct|原四字段和原support|重放参照|
|zero_eval|四字段0，support不变|同权重字段依赖；有分布外限制|
|mean_eval|每通道用该图support内均值填满support，外部0|保留图级均值，去掉局部几何分布；不保留完整直方图|
|permute_s1/s2/s3|在原support位置间，将四维字段向量联合随机置换|保留support及完整联合向量集合，破坏空间组织|

置换seed预定20261023/24/25，再按archive image_id用确定性种子派生；不读GT/预测决定置换。
逐图assert联合向量集合逐值守恒、support完全一致、孔洞外全0；四通道不能独立洗牌。
置换破坏高度差分等物理相容性，因此不是可实现的新场景，只是分布外的依赖诊断。
mean仅保留各通道一阶均值，不能排除方差/直方图等图级统计捷径；它改变局部幅度/频谱，不能孤立归因为空间对齐。
全部置换在RoI读取前的整幅fields上执行，不对每个RoI独立置换；保存每图映射指纹及明确图ID派生算法。
建议派生算法：NumPy PCG64 SeedSequence([固定seed, archive_image_id])，support按行优先展平的有效索引建立联合向量置换。

### 3.3 工程门和计算预算

1. CPU验证扰动不变项、source SHA、same seed可重放、不同seed映射不同。
2. 先按P2重建固定8张train/val真实native来源并进行原始影像抽查；若有可复现系统性冲突，暂停GPU诊断并提交证据。
3. 无已确认系统性错误后，在同8图做correct原始logits/二值mask/框score精确回放。
4. 空闲GPU上对459 test完成六条件；复用旧correct时须核对全459 checkpoint/源文件/GT/图顺序ID及推理合同一致，不能仅凭8图回放复用。不能证明等价就新跑correct。
5. GPU低优先级，不抢占既有训练/推理，不改变旧owner预约。总计至多6×459次单图诊断推理，不训练新参数。
6. 若发现包装器检测框/分数或GT变化，立即将该诊断标为无效并修复实现，不拿结果作机制解释。

### 3.4 指标与预设主比较

主指标只指定Mask AP250，主比较仅两个：correct−mean；correct−三个permutation的平均AP。
后者是三个AP标量/各bootstrap重采样AP的均值，不平均预测、不集成模型。
共同500次同图bootstrap seed20261021，报告名义95%区间及两个主比较Bonferroni 97.5%区间；
报告三个置换各自结果和范围，不挑最差置换；这是干预随机性，不是训练种子重复。
Boundary/AP75/分组/纠错均为描述性次要结果，不能另挑显著值作主结论。
500次97.5%区间每侧尾部约6个重采样值，端点较粗，必须同时列点估计、95%及97.5%区间；不包装成精密确认。
zero_eval及对SAT/训练zero的比较作诊断配套，不新增成功主张。

统一报告Mask AP250/AP75、BoundaryAP2%/1%、bbox/AR250；尺寸分组同时标注canonical bbox面积与独立GT-mask面积补充，不能换分组挑结论。
记录实际注入/base RMS的平方和及元素数，按整图全部RoI调用累积，不能误用旧last-call stats作整图统计。
在固定8图离线输出delta变化/余弦（零范数null）；不参与门控或选模。
偏移/插值/alpha不调整，RMS不同只披露；本轮不按观察补做幅度匹配版，避免自适应增加干预。
固定bbox匹配的边界/内部/背景纠错、新增错误，以及预定支持<.5/.5–.8/≥.8、真实COCO尺寸、密度≤50/51–100/>100作描述，不用test重选阈值。

### 3.5 能与不能得出的结论

- correct优于mean和置换：支持该固定模型对字段的空间赋值敏感；与已有训练内容对照相容。
  无法唯一分清正确几何、平滑/频谱、字段与query相关、分布外敏感性、实际注入幅度，不能升级为“正确空间几何驱动收益”。
- correct与空间破坏未见显著差异：只报告当前干预下证据不足；无预定等效检验，不能称等效或网络只用图级均值。
- 仅zero下降：说明对字段置零敏感，信息来源仍不可分，不表述为“字段依赖较弱”。
- AP对比和RMS变化不一致：记录为机制未决，不用手调缩放令解释更好看。即使直方图置换前守恒，RoI插值后分布/RMS也不守恒。
- 本轮不设新的“成功模型”选取，+.002与CI门仍是原相对SAT净增益参考，不能套到correct−corruption上冒充净收益。

## 4. P2：固定8图的原始影像对应抽查（先于P1 GPU）

### 4.1 固定抽样和来源

固定4train+4val：seed20261022、从每个split排序后的image_id无放回抽取4张，与AP/损失无关。
披露8图密度、真实mask尺寸、native覆盖率及缺组情况；不为补代表性换图。

在CPU按冻结native构建器的原顺序、排序、最近表面选择、1m近表面viewcount、dx/dy规则重建8图。
携带每个selected目标像素实际来源的view、source UV、source camera-Z、world XYZ、satellite连续UV/Z及选择索引。
先断言support逐值等于现有native cache，四fields在相同float16存储后逐值相同，再抽点。
不能用RGB的每格8候选替代native最近表面，也不能仅从缓存高度倒推唯一射线；无法证明来源则标无法核查。

每图最多3点，分别从native有支持的GT前景腐蚀内部、边界、背景抽取各1个。
GT区域固定：union是实例mask并集；内边界=各实例mask减2次3×3腐蚀后的并集；图外按0背景处理；
内部=union减边界；背景=非union。每组从按行优先有效像素索引，以SeedSequence([20261022,image_id,组编号])派生PCG64均匀抽取。
缺组记空缺，不换图、不移动到好看的点。至多8图24点。

### 4.2 核查内容与不能认证的部分

显示该native选中来源的原始RGB/depth像素、世界点与卫星投影、GT及邻域图。
同一公式回环只算内部一致性。只有源RGB和卫星RGB中能独立辨认同一结构（如明确屋顶角或纹理交界），
才标记两幅图的独立识别点及其与投影点的距离，记录外观一致/明显冲突及依据。
固定点没有可辨认结构就记无法判断，不为凑一致样例扩大预算。

height来自选中表面射线；viewcount和dx/dy的来源另外记录，不能用一条射线认证四字段全部语义。
原始RGB/depth/相机参数同属渲染链，没有外部表面真值；“独立”仅指核查方式，不指外部标定真值。
8图不代表密集test，未覆盖的场景明确写出；不报可推广全库的对应正确率，零个明显冲突不等于校准通过。
若需真正量化同表面对应误差，须后续renderer object/surface hit身份或独立对应真值。

如发现明确可复现系统性错误，先提交错误证据和独立修复合同，暂停P1 GPU，不据旧缓存扩大架构。

## 5. 与已运行S²DB矩阵合并后再决定

|证据组合|下一步边界|
|---|---|
|正确RGB在匹配内容训练与固定权重干预上有稳定解释，且相对SAT净正|只留一个候选，进入独立seed及新区域确认，停止加入口|
|仅新增结构有益，constant/zero同样有效|归为适配/几何/容量，不宣称RGB增强，不自动加loss或大解冻|
|native小收益、空间赋值敏感性及来源核查未出现明显冲突，RGB无内容证据|优先考虑最小深度几何方法，随后做训练重复性确认|
|对应核查发现明确系统性错误|先修对应、独立重建对照，不将旧路线比较当正常负结果|
|局部读取/concat/aux全部无内容增益，原始影像抽查也未发现错误|承认冻结探针未证实RGB，记录读取范围/入口盲点，不推为全部UAV路线不可能|

新区域正式test必须独立保留；v1 test已用于开发。确认候选时至少再加2个预定seed，并保留其同结构内容控制；不得把图像bootstrap替代训练重复性。

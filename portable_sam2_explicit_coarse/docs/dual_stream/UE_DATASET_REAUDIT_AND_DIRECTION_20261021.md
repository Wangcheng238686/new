# 数据问题是否解释旧双流失败：2026-10-21复核与方向

## 结论

旧数据确有标签、归属和版本问题，不能用旧失败否定UAV研究假设；但本轮同图比较不支持把“旧数据整体坏掉”当唯一已证根因。原始RGB-D有较多目标观测支持，仍需建立对同一可见表面的可靠对应和局部细节消费。

下一步维持已授权顺序：全新通用SAM初始化训练新固定划分单流EXP-0017→固化val-best→最小局部跨视角适配器（冻结卫星，单高分辨率入口），不先回到复杂BEV或新增尾部修正头。不在本轮改动正在训练的实现。

## 来源与边界

已读取3090渲染会话019f84a8-8bba-7600-b2d0-02a277903def最新8轮的用户决议与完成报告，以及渲染项目docs/HANDOFF_PAIRED_ARCHIVE_V1_20261021.md、TRAIN_MINIMAL_ARCHIVE_20261021.md、SATELLITE_OPEN99_LABEL_PATCH_20261021.md、SATELLITE_PRIMARY_SPLIT_V1_20261021.md和清洗历史。工具只读取历史记录，未声称对方代理已收到消息/给出新答复。

本轮新增CPU审计，无新GPU任务、无新模型前向、不读取test图像/解码test标签、不改生产数据，仅复用缓存预测重算验证AP，不执行模型。四个探索性脚本及完整rows/summary归档probes/dataset_reaudit_20261021/；脚本明确固定hash样本和诊断阈值，不当成预注册模型实验或全数据校准证书。

## 1. 当前数据真正改进了什么

- 原raw/clean标签曾有跨ID窄条入侵、伪碎片、外架梳齿、误分/误并、孔洞/漏标；最新版本使用手工独立mask与用户批准review99 v3。
- 99条是历史标记区域，88个点，不等于99张坏图。复核后19点修订、新增9个实例，不合并不同旧实例；这不代表全3438图逐图语义无误。
- COCO RLE为最小归档唯一权威，保留少量重叠。原single-ID PNG无法表达重叠，不可用于重建新标签。
- 旧global ID/seed不是人工最终物理建筑身份；新实例ID仅图内有效。不得以旧ID匹配、几何连通块充当多视角实例GT。
- 当前3060点2142/459/459：卫星目标空间隔离，不是全UAV输入互斥。训练31点UAV AABB可能覆盖38个val目标，197源目标对；报告称train/val→test目标交叉AABB为0。AABB是保守代理，不是逐像素泄露真值。
- RGB-D为原始观测复制而非本次重渲；metadata与单位合同正确不等于外部像素配准/所有可见性已证明。

## 2. 新旧同图标签：真实差异，非整体推倒

| 前景union IoU | .990425 | .981690 |
| 一对一匹配实例数 | 2154 | 4421 |
| 匹配平均IoU | .986872 | .980101 |
| 匹配IoU<.5 | 5 | 61 |
| 匹配IoU<.9 | 14 | 104 |

153val的94图实例数量有变化，整体总数相同只是增减抵消。4317/4496旧实例与新版匹配IoU>=.9（约96.0%）；75个旧实例未获一对一匹配另计，不把matched均值当全体准确率。所有153图都有少量前景像素修改；新增前景303074px、移除35097px。少量严重错误也可能显著影响AP，尤其原净差仅+.196个百分点，故不能说影响可忽略；也不能用98%前景IoU声称已有因果归因。

诊断重叠图（>=32px且覆盖对侧至少20%）发现35旧实例关联多个新实例、25新实例关联多个旧实例；这是空间重叠诊断，不是确认这些都是物理误并/误拆。没有对同一模型以新旧GT重新计AP，标签替换对旧固定预测的净差影响见下节；不能据此识别训练标签的反事实影响。

## 3. 新测试集对旧检查点不是held-out

旧627train中：19进入新train、0进入新val、454进入新test，其余不在新正式集合。旧153val全部进入新val。

因此新459test里454张曾被旧模型训练使用（约98.9%）。新test对从generic新训EXP-0017仍是held-out，但不能用旧E66/E72作新test正式结果，也不能把旧权重当本次新基座热启动后宣称test独立。当前EXP-0017确从generic开始，无此继承污染。

旧val长时间用于开发，因此它也是开发验证域，不称全新未触碰评价集。最终test只在新模型按val选定后执行。

## 4. 原始几何观测支持：积极但有条件

预先以固定字符串SHA排序，各取16train/16val，不按模型成功失败选图。全部512像素深度以Camera-Z/cm+CV外参反投影，按真实卫星透视矩阵投影到最近像素；同像素只保留离卫星最近的已观测表面。没有完整卫星深度，因此这是“最近UAV已见表面”，不是所有卫星可见遮挡认证。

| 支持率（像素汇总） | 16train/1132实例 | 16val/485实例 |
|---|---:|---:|
| 建筑前景直接像素有点支持 | 91.03% | 85.54% |
| 独立实例内侧1px边界有点支持 | 89.01% | 79.46% |
| 前景支持，容许1px邻域 | 95.48% | 90.49% |
| 边界支持，容许1px邻域 | 95.07% | 88.12% |
| 实例半数以上像素有1px邻域支持 | 1100/1132 | 442/485 |

1px膨胀是乐观容差，不是证明配准误差<=1px。支持率不证明来自正确建筑表面，不证明卫星缺失信息，也不证明最终AP。覆盖高说明值得保留和消费这些观测，不能据此宣布H1已证。

已支持边界中约65.9%/69.1%位于2m深度跳变的1px邻域；阈值为探索性诊断。该数不是边界预测准确率，没有精确率，也受投影采样/遮挡/多个表面竞争影响，不能当新训练监督或性能结果。

32点中与旧manifest来源重合的40view，UAV RGB及depth均SHA逐字节相同，内参/外参最大数值差0。这个抽样支持：最新版主要修标签/组织，不是把旧UAV观测变成更高分辨率或更准确的深度；不能把所有旧消费失败都假设会随版本更新消失。

## 5. 为什么三维重建不等于实例分割自然解决

深度+已知相机直接提供可见表面三维点，是强输入条件；五图不保证完整屋顶/立面均可见。点云没有附带人工建筑实例ID。

同高贴邻屋顶可能无高度跳变；一个建筑可有多个不连通可见片；墙接地后几何连通不等于独立实例；屋顶设备/檐口有几何边缘但通常不是新建筑。图内人工实例分组还可能与引擎资产组件边界不同。几何对齐、表面选择和语义归属均需消费链学习/处理，不能把“重建可行”推成“只剩换一个融合算子”。

旧首版还有确定的表征限制：stride8+16源特征、单4m格向量、stride16投影、SAM高分辨率路径未直接融合。单位错误/固定平移修复未获证；粗表示是否丢掉可变成AP的增量仍是待验证假设。

## 6. 单一可执行方向

**冻结新单流，做几何锚定的局部源特征查询，只增强一个SAM高分辨率入口。**

- 保留深度恢复的表面位置。几何只筛选投到同一卫星邻域的候选，保留来源视角/投影偏移/规范化高度；不提前把所有高度或视角压成单个BEV格。
- 一个UAV源特征尺度、一层局部注意力；卫星特征query选择同位置多视角证据。首版无独立深度形状骨干、无三维重建网络、无点云实例头。
- 规范化高度若作为候选元信息进入注意力，要在协议中明示为新增几何属性，不静默增加复杂支路；首版仍以对应关系为深度主要职责。
- 有效支持掩码+单残差系数，零贡献初始化；只输出特征增量。SAM/CSPM/UDPR保留职责；不硬裁剪到当前预测mask，避免错误mask把纠错证据排除。
- 所有参数冻结范围按此前协议，新增UAV LoRA/注意力/adapter训练；最终mask梯度经过冻结SAM和UDPR回传。先验证mask AP增益，不要求bbox增加，因为未接检测入口。
- 训练/val筛查以新数据为准，首轮固定预算、last，不挑best尖峰；正确UAV与同容量错配/无任务内容对照，错配RGB-D不一致须披露。恒零关闭应精确复现新单流。
- 新test留到验证方案确定后，与相同新单流基座按同一AP250完整推理。test不用于调整查询尺度/阈值/预算。

本方向是有原始几何支持与现有结构缺口依据的工程假设，不承诺必涨。若失败，应区分覆盖区域收益/非覆盖副作用、几何候选错表面、正确与错配是否有差，再决定修哪一处；不重新开始全局门控/平移扫描或堆更多BEV模块。

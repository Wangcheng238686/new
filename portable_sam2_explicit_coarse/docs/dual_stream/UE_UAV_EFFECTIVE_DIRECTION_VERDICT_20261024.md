# 阶段结论：UAV几何实例候选补充已得到重复正向证据

## 1. 结论与适用范围

在固定v1数据、EXP-0017 E73卫星基座、原SAM/UDPR/coarse64不变的条件下，已找到一条可以产生真实内容增量的路线：

**五视角深度/相机参数 → 卫星像素坐标中的表面几何图 → 独立几何实例头 → 框与自身objectness → 原卫星RoI掩码路径解码新增实例。**

两次独立训练均超过当前已核对的强纯卫星对照；匹配常量控制、固定权重输入干预和逐图候选数量匹配均支持几何内容贡献。当前证明的是UAV深度/位姿导出的几何证据，UAV RGB、CVT和最终联合训练模型仍没有被本实验验证。

## 3. 哪些证据证明不是仅接通或仅增加容量

### 训练与来源

- 每个seed内G/K复制完整同一初始化，10轮每轮2136图的顺序完全一致；每个参数的AdamW step实际为2670。
- 两seed完整初始化不同，E1样本顺序也不同。原卫星参数和buffer在全部推理后SHA不变；纯SAT前缀跨内容、跨seed逐字节一致。
- 原49份冻结source未变，新代码/source快照、checkpoint、输入身份均保存。
- 36734个归档文件SHA全部匹配，3060个native缓存的camera＋五depth来源与同一归档全部匹配。没有缓存串版本证据。

### 固定权重的真实输入依赖

只用seed44真实几何E10权重，原卫星预测固定：

|输入|Mask AP|正确输入优势pp|95%区间pp|
|---|---:|---:|---|
|正确几何|66.551599|—|—|
|四字段换成train均值、support不变|66.230773|+.320826|[+.239626,+.452999]|
|支持内四维向量联合空间置换|66.229936|+.321663|[+.241482,+.451779]|
|另一场景的完整四字段＋support图|66.173007|+.378593|[+.248073,+.480274]|

联合置换保留向量集合，破坏局部物理组织；整图错配采用固定229半循环，源点XY距离中位878.2m。它们是OOD／场景配对诊断，不是精确相机位姿反事实。不用这些干预选择新的权重或模型。

### 输出预算与实际新增实例

真实／常量头参数量同为202581，候选政策与max250相同。进一步逐图截到min(G,K)新增数量，共50838个新增假设，两边每图数量严格相同；Mask点值仍为66.551599对66.310435，bbox点值也不变。

按COCO segm一对一匹配，而非任意bbox覆盖代理：

- 真几何在IoU .5新增匹配811个GT，常量控制476个；IoU .75为253对176。
- 原强SAT的dtMatches/ignore在全部10个IoU阈值逐项不变。
- 真几何811个新增.5匹配中，688来自>100实例图；按标准bbox面积分组，small451、medium359、large1。
- 这一路线主要补充实例及其掩码，旧mask RLE完全保持，不宣称修改了旧实例边界。

原始新增假设约5.1万，很多在给定IoU下未匹配，包含背景、重复、定位不足。层级分数用于排序，不是统一校准的建筑概率；不能据此声称部署工作点的误检率下降。

## 4. 旧探针为什么容易失败

|已确认的限制|证据|对设计的含义|
|---|---|---|
|mask-only入口不能补回检测漏失|原框/分数固定；检测阶段预筛与NMS漏失明显；纯SAT pre1000→2000已使test Mask +1.139pp|先处理实例发现/保留，不能只期待mask残差解决所有AP损失|
|旧RPN监督与要挽救的候选不匹配|固定32train中，抽样正anchor约94% logit>10、负约99.5%<−10；26个Top-K丢失GT只有12在该次抽样获得好回归候选的正监督|直接对目标坐标实例中心和框给梯度，避免依赖已饱和的原anchor分类|
|原卫星消费链会再次丢失UAV证据|val几何框能补最终漏失142GT，novelty后119，原分类等链路实际只保留8；再次框回归臂各仅5个新增框|保留UAV自己的objectness和框，不用冻结SAT前景判断作为硬否决|
|旧特征融合具有坐标/语义约束|conv_s0接收重复全图特征，UAV残差按RoI局部网格组织；拼接增益常被常量RGB控制复制|采用明确的卫星像素实例框接口，原mask路径保持原有语义|
|训练/测试分布偏移不是全部解释|旧N2/shared在完整train也无Mask净收益；新头在相同v1数据上可学习几何并产生内容差|数据分布需修，但不能单独解释或替代消费机制检查|

没有证据把所有失败归为公共cm/m错误；来源与独立数值审查没有发现这类错误。输入完整性也不等于外部标定、RGB-depth同表面对齐或标签语义已被全面认证。

新路线同时改变了表示读取、实例监督和消费接口，因此不能将全部提升唯一归因于其中某一个改动。UAV RGB旧路线的每项失败因素尚未完全拆开；本结论不宣称RGB无信息。

## 5. 下一版应保留的设计

1. 用相机参数和深度建立目标卫星坐标中的观测证据；允许局部覆盖，未知区域由原卫星分支处理。
2. UAV侧保留直接的实例中心／框监督和自身objectness。标签来自已有卫星实例，不需要新增UAV/BEV标签。
3. 先以实例候选为接口让原卫星掩码路径消费证据；当前不增加边界loss或尾部修正模块。
4. RGB/CVT的后续增量可在这个已验证接口上检验，不把本轮几何头的成功写成CVT/RGB成功。

当前冻结E73只用于探针。最终双流从共同初始化联合训练仍是后续开发任务，本轮没有以热启动模型替代该要求。正式化还应评估候选效率与跨来源分数校准；本轮为精确复现缓存先计算了部分随后被过滤的mask，非优化后的生产实现。

v1 test在此前多路线开发中已暴露，同城空间相关和已知密度分布差仍在；下一批独立区域/重新固定数据协议应作进一步泛化确认。这里已完成的是“在手头数据上找出可消费的UAV信息和可实现的增益方向”，没有宣称真实环境或任意卫星基座必然提高。

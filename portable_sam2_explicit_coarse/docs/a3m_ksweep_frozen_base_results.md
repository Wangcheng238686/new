# a3m K 敏感性扫描：冻结基座三基座 × K∈{16..256}（machine2，定版）

日期：2026-09-15。执行机：machine2（RTX 4090×4）。结论依据的训练日志见 §2d
（带 PID 全名，原始日志不入库）。配套在飞实验（dev100 主制式 K 筛选）见 §7。

## 0. 摘要

- **K 的收益在 K≈128 处饱和；"K 越大越好"不成立**（last 基座 K=256 回落
  -0.0010，另两基座 128→256 增益 +0.0008/+0.0016 均在噪声标尺 0.008 之内）。
- **K=16 明确不足**（三基座 16→128 spread +0.0106/+0.0140/+0.0114，全部过
  噪声标尺且方向一致）。
- **K=64 与扫描最优（128）之差 +0.0015/+0.0033/+0.0018，全部在噪声内**——
  主矩阵 a3/a3r 固定 K=64 的选择位于噪声带内，臂间结论对该选择稳健。
- 机制：K 逐点兑换**错误覆盖率**（0.18@16 → 0.80@128 → 0.96@256），覆盖近
  完备后增益归零；K 增大同时使单点修正强度反比收缩（delta_abs 0.178→0.075）。
- 尾部为逐点共享 MLP：**参数量与 K 无关（恒 38,217，占全模型 0.054%）**，
  训练墙钟近乎平坦（K16→256 仅 +4%）——K 是计算上近乎免费的纯采样预算旋钮。

## 1. 问题

UDPR decoder-tail 读取的不确定性点数 K（DECODER_TAIL_NUM_POINTS）此前无系统
敏感性测量；主矩阵 a3/a3r 固定 K=64 无实证辩护。本扫描在冻结基座热启动制式
下测三基座 × 五档 K，回答：K 的响应形状、峰值位置、是否依赖基座状态。

## 2. 协议

### 2a. 训练制式
- 臂：`a3m`（A0 系谱 + threshold-anchored margin 尾，`residual_v1_stop_margin`，
  crossing margin 0.10，boundary logit 锚 -0.4055，hidden 128）。
- **热启动**：`DECODER_TAIL_TRAIN_ONLY=1`——A0 基座全冻结（含 backbone LoRA/
  neck/检测头），仅训零初始化 margin 尾（6 张量，38,217 参数；日志
  `Training scope: UDPR only; A0 base frozen`）。
- 协议 `ksweep40`：40 epochs，每 2 epoch 验证，dev100 同款选模（best segm，
  无 bbox/composite 别名），lr 5e-4 / warmup 100，seed 44。
- 形态：四卡 4×1×2（有效 batch 8），15 run 串行队列 00:17–10:31（10.2h），
  零失败；每 run 后接 best/last 双 eval（含 dt/gt records 导出）。

## 3. 结果（eval 导出口径）

### 3a. segm/mAP（best / last）

| K | last(E300) | bestS(E105) | bestC(E265) |
|---|---|---|---|
| 16 | 0.6380 / 0.6370 | 0.6567 / 0.6555 | 0.6403 / 0.6399 |
| 32 | 0.6415 / 0.6407 | 0.6609 / 0.6591 | 0.6471 / 0.6466 |
| 64 | 0.6471 / 0.6453 | 0.6663 / 0.6632 | 0.6499 / 0.6485 |
| 128 | **0.6486** / 0.6485 | 0.6696 / 0.6677 | 0.6517 / 0.6506 |
| 256 | 0.6476 / 0.6460 | **0.6712** / 0.6675 | **0.6525** / 0.6519 |
| 16→峰 spread | +0.0106 | +0.0145 | +0.0122 |
| 峰值 composite | 0.6852 | 0.6838 | **0.6905**（全场最优） |

- **bbox 全 10 项指标逐位恒等于基座**（0.7218 / 0.6963 / 0.7284）——冻结
  检测器的数学必然，全表核验一致（30/30）。
- best−last 差 ≤0.004：tail 收敛稳定，高 K 无过拟合。
- segm/AP75 为最敏感指标：bestS 基座 16→128 达 +0.027（mAP 同段 +0.013）。
- AP50 全程 ~0.93 不动；APm 随 K 同步上行（last 0.486→0.499）——K 的收益
  集中在高精度段与中等尺度目标；AR@1 全程 ~0.27 不随 K 动（tail 不改排序）。

### 3b. 基座条件性
- **峰值 K 随基座"烤熟度"前移**：last（E300，最熟）峰@128 且 256 回落；
  bestC（E265）128-256 饱和；bestS（E105，mask 误差存量最大）至 256 仍弱涨。
- **segm 绝对天花板跟基座 mask 质量走**（bestS 全线最高），bbox 原样继承
  （bestC 最强 0.7284）；composite 全场最优为 bestC@K=256（0.6905）。

## 4. 观测指标（机制遥测，E40 末态，基座 last）

| K | selected_error_coverage | error_direction_agreement | boundary_margin_violation | delta_abs |
|---|---|---|---|---|
| 16 | 0.1804 | 0.854 | 0.0720 | 0.1781 |
| 32 | 0.3730 | 0.884 | 0.0770 | 0.1769 |
| 64 | 0.5728 | 0.949 | 0.0969 | 0.1667 |
| 128 | 0.7983 | 0.960 | 0.0858 | 0.1359 |
| 256 | 0.9624 | 0.964 | 0.0683 | 0.0747 |

- K 逐点近似线性兑换错误覆盖；方向一致率升至 0.96 后饱和；越界率全程
  0.07-0.10 有界（stop-margin 锚在所有 K 下成立）。
- K 增大 = 修正"散布化"：单点修正强度反比收缩（delta_abs↓）、误杀率骤降
  （destroy_fraction 0.058→0.002、correct_flip_fraction 0.073→0.003）。
- selected_count = K × 有效 ROI 数（887→14194，K=16→256）。

### 4b. 参数量与计算效率
- **参数量与 K 无关**：五档 K 的 optimizer 组均为 decoder_tail 38,217 参数
  （6 张量，逐点共享 MLP，K 只改采样点数不改宽度）；占全模型 70.6M 的 0.054%。
- **墙钟近平平坦**（基座 last 同条件串行实测）：K=16/32/64/128/256 的
  train+eval 为 47.8/48.3/46.7/49.4/49.8 min（16→256 约 +4%）。

## 5. 结论

1. **不是"K 越大越好"**：收益递减曲线，K≈128 饱和，256 一处回落两处进噪声。
2. **K=16 明确不足**；K=64→128 为方向一致的小增益（三基座同向但单点均低于
   0.008 噪声标尺）；128→256 无证据支持。
3. **主矩阵 K=64 的辩护**（论文表述建议）：
   > "K 敏感性扫描（冻结基座、三基座 × K∈{16..256}）显示收益随 K 单调上升
   > 并在 K≈128 饱和；K=64 与最优值之差（≤0.003）在 run 间噪声（0.008）之内，
   > 而 K=16 显著不足。主实验取 K=64 作为噪声带内更小的采样预算，且臂间结论
   > 对该选择稳健。"
4. 若 margin-tail 臂进入正式矩阵/部署：**K=128 为证据支持的默认值**。

## 6. 边界

- 制式断层：本扫描为 stop_margin 尾 + 冻结基座 + 40ep 热启动；主矩阵 a3/a3r
  为普通 residual_v1 尾 + 联合从头训练 + 300ep。K=128 结论外推到主矩阵仅为
  假设，由 §7 的主制式筛选检验。
- 单 seed（44）；128 vs 256 的差异如需下定论需 seed 复刻（方向不明朗，未排期）。
- 外来基座 + 本机训练的混合偏移：仅扫描内部比较有效。

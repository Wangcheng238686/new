## 4. 机制遥测与轨迹工件

### 4a. 尾部遥测全字段（E64–84 epoch 均值，epoch 配对；源：各 epoch detailed losses 行）

| TAIL 字段 | K=32 | K=64 | K=128 |
|---|---|---|---|
| selected_error_coverage（错误覆盖率） | 0.4572 | 0.6569 | **0.8231** |
| error_direction_agreement（修正方向一致率） | 0.7286 | **0.7590** | 0.7345 |
| selected_error_fraction（选中点落在误差上的占比） | 0.3658 | 0.2922 | 0.2097 |
| selected_bce（选中点 BCE） | 0.6171 | 0.5334 | 0.4081 |
| delta_abs（单步写入强度） | 0.1096 | 0.1667 | **0.2670** |
| correct_flip_fraction（正确翻转率） | 0.0238 | 0.0154 | 0.0161 |
| destroy_fraction（误杀率） | 0.0174 | 0.0107 | 0.0096 |
| selected_count（每步选中点数 ≈ K×有效ROI） | 1865 | 3733 | 7515 |

**解读**：联合从头训练下 K 的约束维度从"覆盖率"切换为"修正质量"——
K=128 覆盖最高但方向一致率回落、写入偏重 60%（写得多、写得糙，selected_bce
与 error_fraction 同时下降说明写入摊薄）；K=64 是唯一同时拿住覆盖与方向质量
的点，且方向一致率非单调峰值恰在 64。与冻结基座层（L2：方向一致率单调升至
0.96、覆盖率主导、饱和@128）构成制式对照：**最优 K 依赖基座成熟度**
（成熟基座买覆盖，演化基座买质量）。

### 4b. bbox 侧轨迹观察

- 三臂 bbox E81–100 平台：0.6939±0.0022 / **0.7022±0.0034** / 0.7025±0.0025

## 5. 结论（落选）

1. 按预注册 v1.1 规则：argmax K\*=64；K128 带内（−0.0055）非最小；K32 出带
   （−0.0152）；bbox 伴随无损失；跨层一致（64 ∈ L1 渐近 94% / L2 饱和带）。
   **入选 K = 64 = 主表 K，零改动，辩护闭环。**
2. 论文表述（口径已定）：K 经三层证据 + 100ep 同序配对筛选选定，全部证据层
   显示 K=64 位于饱和/质量峰带、与 argmax 差在噪声内；主表以完整 300ep
   协议 K=64 报告；K 敏感性表用 last ckpt 完整 COCO（与主表口径不可直比）。
3. 制式对照（L2 vs L2.5）本身是论文机制分析小节的骨架：覆盖率→质量的
   约束切换 + 方向一致率峰。

## 6. 边界

- 单 seed（44）；K 间差以预注册噪声带 0.008 判读，不做过解读；

  K32 完赛 / K128 排程中）；

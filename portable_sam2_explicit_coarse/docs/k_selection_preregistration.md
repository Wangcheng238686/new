# K 值选择预注册（论文辩护基础）

日期：2026-09-15（K=32 在跑、K∈{16,128,256} 未跑时写定）。本文在选择数据齐备前
固定选择规则与辩护框架；数据到齐后按规则落选，不得事后改规则。

## 1. 候选与证据层

候选 K ∈ {16, 32, 64, 128, 256}。三层证据（口径互不可混）：

| 层 | 内容 | 状态 |
|---|---|---|
| L1 冻结策略 | a3sgtm E32 平台上 prefix 截断的写入价值曲线 | 完成：饱和 @64–128，K64=渐近 94% |
| L2 热启动训练 | 远端 a3m 三基座 × 五 K（ksweep40） | 完成：饱和 @128，K64 与峰差 ≤0.003（噪声带内） |
| L3 从头训练（主判读） | 本机 A3 matrix300 × 五 K，诚实口径 | K64 锚点完成；K32 在跑；16/128/256 待排 |

## 2. 选择规则（预注册）

主口径：**平台均值（E271–300）segm/mAP**；副口径 last；伴随指标 bbox/mAP
（K 不得以牺牲 bbox 换 segm）。

1. 计算各 K 的主口径值与 K 间配对 bootstrap CI（records 已由 wrapper 自动导出）；
2. 取平台口径的 argmax 为 K\*；
3. **入选 K = 满足以下全部条件的最小 K**：
   a. 与 K\* 的差在噪声带内（配对 CI 跨零，或 |Δ| ≤ 0.008 训练噪声尺度）；
   b. bbox 相对 K\* 无显著损失（CI 下界 > −0.005）；
   c. 该 K 在 L1/L2 层同样位于其饱和带内（跨层一致性）。
4. 平局（多 K 同时满足）取更小 K（简约性：更少选中点、更省算力）。

**预期落点**（写定时的先验，非承诺）：K\* ∈ {64, 128}，入选 K = 64——由 L1/L2 的
饱和位置与"最小合格 K"规则联合推出。若 L3 显示 128 显著超 64（CI 不跨零），
则入选 K = 128，此时"梯度通道覆盖饥饿"成立并作为机制发现写入论文。

## 3. 论文辩护框架（最终指标 + 平衡性）

**最终指标维度**：五 K 的主口径曲线 + 配对 CI 图；argmax 与入选 K 标注。

**平衡性维度**（三条，全部可量化）：
1. **精度–预算平衡（膝点论证）**：入选 K 位于饱和膝部——拿到的价值 ≥ 渐近的
   94%（L1 实测），相对 argmax 的损失在噪声带内，而选中点数/计算更省；
2. **segm–bbox 平衡**：K 扫描全程 bbox 无显著退化（L2 冻结基座 bbox 逐位继承；
   L3 逐 K 检验），K 的选择不引入检测代价；
3. **稳健平衡（非调参论证）**：选择落在曲线平坦带内——三层证据（冻结/热启动/
   从头）在同一区域饱和，K 的具体取值在 [入选 K, 128] 内不敏感，故 K 不是
   精调出来的超参。

## 4. 排程与门槛

- K32 完赛（~22:00）→ 自动 best/last 推理；随后 K128 → K16 → K256 依次
  （K128 为决策关键行：定 argmax 在 64 还是 128）；
- 每档一个 EXP-ID、全量先 commit；GPU 与另一会话的 dev100 K 筛选协调；
- 全部出数后按 §2 落选、按 §3 成文，选择理由与数据一起归档本文档。

## 5. 已知边界

- L3 各 K 均单 seed；K 间噪声带用 0.008（A0/A3 双 seed 标定）作先验尺度，
  不对单 seed 差值做过解读；
- L2 为远端机器（+0.011 系统偏移），只取其 K 间序，不混绝对值；
- 中期尖峰（bestS 类）不进判读，预注册口径为平台/last。

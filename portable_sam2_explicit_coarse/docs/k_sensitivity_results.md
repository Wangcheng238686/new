### L3-K32 判读（对照预注册预测带 [−0.010, −0.003]）

实测平台 −0.0096 / last −0.0115，贴预测带深沿。落点：
1. **K32 掉出平坦带**（点估计超 0.008 噪声尺度；P(Δ>0)=6%——大概率真实、
   未达图像级显著的单 seed 表述）；
2. **平坦带左边界钉在 64**——按选择规则 K32 不满足"与 K* 噪声带内"，
   入选 K=64 的结论加强；
3. 代价集中后期 + AP75（−0.0182，两倍于 mAP 差）——与 L2 的 AP75 敏感规律
   互证；梯度通道的低段分层真实存在，"K 不敏感"只在 [64,128] 带内成立。

### L3-K128 判读与选择规则落选

1. **argmax = K64**（0.6689 > 0.6621 > 0.6593，平台与 last 双口径一致）；
2. **"覆盖饥饿"分支不触发**：K128 未超 K64（点估计 −0.0068~−0.0080，
   P(Δ>0)=15%）——梯度通道与写入通道同律，在 64 附近饱和，128 持平偏下；
3. **新增机制论据**：大 K 有早期训练代价（E6–50 窗口 −0.0127）与边界质量
   代价（AP75 0.7059 为三 K 最低）——过度选点在非平稳基座上是净负担；
4. **按预注册规则落选：入选 K = 64**——argmax 即最小合格 K（K32 差 −0.0096
   超噪声带、K128 更大且不占优）；三层证据同向（L1: 64=渐近 94%；L2: 饱和
   @128 且 64 带内；L3: 64 为 argmax 且右翼 128 持平偏下）。

论文辩护口径（平衡性三论 + 新论据）：膝点（94% 渐近 + 预算减半）；
segm–bbox 无损；跨层非调参；**过选点有早期稳定性与 AP75 代价——64 是
饱和律与训练稳定性的联合自然值**。

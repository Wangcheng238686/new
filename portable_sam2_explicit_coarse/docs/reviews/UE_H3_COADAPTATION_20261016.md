## 判决和可主张的范围

**H3完整因果命题“联合训练让卫星路径让渡能力，UAV补回能力的收益与让渡/优化成本抵消，因此净收益小”：弱支持，因果未定。**

将它拆开会更准确：

| 子命题 | 支持程度 | 证据界限 |
|---|---|---|
| 已训双流在正常UAV条件下运作，移除/错配会损伤mask | 强 | 同一冻结权重的条件依赖，主要沿SAM embedding |
| 当前双流对独立单流没有可靠净优势 | 强，仅限当前开发协议 | 一个seed；best差+.1958pp，探索性图像CI跨0，非独立test |
| 两条路径在联合训练中发生功能分工/共同适应 | 中，概括性机制解释 | 依赖、梯度、强度轨迹与之相容；没有分工前后能力测量 |
| 卫星表征或其读出能力被UAV训练**损害/让渡** | 弱/未定 | 缺同域、同读出、同训练预算的卫星能力保持控制；zero不是能力审计 |
| 梯度竞争或clip预算争抢是主要抵消成本 | 未定；全局clip抢占版本有直接反证 | UAV/CVT/fusion独立clip；没有共享参数分loss梯度方向或更新投影证据 |
| 去掉依赖或保护卫星能力就会产生较大净收益 | 未定 | 所有现有干预冻结权重，未干预训练机制 |

应修改此前消费独立报告的标题式句子“已证实现象：训练形成替代性依赖”：已证的是条件依赖；“替代卫星能力”仍为解释，不能靠下文保留句完全挽救标题中的因果暗示。

## 最强支持证据及为什么不充分

1. 首轮dual=.58495797，single=.58300044；dual zero=.509657，shift=.513302。同双流切掉路径下降7pp而独立单流追平双流，说明独立单流可以用卫星完成绝大部分任务，并提示双流没有保留相同的无辅助运行方式。**但它不等于证明卫星encoder能力变弱**：zero跳过整个编码/BEV/融合，decoder与融合后的统计共同训练，去掉残差本身就是分布外激活。即使dual卫星表征完整保存全部信息，decoder只学会在加残差后读取，也会出现相同结果。
2. 几何固定、只改RGB donor，AP=.550637/.549565；CC/CD/DC/DD共同框SAM条件差约.018，FPN条件差<.0001，强交互未见。它否定“只是几何常量或RGB完全没用”。但donor造成RGB-D失配，证明配对条件依赖，不能区别冗余RGB的共同适应和独有信息的贡献，也不能把3.4pp与7.5pp作可加分解。
3. SAM强度0/.5/1，AP=.508288/.564212/.584958；bbox逐值相同。**固定模型的0/.5都不是卫星能力保留的训练反事实**。半强度失败反驳“当前直接减半即可救回”，并不反驳训练时限制协同的方案；也不支持训练时强度过大。
4. raw训练SAM gate_supported从E1 .7009到E80 .9893，residual/satellite L2 .1323→.9457，alpha .0518→.2221。E72 EMA离线残差比.8548、alpha .2137属不同口径。fusion为satellite+alpha*valid*confidence*gate*GN(project(UAV))，分子、分母均可变化；**高gate不测能力让渡，L2比不是信息占比**。存在有用冗余修正、归一化尺度重配、decoder条件化等其它解释。

## 对训练/优化混淆的直接核验

checkpoint_audit的args差只有config和checkpoint_dir，runtime无差，data差仅load_uav。两臂generic独立初始化，同seed42、4卡batch1、accum2、80轮、lr2e-4、warmup100 optimizer steps、相同LR倍率/weight_decay、同EMA .999每步更新/E5启用；没有resume/UE单流热启动。final_checkpoints两臂epoch80、Adam step都6240，AMP skip均0。由此可排除少更新一臂或EMA配方不同这类简单解释。best E72 vs E66为5616 vs5148更新属于各自选模差；同E80差+.1075pp，最后5轮均值差+.2393pp，仍是小差。

EMA有效记忆时间约1000更新（约12.8轮），半衰约693更新（约8.9轮），所以早期EMA曲线优势不能直接解释为新增可用信息；两臂均受平均滞后，但训练速度可不同。E1–4 raw/E5起EMA必须断开；不是优化崩溃。没有独立空间test、种子分布或匹配raw末期评估，不能将小差说成精确零收益。

原日志确认卫星与UAV各1,492,528可训练参数、初始LR2e-5；CVT5,518,672、fusion494,854、other37,130,794初始LR2e-4；mask decoder4,082,497初始LR1e-5。容量+17%、wall约3.08倍意味着比较不是纯信息增量控制，也未做到等FLOPs；**wall更长不是学习更新预算更少，更不能用运行成本直接解释AP抵消**。

实际`Clip decomposition ON: base 663 tensors ... aux [6,418,59,16,8]`，loops在AMP unscale后先记录梯度，随后base/tail/UAV/CVT/FPN/SAM各自max_norm=.5。UAV参数**没有直接参与base范数的全局竞争**。共享卫星/neck/检测/mask/coarse头仍可能接收不同任务梯度并在base内部共裁剪，但没有base范数/方向记录支撑其强度和负效应。aux增加独立clip集合也是优化器结构变化，不能声称全模型总更新范数预算相同。

## 共同框和dense路径提供的反证/限制

全部4496出现共同GT框dual .841769 < single .844073；共同single预测框差+.001247、dual框差+.001550；按237建筑等权方向相同。GT框small差−.009311、medium−.002528、large+.003791，预测框大目标差约+.0094/+.0115。说明条件mask差不是统一优势；**这是不同完整系统的能力差，不能定位为卫星能力损坏**。框和提示分布会改变相对次序，不能拿GT框差直接量化部署损失抵消。

P2未直接融合、GT RoI81.34%直接取P2，SAM high-res原样返回；因SAM mask梯度也回到共享卫星骨干，P2仍受双流训练影响。dense detach、point no_grad让coarse只获自身GT BCE+Dice(.1)监督，而视觉直路仍获mask/tail梯度；有结构上形成分工的可能，但.1不代表梯度弱。现有梯度设计审查没有backward测cosine，本次也没有。GTdense有效仅说明可被消费的条件空间，不能证明训练冲突或UAV能学会GT形状。

## 三路交叉质疑：接受与保留

**接受H1/H2审查的限定：H3完全可能只是它们的下游现象，当前不能作为三个彼此独立、互斥的根因投票。** 原RGB没有普遍精细优势，或source/BEV/projection把独有细节压掉，训练都可能学会利用剩余冗余内容并形成strong correct-vs-zero差，但最终上限接近单流。这条因果图为H1/H2→有效互补弱→共同适应与小净差；另一条是本有互补→不利共同优化/能力让渡→小净差。现有冻结证据无法选择二者。

反对把H3直接删除的理由是：任务冗余并不逻辑上要求zero性能差，特征压缩也不必导致卫星路径无法独立工作；联合训练的路由选择是额外可干预机制。但“可干预”不是“已证主因”。高gate只说明训练采用了这条通路，既可出现在真正增加信息时，也可出现在重复重编码时；不能从幅值推断让渡，更不能把H1/H2阴性探针拼成H3阳性证明。

## 唯一最小机制对照（未来建议，未执行）

若明确要检验H3，最低限度应是**一对匹配训练的“保留卫星独立运行能力”干预，而不是再做冻结zero**。一个具体可审查设计：同generic初始化、同图/框监督合同、同6240更新/EMA/clip/LR与融合；每步两次mask计算、损失权重固定：控制为`0.5 L_fused + 0.5 L_fused`，干预为`0.5 L_fused + 0.5 L_UAV-off`，共享卫星/decoder参数，off分支不更新UAV；RPN/检测及其它loss保持原权重。固定两pass计算图/随机数与正proposal协议，防止把多一次训练样本或额外预算误作效果。它是一项训练目标变量，不同时改P2/detach/grid/gate。

预注册同时检查独立空间test的fused AP与off AP/固定共同预测框IoU：只有**off能力恢复且fused净优势也扩大**才支持“不保留卫星独立能力是净收益瓶颈”。若off恢复而fused仍接近单流，H3作为首要净收益根因削弱，H1/H2更值得查；若off不恢复，这次干预未实现操纵，不能拿阴性否定H3。若fused变好但off未恢复，更像一般正则/优化改变，也不算能力让渡机制成立。

这仍是对“保护卫星运行方式”策略的因果效应，不能单靠一个训练对照证明原始信息独有性，或把encoder损失与decoder适配分别量化。off分支训练暴露消除了当前最突出的OOD解释，但损失目标改变仍可能有正则作用；要主张梯度竞争，还需另行同batch分loss梯度方向观测，而不是从这个对照推出来。不能要求一个最小对照同时因果识别H1、H2、H3全部链路。

目前阶段优先级仍应结合另外两路：先核外部可见目标互补/对应或完成唯一已注册尺度候选；若根本没有可用增量证据，不应为了H3先追加上述训练。这一设计仅说明H3还欠哪种证据，本次未请求/启动新训练。

## 交叉阅读H2完整稿后的补充

已读`/tmp/ue_hypothesis_representation_loss.md`。该稿最终明确“检查效用排序不是因果置信排序”，因此不反对其优先闭环现成尺度候选；但综合报告必须保留这句，不能缩为“结构压缩证据最强，所以H2是第一根因”。压缩对输入差异的损失与对目标条件充分统计量的损失不是一回事，一个粗向量仍可能在通道编码边界。

尤其旧ridge和stage读出中的卫星条件来自**已共适应dual的pre-fusion分支**。这使弱条件增量既不能测独立single的剩余信息，也不能测让渡代价：若dual卫星较弱，UAV的增量可能只是补回旧能力；若dual卫星已经通过训练变强，条件增量反而会被压低；如果decoder只在融合统计下读取，encoder可能均未损坏。缺少独立的能力定义与控制，方向都不能从现有读出推断。

本报告的最小保留监督对照也**不能区分H1冗余是否真实**：完全冗余的UAV有时也能经正则提高有限样本模型表现；真实独有信息与保护卫星路径可同时存在。它最多测试“不约束卫星独立运行是否是可避免的系统代价”，不能把阳性自动称为恢复让渡，也不能把阴性自动称原始冗余。正式双流仍遵守generic联合初始化；未建议将UE单流热启动当正式结果。

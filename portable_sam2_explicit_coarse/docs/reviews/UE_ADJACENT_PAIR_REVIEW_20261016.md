## 实现审查发现清单

1. **无阻断错误：匹配基数优先。** 合格边权重为 N_GT+1+IoU，dummy 为 0；丢一条合格边的损失大于其余至多 N_GT 条边 IoU 和的任何收益。一个预测只能对应一个 GT。pair-local 两栋可行性可正确暴露全图第三栋竞争。
2. **无阻断错误：邻接与单位。** 距离为 GT 可见 mask 前景像素中心间距离；8 邻接接触与 5px 近邻分开，名义米数只对应 Z=0 平面。它不是建筑真实足迹间距，也不是连续边缘间隙。全 mask 与最大连通分量敏感性并列，避免把零散碎片直接视作可靠物理贴邻。
3. **报告口径须明确：侵入分母。** 当前 `neighbor_coverage_given_box_match` 统计每一个已匹配框对应 mask 对邻栋 GT 的覆盖；若一对仅一栋框匹配，该有向记录也纳入。分母是 assignment 条数，不是两框均成功分开的 pair 数，也不是所有 pair 数。每条覆盖比例分母为邻栋 GT 面积。若声称“框已分开后侵入”，需改用 `box_assigned_mask_failure` 或另限制两框均成功的记录。
4. **归因边界合理。** 缺 RPN 覆盖、score/NMS 跨阈值损失是 per-GT 最佳框摘要标签，可重叠。缓存没有全部候选身份，不能从标签推出 pre-NMS 两框独立可行性、直接抑制者或“改 NMS 必然提升 AP”。mask 失败而 box 成功也是描述性分层，不足以断言唯一病因在 SAM。
5. **重复出现边界合理。** pair appearances 与 unique physical pairs 同列，物理对等权均值作为敏感性分析；图像 bootstrap 不能覆盖跨图重复物理建筑相关性、单 seed 与 best-val 选择偏差。结果不能成为 H1 普遍成立/不成立的证据。
6. **非 AP：** 全图一对一最大基数/IoU 匹配不按分数递进，成功率不等于 COCO AP；需保留原 AP 伴随数据。一个预测覆盖两栋各 50% 的标签也不能直接等同于“模型合并两栋且造成漏检”。

## 数字复现结果

独立使用 5px 欧氏圆盘形态学膨胀和 3×3 接触膨胀核对全量邻接；从原始四臂 RLE/框重建 IoU 与匹配；用另一稀疏最大二分匹配实现验证匹配基数；校验缓存最终框最佳 IoU 与原 DT、GT 固定框 mask IoU。


- 153 图、4496 GT appearances；邻接 3734 pair appearances / 290 physical pairs，其中接触 3375/253、非接触近邻 359/75（物理对跨层可重复，不能将 253+75 当总去重数）。独立膨胀方法重算的全部 pair 身份与接触分层与主实现完全相同。
- 从原始四臂 GT/DT RLE 与 COCO xywh 框独立重算 2448 个 IoU 阈值匹配矩阵（153×4×2×mask/box）；全部 pair 的 mask/box 成功与主结果一致，另用稀疏最大二分匹配核对全部匹配基数。
- 四臂、四分层、两阈值的全部布尔标签计数、物理对等权均值、单流→双流四格表均复核一致。
- 8 个 image-paired bootstrap 区间按预注册 seed/2000 次独立重算，一致。
- stage 缓存 final_best bbox IoU 对比原 DT 重算最大绝对差 3.8096e-7；固定 GT 框缓存 mask IoU 对比原 RLE 重算最大绝对差 0。
- 复核产物：`independent_check.py`、`independent_numbers.json`、`independent_check.log`（均在本评审同目录）。

- @0.5：57 对改善、40 对退化，净 +17/3734=+0.4553pp；探索性图像 CI [-0.3338,+1.2634]pp。
- @0.75：149 对改善、148 对退化，净 +1/3734=+0.0268pp；CI [-1.2487,+1.2954]pp。物理对等权成功率 54.6201%→52.7803%，反降约 1.8398pp。不能只报告出现次数权重下的小幅正值。
- 双流 @0.5 的 374 个 mask 失败对中，327 个 bbox 配对也失败（87.43%），47 个 bbox 成功；这支持下一步优先检查检测候选、排序/抑制与实例身份消费接口的选择依据。它不证明 bbox 失败是全部 mask 失败的原因，亦不排除两个任务共享表征不足。
- 正确 UAV 与 zero/shift 在严格 mask 配对指标上差异明显，而 bbox 配对近似不动，支持“训练好的双流确实消费 UAV，并主要影响 mask 结果”；仍不能由此推断 UAV 提供了卫星不可替代的新信息，或比单流有稳定收益。
- H1 尚未被该诊断证伪，也未得到稳定收益支持。首版模型未显示可靠的严格相邻实例分离增益；优先方向需结合本次分层，避免把“改 mask 分支”或“换 NMS”直接写成已证实有效的解法。

## 事后补充分层与多块覆盖代理（独立追加复核）

VERDICT: PASS — `POSTHOC_SCOPE.md` 与 `ue_adjacent_pair_sensitivity.py` 的事后属性、定义和计算一致；原主统计未改变。

补充触发于六例读图之后，不属于事前注册的主要指标，也不能包装为 H1 或过分割机制的预注册验证。补充目的正当：避免把图边小块、同栋屋顶被拆分、多栋被合并混成同一种原因。

### 独立重算

`independent_sensitivity.py` 不调用主敏感性脚本函数，直接解码 GT/预测二值 mask：从四边像素核对触边，从面积核对 small，从交并集像素数核对每个碎块候选的覆盖、纯度、两预测互 IoU 及联合覆盖。所有标记的 GT 身份与预测 index 完全一致，全部六组分母、每阈值四格计数、失败对 GT-box 条件量与碎块计数均一致。133 条跨臂 GT 记录不等于 133 个独立建筑；详见 `independent_sensitivity_numbers.json`。

### 数字与结论边界

- 全部双流 @0.5 mask 失败对为 374，其中任一 GT 触边组失败 301，非触边组失败 73；任何 small 组失败 257。触边与 small 重叠，不可相加。全量失败统计确实强烈受图边/小物体分层影响。
- 两栋均不触边且均非 small 的 1544 对（141 个物理对）中，单流/双流 @0.5 成功 1501/1505；双流失败 39，其中 bbox 同失败 33、bbox 成功 6。@0.75 成功 1282/1297，双流失败 247，其中 bbox 同失败 181、bbox 成功 66。这是事后选定的敏感性组，不能取代主集合结果。
- 该组双流 @0.5 的 39 个失败对，在 GT 框条件下两栋 mask 均可过线；这是改变输入框后的条件诊断，支持“候选实例范围/分组或后续消费接口值得优先排查”，不证明只改框必然改善 AP，也不证明改 NMS 即可恢复它们。
- 多块覆盖代理：全部双流 mask 失败对 374 中有 73 个命中；非触边非 small 组 39 个失败中 18 个命中。代理表明同一 GT 有两个分离的较纯局部预测能够覆盖其较大部分，不能直接视作人工确认的过分割。73 个 pair 也可能反复涉及同一 GT/物理建筑；不是独立样本的故障发生率。
- 代理明确只标记原 @0.5 一对一匹配未通过的 GT；它不能覆盖所有“多块”现象，也不与跨栋覆盖、低质量候选、score/NMS 损失互斥。较大实例拥有两个较纯预测可出现，几何代理本身不足以确证生成过程因果。

### 对建议的独立判断

“优先核对实例整体性/候选排序；后续 UAV 读取接口应在最终 NMS 之前的候选 bbox/RoI 阶段有机会起效”是与已有证据相容的下一步工程假设。局部读取应保留整栋上下文，因过窄的屋顶局部证据也可能继续强化分块。当前数据不足以把 RPN 或 NMS 指认为因果主因；最后 mask 端仍有失败子集，不能把这些接口全部放弃。后续正式实现应单独预注册比较协议，不由本次事后敏感性结果直接批准大规模训练或宣称收益。
